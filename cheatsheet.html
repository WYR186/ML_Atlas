📐 Block 1 · Foundations

算法公式 · Formula高频考点

Conditional Indep.条件独立$P(A,B\mid C)=P(A\mid C)P(B\mid C)$Naive Bayes 因子分解
PCA IntuitionPCA 直觉$Au=\lambda u$先中心化 → 最大特征值方向

🧮 Block 2 · KNN · Naive Bayes

KNN ClassificationKNN 分类$\hat y(x)=\mathrm{mode}\{y_i:x_i\in\mathcal{N}_k(x)\}$特征缩放；高维 distance concentration
NB FactorizationNB 分解$P(X\mid Y)=\prod_j P(X_j\mid Y)$log-space MAP；GNB 共享方差 ⇒ 线性边界

📈 Block 3 · Linear · Logistic · SVM · Kernel

Linear Reg$w^*=(X^\top X)^{-1}X^\top y$闭式解需要 $X^\top X$ 可逆
Logistic$\min_w\sum\log(1+e^{-y_i w^\top x_i})$边界仍线性（$\sigma(a)=0.5\Leftrightarrow a=0$）
SVM hard$\min\tfrac12\|w\|^2,\ y_i(w^\top x_i+b)\ge 1$最大间隔；只支持向量决定解
Hinge$\ell=\max(0,1-yf(x))$先 $t=yf(x)$ 再代入
RBF$k(x,x')=\exp(-\gamma\|x-x'\|^2)$$\gamma\uparrow$ ⇒ 边界更弯曲 / 易过拟合

🌳 Block 4 · Trees · Ensemble · PCA · K-means

Entropy / IG$IG=I(D)-\sum\frac{|D_j|}{|D|}I(D_j)$贪心选最大 IG；纯叶 → 过拟合
Baggingbootstrap + 平均降方差，偏差几乎不变
Boosting串行 + 关注难样本常降偏差；对噪声敏感
PCA$\Sigma=\tfrac1n\sum x_c x_c^\top$先居中；PC1 = max-eig 方向
K-means$J=\sum r_{ik}\|x-\mu_k\|^2$E 分配 / M 更新；局部最优

🧠 Block 5 · MLP · Backprop · CNN · RNN

MLP forward$z^{(2)}=W^{(2)}\sigma(W^{(1)}x+b^{(1)})+b^{(2)}$XOR 需隐藏层 + 非线性

🎭 Block 6 · AE · VAE · Contrastive

AE$\min\|x-g(f(x))\|^2$线性 AE ≈ PCA；需正则防恒等
VAE ELBO$\mathbb{E}_q[\log p_\theta(x\mid z)]-D_{KL}(q\|p)$重建 + KL；最大化 ≈ 最大化 $\log p(x)$
Reparam$z=\mu+\sigma\odot\epsilon$把随机性转移到 $\epsilon$
Gaussian KL$\tfrac12\sum(\mu_j^2+\sigma_j^2-\ln\sigma_j^2-1)$必背 / 必推
InfoNCE$-\log \frac{e^{s(x,x^+)/\tau}}{\sum e^{s/\tau}}$$\tau\downarrow$ 更尖锐；负样本防坍塌

🌊 Block 8 · Diffusion

Forward$x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$$\bar\alpha_T\to 0 \Rightarrow x_T\approx\mathcal{N}(0,I)$
Reverse$p_\theta(x_{t-1}\mid x_t)=\mathcal{N}(\mu_\theta,\Sigma_\theta)$前向固定 / 逆向学习；常预测 $\epsilon$
ELBO重建 + 先验 KL + 每步一致性每步对齐已知 $x_0$ 真后验

🎓 Block 9 · Learning Theory

Bayes 决策$\eta(x)\ge 0.5 \Rightarrow 1$回归：$f^*(x)=\mathbb{E}[Y\mid X]$

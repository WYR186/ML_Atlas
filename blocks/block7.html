👀 1. Attention · 注意力机制

🧠 直觉 · 按需检索

Query 提问，Key 做索引，Value 提供内容。让模型在处理某个 token 时，动态“关注”序列中其它 token，缓解 RNN 必须把信息压缩到固定向量的瓶颈。

Scaled Dot-Product Attention（必背公式）
$$ \mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$
⚖️ 为什么除以 $\sqrt{d_k}$？

$d_k$ 越大，点积幅值越大，softmax 更易饱和导致梯度变小。除以 $\sqrt{d_k}$ 让方差近似常数级，训练更稳定。

自注意力 Self-Attention

$Q,K,V$ 都来自同一输入 $X$：$Q=XW_Q,\ K=XW_K,\ V=XW_V$。

  • 并行计算（相比 RNN）。
  • 捕捉长程依赖。
🕶️ Masked Attention（必考考点）
  • Decoder 自回归生成中：把未来位置的 logits 设为 $-\infty$ → softmax 后权重 0。
  • 易错点：mask 是加到 softmax 之前的 logits 上，不是 softmax 之后。
  • 为什么必须？避免 train–test mismatch（训练时偷看未来 → 推理无法复现）。

🌊 2. Positional Encoding · 位置编码

Self-attention 对输入顺序不敏感（permutation invariant），需要显式注入位置信息。

Sinusoidal PE
$$ PE_{(pos,2i)}=\sin\!\Big(\tfrac{pos}{10000^{2i/d}}\Big),\quad PE_{(pos,2i+1)}=\cos\!\Big(\tfrac{pos}{10000^{2i/d}}\Big) $$
✅ Exam focus

$PE(pos+k)$ 可表示为 $PE(pos)$ 的线性变换（旋转 / 相位移动），便于模型学习相对位置关系。

🔮 3. Transformer 架构

标准 Block 组件

  • LayerNorm（层归一化）
  • Multi-Head Attention（多头注意力 MHA）
  • Feed-Forward Network（FFN / MLP）
  • Residual Connections（残差）
🔧 Mnemonic

LN → (MHA) → Add → LN → (FFN) → Add

实现可能是 Pre-LN 或 Post-LN 变体。

Multi-Head Attention

多个 head 并行在不同表示子空间学习关系（语法 / 语义 / 指代等），最后拼接 + 投影。

✅ Exam checklist

  • 说明为什么需要 PE。
  • 说清 Transformer block 的组成。

$$ PP(X)=\exp\!\big(L(X;\theta)\big) $$
如 $L=2 \Rightarrow PP=e^2\approx 7.39$。
🧱 BPE 分词

迭代合并高频符号对，平衡词表大小与序列长度。

🛠️ Post-training 阶段（区分清楚！）
  • Pre-training：海量无标注文本上的 next-token loss。
  • SFT（Supervised Fine-Tuning）：指令 - 回复对的监督学习。
  • RLHF：人类反馈强化学习（偏好对齐）。
  • ICL（In-context Learning）：不更新参数，仅靠 prompt 示例。
🧩 Example · Mask 必要性

训练时若允许关注未来 token，会信息泄露（“看答案”），训练–推理失配。Causal mask 保证每步只依赖过去。

🧠 1. Neural Networks · MLP

  • 非线性必要性：单层线性模型无法解决 XOR；隐藏层 + 非线性激活可学习更强表示。
  • 通用近似定理：足够宽 + 含非线性 ⇒ 可近似任意连续函数（一定条件下）。
  • 深 vs 宽：深度带来层级抽象；宽度决定容量。

二层网络前向传播

$$ z^{(1)} = W^{(1)}x + b^{(1)} $$
$$ a^{(1)} = \sigma(z^{(1)})\quad(\text{often ReLU}) $$
$$ z^{(2)} = W^{(2)}a^{(1)} + b^{(2)} $$
多分类：$\hat y=\mathrm{softmax}(z^{(2)})$；二分类：$\hat y=\sigma(z^{(2)})$

常用激活

  • Sigmoid / Tanh：易饱和 → 梯度消失。
  • ReLU：$\mathrm{ReLU}(z)=\max(0,z)$。
  • Leaky / ELU：缓解 ReLU 在 $z<0$ 处梯度为 0。
⚠️ Pitfall

把 ReLU 写成 $\max(z,1)$，或忘记 ReLU 在负半轴梯度为 0。

常见损失

  • BCE（二分类）
  • Softmax + Cross-Entropy（多分类）
  • MSE（回归）
🧩 Example · XOR 为什么需要隐藏层

单层感知机等价于一个线性超平面，无法分开 XOR 的对角点对。隐藏层 + 非线性激活可构造中间特征（如 $x_1\lor x_2$、$x_1\land x_2$ 的变体），再线性组合即可。

🔁 2. Backpropagation · 反向传播

本质：链式法则在计算图上的高效实现。

核心口令

downstream gradient = local gradient × upstream gradient

必考 · Shape Check
$$ \frac{\partial L}{\partial W}\ \text{must have the same shape as}\ W $$
不会推导时：先写出每个张量 shape，用矩阵乘法规则倒推，常能救命。
✅ Exam focus
  • 给两层网络，能写出对每个 $W^{(l)}, b^{(l)}$ 的梯度（含 shape）。
  • 知道 Forward 缓存 $z^{(l)},a^{(l)}$，Backward 从 loss 逐层回传。

🖼️ 3. CNN

  • 局部连接：感受野关注局部（边缘/纹理）。
  • 权重共享：同一卷积核滑动 → 参数更少 + 平移不变性。
  • 核心结构：Conv（特征提取）→ Pooling（降采样）→ FC（分类/回归）。
必考 · Output Size（一维，2D 对 H/W 分别算）
$$ \text{Output}=\left\lfloor\frac{N+2P-F}{S}\right\rfloor+1 $$
$N$ 输入；$P$ padding；$F$ kernel；$S$ stride。
⚠️ Pitfall
  • 忘记取 floor。
  • 把 $2P$ 写成 $P$。
  • 用错 $F$ 与 $S$。
🧩 Example · 输出尺寸

$N=32,F=5,P=2,S=1$：

$$ \left\lfloor\frac{32+4-5}{1}\right\rfloor+1 = 31+1 = 32 $$

$P=2$ 抵消 $F=5$ 的缩小效应。

🔄 4. RNN · 循环神经网络

  • 参数共享：同一组参数处理每个时间步。
  • 隐藏状态 $h^{(t)}$ 作为“记忆”，汇总到时间 $t$ 的信息。
  • BPTT：把 RNN 在时间上 unroll 成深网络再做标准 backprop。
💥 核心挑战

长序列中反复乘同一权重矩阵 → 梯度消失 / 爆炸（vanishing / exploding gradients）。

🚪 5. LSTM & GRU · 门控机制

  • 目标：通过门控控制信息流动，缓解长程依赖。
  • LSTM gates：Forget / Input / Output。
  • GRU gates：Update / Reset（参数更少）。
🧠 直觉

门 = sigmoid 控制器，决定“写入多少 / 保留多少 / 输出多少”，把梯度沿 cell-state 走的“高速公路”稳定下来。

👀 接 Block 7 · Attention
$$ \mathrm{Attention}(Q,K,V)=\mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V $$

相比 RNN：并行训练 + 长序列依赖更强。

✅ Block 5 速记 Checklist

  • MLP：先 forward（$z,a$），再 loss，做 shape check
  • Backprop：一句话“chain rule” → local × upstream
  • CNN：套 $\lfloor (N+2P-F)/S\rfloor+1$（注意 floor）
  • RNN：BPTT + vanishing/exploding；写门控直觉
  • Attention：写公式 + “加权求和”

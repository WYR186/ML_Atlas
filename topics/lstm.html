LSTM and GRU

LSTMs and GRUs are gated recurrent cells designed to make classical RNNs better at keeping useful information across long gaps.

1. Concept Understanding

A standard RNN updates one hidden state directly. An LSTM adds a separate memory cell $c^{(t)}$ and gates that decide what to forget, what to write, and what to expose as the hidden state.

Problem background. Classical RNNs repeatedly multiply gradients through time, so long-term signals can vanish or explode.
What gates solve. Gates create controlled additive memory updates, so information can persist without being overwritten at every step.
GRU variant. GRU keeps the gating idea but uses fewer gates and no separate output gate, making it lighter than LSTM.

2. Plain-English Explanation

Think of an LSTM as a notebook with three small switches. One switch decides what old notes to erase, one decides what new note to write, and one decides how much of the notebook to show to the rest of the model.

A GRU is the simpler travel version of the notebook: fewer switches, easier to carry, often good enough.

3. Core Intuition

The cell state $c^{(t)}$ is the important highway. Instead of replacing memory completely, LSTM updates it additively:

$$ c^{(t)} = f^{(t)}\odot c^{(t-1)} + i^{(t)}\odot \tilde c^{(t)} $$

This structure lets the model keep old information when $f^{(t)}$ is near 1 and write new information when $i^{(t)}$ is large. The model learns the gates from data; they are not hand-coded rules.

Constant Error Carousel (CEC). The formal name for what the additive update achieves. When $f^{(t)}\!\approx\!1$, the partial derivative $\partial c^{(t)}/\partial c^{(t-1)}\!\approx\!1$, so the cell state forms a near-identity linear self-loop that gradients can travel along over many time steps without exponential decay. That uninterrupted gradient path is exactly the architectural fix for the vanishing-gradient problem in vanilla RNNs — there's no repeated multiplication by a $<1$ Jacobian factor.

4. Key Equations

LSTM gates from Lecture 14
$$ i^{(t)}=\sigma(W_{ix}x^{(t)}+W_{ih}h^{(t-1)}+b_i) $$
$$ f^{(t)}=\sigma(W_{fx}x^{(t)}+W_{fh}h^{(t-1)}+b_f) $$
$$ o^{(t)}=\sigma(W_{ox}x^{(t)}+W_{oh}h^{(t-1)}+b_o) $$
$$ \tilde c^{(t)}=\tanh(W_{cx}x^{(t)}+W_{ch}h^{(t-1)}+b_c) $$

Symbols. $x^{(t)}$ is current input and $h^{(t-1)}$ is previous hidden state. $i^{(t)}$ is the input gate, $f^{(t)}$ the forget gate, $o^{(t)}$ the output gate, and $\tilde c^{(t)}$ the candidate memory. Each $W$ and $b$ is gate-specific. $\sigma$ is sigmoid, so gate values lie between 0 and 1.

How to read it. Each gate looks at the current input and previous hidden state, then outputs a soft switch. Near 0 means closed; near 1 means open.

How to use. Compute the three gates and candidate memory first. Then plug them into the cell-state and hidden-state update formulas.

Cell and hidden updates
$$ c^{(t)}=f^{(t)}\odot c^{(t-1)}+i^{(t)}\odot \tilde c^{(t)}, \qquad h^{(t)}=o^{(t)}\odot \sigma_h(c^{(t)}) $$

Symbols. $c^{(t)}$ is internal cell memory. $f^{(t)}\odot c^{(t-1)}$ keeps old memory coordinate by coordinate. $i^{(t)}\odot\tilde c^{(t)}$ writes new candidate memory. $o^{(t)}$ controls how much updated memory becomes visible as $h^{(t)}$. $\odot$ means elementwise multiplication.

How to read it. The cell update is keep-old-memory plus write-new-memory. The plus sign is the key: memory can flow additively instead of being overwritten every step.

How to use. If a problem gives gate values directly, skip matrix multiplications and plug vectors into the cell equation coordinate by coordinate.

GRU summary
$$ z^{(t)}=\sigma(W_{zx}x^{(t)}+W_{zh}h^{(t-1)}+b_z), \qquad r^{(t)}=\sigma(W_{rx}x^{(t)}+W_{rh}h^{(t-1)}+b_r) $$
$$ \tilde h^{(t)}=\tanh(W_{\tilde h x}x^{(t)}+W_{\tilde h h}(r^{(t)}\odot h^{(t-1)})+b_{\tilde h}) $$
$$ h^{(t)}=(1-z^{(t)})\odot \tilde h^{(t)}+z^{(t)}\odot h^{(t-1)} $$

Three lines = one GRU step. Line 1 computes the two gates from the current input and previous hidden state. Line 2 computes a candidate hidden state $\tilde h^{(t)}$ — like a vanilla-RNN proposal, except the previous state is first masked by the reset gate $r^{(t)}\odot h^{(t-1)}$ so the candidate can ignore stale context. Line 3 blends the candidate with the previous state using the update gate.

Symbols. $z^{(t)}$ is the update / keep gate in this convention; $r^{(t)}$ is the reset gate; $\tilde h^{(t)}$ is the candidate hidden state; $W_{\tilde h x}, W_{\tilde h h}, b_{\tilde h}$ are the candidate's own weights (separate from the gate weights); $\odot$ is elementwise multiplication.

How to read it. GRU blends old hidden state with the candidate using fewer gates than an LSTM (no separate cell state, no output gate). With this written convention, large $z^{(t)}$ keeps more old hidden state.

How to use. Compute $z, r$ first, then $\tilde h^{(t)}$ (don't forget the reset mask on $h^{(t-1)}$), then the blended $h^{(t)}$ coordinate by coordinate. Always look at the formula before explaining $z$'s direction — some textbooks flip the convention.

Why the candidate matters. Without the $\tilde h$ line, the GRU is incomplete — the update equation $h^{(t)}=(1-z)\odot\tilde h+z\odot h^{(t-1)}$ alone doesn't tell you what $\tilde h$ is. HW3-style "fill in the GRU forward pass" or "back-prop through one GRU step" questions almost always ask about this middle line.

5. Worked Examples

Lecture 14 gate interpretation. Input gate asks whether the current input matters; forget gate asks whether old memory should remain; output gate asks how much memory should be exposed.
Lecture 14 GRU comparison. Update gate controls how much previous hidden state survives; reset gate controls how much old state contributes to the candidate memory.

6. Problem-Solving Tips

  • When asked for intuition, name the three LSTM actions: forget old, write new, expose output.
  • When reading equations, separate gates from candidate memory. Gates usually use sigmoid; candidate memory often uses tanh-like activations.
  • For shape checks, every gate vector has the same dimension as the hidden state.
  • For comparisons, say GRU is simpler and parameter-lighter; LSTM has an explicit cell state and output gate.
  • Initialize the forget-gate bias $b_f$ to ~1. A standard practical trick: at $t=0$ this makes $f^{(t)}\!\approx\!\sigma(1)\!\approx\!0.73$, so the cell starts in a "remember by default" state and learns what to forget rather than starting from "forget everything." Big convergence-speed win on long sequences and a frequent quiz / interview gotcha.
  • When does LSTM actually pay off? LSTM has roughly 4× the parameters per cell of a vanilla RNN (3 gates + candidate memory), so it's slower per step and per epoch. The trade is worth it for tasks where long-range context matters — machine translation, handwriting recognition, speech, long-document summarization. For short-context tasks a vanilla RNN or even an MLP may match it.

7. Common Mistakes

  • Calling the forget gate a hard delete. It is continuous: values can keep part of the old memory.
  • Mixing up $c^{(t)}$ and $h^{(t)}$. The cell state stores memory; the hidden state is the exposed representation.
  • Forgetting that LSTMs are still trained with BPTT.
  • Assuming LSTM completely solves all long-sequence problems. It helps, but transformers are used because they parallelize better and handle very long dependencies differently.

8. Exam Focus

  • Know what input, forget, and output gates mean.
  • Be able to read and explain the LSTM cell update equation.
  • Explain how gates mitigate vanishing gradients compared with vanilla RNNs.
  • Compare LSTM and GRU at the conceptual level.

9. Quick Checklist

  • LSTM = recurrent model plus gated memory cell.
  • $f_t$ keeps old memory; $i_t$ writes new memory; $o_t$ exposes memory.
  • GRU has update and reset gates, usually fewer parameters.
  • Training still uses BPTT.

LSTM 与 GRU · 门控循环单元

LSTM 和 GRU 是为了解决 vanilla RNN 不擅长长程依赖而设计的 gated recurrent cells。核心不是“更玄学”，而是更会控制记忆。

1. 概念理解 / Concept Understanding

普通 RNN 直接更新 hidden state。LSTM 额外引入 cell state $c^{(t)}$，并用 gates 决定旧信息保留多少、新信息写入多少、当前记忆暴露多少。

问题背景：classical RNN 的梯度要沿时间反复相乘，长距离信号容易 vanishing / exploding。
解决什么：门控让 memory 以 additive update 的方式流动，不必每一步都被彻底覆盖。
GRU 变体：保留 gating 思想，但门更少、没有单独 output gate，参数量通常更小。

2. 大白话理解 / Plain-English Explanation

把 LSTM 想成一本笔记本加三个开关：一个决定旧笔记擦多少，一个决定新笔记写多少，一个决定这页笔记给外面看多少。

GRU 就像轻量版旅行笔记本：开关少一些，背起来更轻，很多任务上也够用。

3. 核心直觉 / Core Intuition

最重要的是 cell state $c^{(t)}$ 这条“记忆高速路”。LSTM 不是每步都重写记忆，而是做加法式更新：

$$ c^{(t)} = f^{(t)}\odot c^{(t-1)} + i^{(t)}\odot \tilde c^{(t)} $$

当 $f^{(t)}$ 接近 1，旧记忆保留；当 $i^{(t)}$ 大，新信息写入。gate 是模型从数据里学出来的，不是人工规则。

Constant Error Carousel (CEC). 这套加法式更新有个正式名字。$f^{(t)}\!\approx\!1$ 时，$\partial c^{(t)}/\partial c^{(t-1)}\!\approx\!1$，cell state 形成一条近似 identity 的 linear self-loop，gradient 可以沿着它穿越很多 time step 而不会指数衰减。这条不被打断的 gradient 路径，就是 LSTM 解决 vanilla RNN vanishing-gradient 的架构层手术 —— 没有反复乘以 $<1$ 的 Jacobian factor。

4. 核心公式 / Key Equations

Lecture 14 的 LSTM gates
$$ i^{(t)}=\sigma(W_{ix}x^{(t)}+W_{ih}h^{(t-1)}+b_i) $$
$$ f^{(t)}=\sigma(W_{fx}x^{(t)}+W_{fh}h^{(t-1)}+b_f) $$
$$ o^{(t)}=\sigma(W_{ox}x^{(t)}+W_{oh}h^{(t-1)}+b_o) $$
$$ \tilde c^{(t)}=\tanh(W_{cx}x^{(t)}+W_{ch}h^{(t-1)}+b_c) $$

符号. $x^{(t)}$ 是当前 input，$h^{(t-1)}$ 是上一 hidden state；$i^{(t)}$ 是 input gate，$f^{(t)}$ 是 forget gate，$o^{(t)}$ 是 output gate，$\tilde c^{(t)}$ 是 candidate memory。每组 $W,b$ 都属于对应 gate；$\sigma$ 是 sigmoid，所以 gate 值在 0 到 1 之间。

怎么理解. 每个 gate 都看当前 input 和上一 hidden state，然后输出一个 soft switch。接近 0 表示关，接近 1 表示开。

怎么用. 先算三个 gates 和 candidate memory，再把它们代入 cell state / hidden state 更新公式。

cell state 与 hidden state
$$ c^{(t)}=f^{(t)}\odot c^{(t-1)}+i^{(t)}\odot \tilde c^{(t)}, \qquad h^{(t)}=o^{(t)}\odot \sigma_h(c^{(t)}) $$

符号. $c^{(t)}$ 是内部 cell memory；$f^{(t)}\odot c^{(t-1)}$ 表示逐坐标保留旧 memory；$i^{(t)}\odot\tilde c^{(t)}$ 表示写入新 candidate memory；$o^{(t)}$ 控制多少 memory 暴露成 $h^{(t)}$；$\odot$ 是 elementwise multiplication。

怎么理解. Cell update = 保留旧记忆 + 写入新记忆。中间的加号很关键：memory 可以 additive 地流动，而不是每一步都完全覆盖。

怎么用. 如果题目直接给 gate values，就跳过矩阵乘法，把向量逐坐标代进 cell equation。

GRU 速记
$$ z^{(t)}=\sigma(W_{zx}x^{(t)}+W_{zh}h^{(t-1)}+b_z), \qquad r^{(t)}=\sigma(W_{rx}x^{(t)}+W_{rh}h^{(t-1)}+b_r) $$
$$ \tilde h^{(t)}=\tanh(W_{\tilde h x}x^{(t)}+W_{\tilde h h}(r^{(t)}\odot h^{(t-1)})+b_{\tilde h}) $$
$$ h^{(t)}=(1-z^{(t)})\odot \tilde h^{(t)}+z^{(t)}\odot h^{(t-1)} $$

三行 = 一个 GRU 步. 第 1 行用当前 input 和上一 hidden state 算两个 gates。第 2 行算 candidate hidden state $\tilde h^{(t)}$ —— 像 vanilla RNN 的 proposal，区别是先用 reset gate 给 previous state 套了 mask $r^{(t)}\odot h^{(t-1)}$，让 candidate 可以选择忽略陈旧 context。第 3 行用 update gate 把 candidate 与 previous state blend 起来。

符号. 这个写法下 $z^{(t)}$ 是 update / keep gate；$r^{(t)}$ 是 reset gate；$\tilde h^{(t)}$ 是 candidate hidden state；$W_{\tilde h x}, W_{\tilde h h}, b_{\tilde h}$ 是 candidate 自己的 weights（与 gate weights 分开）；$\odot$ 是 elementwise multiplication。

怎么理解. GRU 用 更少 的 gates 把旧 hidden state 和 candidate 混在一起（没有单独 cell state，也没有 output gate）。这个写法下 $z^{(t)}$ 越大，越保留旧 hidden state。

怎么用. 先算 $z, r$，再算 $\tilde h^{(t)}$（别忘记给 $h^{(t-1)}$ 套 reset mask），最后逐坐标 blend 出 $h^{(t)}$。注意有些教材的 $z$ 方向相反，先看公式再解释。

candidate 为什么必要. 没有 $\tilde h$ 这一行整个 GRU 就不完整 —— 单看 $h^{(t)}=(1-z)\odot\tilde h+z\odot h^{(t-1)}$ 你不知道 $\tilde h$ 是什么。HW3 风格的 “补全 GRU forward pass” 或 “backprop 一个 GRU step” 题，几乎都问中间这一行。

5. 例题讲解 / Worked Examples

Lecture 14 gate 解释：input gate 问当前输入重不重要；forget gate 问旧 memory 要不要留；output gate 问多少 memory 暴露给 hidden state。
Lecture 14 GRU 对比：update gate 控制上一 hidden state 保留多少；reset gate 控制旧状态对 candidate memory 的影响。
HW3 2.2 关联：BPTT 题展示了 repeated product 为什么脆弱；LSTM 的 additive cell update 就是在结构上回应这个问题。

6. 解题技巧 / Problem-Solving Tips

  • 解释直觉时先说三件事：forget old、write new、expose output。
  • 读公式时把 gates 和 candidate memory 分开；gate 通常是 sigmoid。
  • shape check：每个 gate vector 的维度都和 hidden state 一样。
  • 比较题里说清：GRU 更轻；LSTM 有显式 cell state 和 output gate。
  • Forget-gate bias $b_f$ 初始化为 ~1. 标准实践 trick：$t=0$ 时 $f^{(t)}\!\approx\!\sigma(1)\!\approx\!0.73$，cell 默认进入 "remember" 状态，模型只需学 "什么时候忘"，而不是从 "全部忘掉" 起步。长序列收敛速度提升明显，也是 quiz / interview 高频陷阱。
  • 什么时候真的值得用 LSTM？ 每个 cell 的参数量大约是 vanilla RNN 的 4 倍（3 个 gate + candidate memory），所以单步、单 epoch 都更慢。值得付出这个代价的场景 = 长程依赖关键的任务：machine translation、handwriting recognition、speech、long-document summarization。短上下文任务上，vanilla RNN 甚至 MLP 也可能持平。

7. 常见错误 / Common Mistakes

  • 把 forget gate 理解成硬删除。它是连续值，可以只忘一部分。
  • 混淆 $c^{(t)}$ 和 $h^{(t)}$：cell state 存记忆，hidden state 是暴露出来的表示。
  • 以为 LSTM 不需要 BPTT。它仍然是 computation graph，仍然反向传播。
  • 说 LSTM 完全解决长序列。它是缓解，不是终结；Transformer 后面还会处理并行性和更长依赖。

8. 考试重点 / Exam Focus

  • 知道 input / forget / output gate 各自含义。
  • 能读懂并解释 LSTM cell update。
  • 能说明 gate 如何缓解 vanilla RNN 的 vanishing gradients。
  • 能概念性比较 LSTM 和 GRU。

9. 速记清单 / Quick Checklist

  • LSTM = recurrent model + gated memory cell。
  • $f_t$ 留旧记忆；$i_t$ 写新记忆；$o_t$ 暴露记忆。
  • GRU 有 update / reset gates，参数通常更少。
  • 训练仍然用 BPTT。

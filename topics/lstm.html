🚪 LSTM & GRU — Gated Recurrent Cells

  • Goal: control how much information flows along the cell state, mitigating long-range dependency issues.
  • LSTM gates: Forget, Input, Output.
  • GRU gates: Update, Reset — fewer parameters than LSTM.
🧠 Intuition

Each gate is a sigmoid that decides "how much to write / keep / read". The cell state is a near-identity highway, so gradients no longer get repeatedly multiplied by a small factor.

🚪 5. LSTM & GRU · 门控机制

  • 目标：通过门控控制信息流动，缓解长程依赖。
  • LSTM gates：Forget / Input / Output。
  • GRU gates：Update / Reset（参数更少）。
🧠 直觉

门 = sigmoid 控制器，决定“写入多少 / 保留多少 / 输出多少”，把梯度沿 cell-state 走的“高速公路”稳定下来。

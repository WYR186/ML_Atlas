🔁 Backpropagation

Backpropagation is the chain rule turned into an efficient algorithm. Lecture 10 presents it as forward pass plus backward pass on a computation graph, with HW3 supplying the small two-layer network you should be able to work by hand.

1. Concept Understanding

A neural network is trained by minimizing a loss. The hard part is not the update rule itself; gradient descent only says $w_{t+1}=w_t-\alpha\nabla_w L(w_t)$. The hard part is computing the gradient for every parameter in a large graph.

  • Computational graph: a directed acyclic graph whose nodes are inputs, parameters, intermediate tensors, and operations.
  • Forward pass: compute predictions and cache whatever each operation needs for its derivative.
  • Backward pass: start at the loss with upstream gradient $1$, then apply local derivative rules in reverse order.

2. Plain-English Explanation

Imagine every operation leaves a tiny receipt during the forward pass: “I multiplied these two numbers,” or “I summed this vector.” Backprop walks backward through those receipts and asks: if the final loss changed a little, how much blame should this earlier value get?

The important habit is mechanical: cache forward values, start from the loss, and move backward one local derivative at a time.

3. Core Intuition

Backprop is efficient because it reuses partial derivatives. A parameter can influence the loss through many downstream paths; reverse-mode autodiff accumulates all those contributions into one gradient field.

Why reverse mode fits neural nets

Neural networks usually have one scalar loss and many parameters. Reverse mode computes gradients of that one scalar with respect to all parameters in roughly one backward sweep.

4. Key Equations

Chain rule at one node
$$ \bar{x}=\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial x}=\bar{y}\frac{\partial y}{\partial x} $$

$\bar{y}$ is the upstream gradient; $\partial y/\partial x$ is the local gradient.

Gradient accumulation
$$ \frac{\partial L}{\partial x}=\sum_{j:\,x\to y_j}\frac{\partial L}{\partial y_j}\frac{\partial y_j}{\partial x} $$

If a value feeds multiple later nodes, add the incoming gradient contributions.

Shape check
$$ \frac{\partial L}{\partial W}\;\text{has the same shape as}\;W $$

For a layer $z=Wx+b$, typical single-example shapes are $x\in\mathbb{R}^{d}$, $W\in\mathbb{R}^{h\times d}$, $z,b\in\mathbb{R}^{h}$, and $\partial L/\partial W=(\partial L/\partial z)x^\top$.

5. Worked Examples

Example A · Lecture 10 computational graph

Source: Lecture 10, computation-graph backprop slides. Paraphrased.

Let $c=a+b$, $d=b+1$, and $e=cd$. At $a=3,b=2$, forward gives $c=5$, $d=3$, $e=15$. Backward gives $\partial e/\partial c=d=3$ and $\partial e/\partial d=c=5$. Then $\partial e/\partial a=3$, while $b$ receives two paths: from $c$ and from $d$, so $\partial e/\partial b=3+5=8$.

Example B · HW3 §2.1 shape audit

Source: HW3 §2.1. The problem asks for dimensions in a small two-layer network.

If $x\in\mathbb{R}^{3}$, hidden width is $4$, and the output is scalar, then $W^{(1)}$ is $4\times3$, $b^{(1)}$ is length $4$, $W^{(2)}$ is $1\times4$, and every gradient with respect to a weight has the same shape as that weight.

Example C · HW3 §2.1 numerical backprop

Source: HW3 §2.1. The problem asks for forward values and gradients in a two-layer network.

Compute $z^{(1)}$, apply the ReLU mask to get $a^{(1)}$, then compute the scalar logit and binary cross-entropy gradient. The key matrix forms are $\partial L/\partial W^{(2)}=(\partial L/\partial z^{(2)})a^{(1)\top}$ and $\partial L/\partial W^{(1)}=(\partial L/\partial z^{(1)})x^\top$.

6. Problem-Solving Tips

  • Draw the graph first. Label each intermediate value, not just the final formula.
  • Write the forward values before differentiating; many local gradients need cached values.
  • Move backward one node at a time: upstream gradient times local derivative.
  • For matrix gradients, write shapes before writing formulas.

7. Common Mistakes

  • Forgetting to add gradients when a variable is reused in multiple branches.
  • Confusing elementwise multiplication with matrix multiplication.
  • Dropping a transpose in an outer product gradient.
  • Using the activation derivative at $a$ instead of at the pre-activation $z$.

8. Exam Focus

  • Hand-compute gradients on a small computational graph.
  • Explain what information must be saved during the forward pass.
  • For a two-layer network, compute forward values, masks for ReLU, and gradient shapes.
  • Use the outer-product gradient formulas for affine layers.

9. Quick Checklist

  • I can explain upstream, local, and downstream gradients.
  • I can handle reused variables by summing gradient contributions.
  • I can verify $\partial L/\partial W$ has the same shape as $W$.
  • I can write affine-layer gradients as outer products.

🔁 Backpropagation · 反向传播

Backpropagation 就是把 chain rule 做成高效算法。Lecture 10 把它讲成 computation graph 上的 forward pass + backward pass；HW3 给了你必须能手算的二层网络例题。

1. Concept Understanding

训练神经网络是在最小化 loss。梯度下降公式本身很短：$w_{t+1}=w_t-\alpha\nabla_w L(w_t)$；真正麻烦的是大模型里每个 parameter 的 gradient 怎么算。

  • Computational graph：把变量、参数、中间 tensor、operation 连接成有向无环图。
  • Forward pass：算 prediction / loss，同时缓存 backward 需要的信息。
  • Backward pass：从 loss 的 upstream gradient $1$ 开始，反向应用每个节点的 local derivative。

2. Plain-English Explanation / 大白话理解

可以把 forward 想成每一步操作都留了一张“小票”：这里做了乘法，那里做了 sum，这里过了 ReLU。Backward 就是从最后的 loss 倒着翻小票，问：如果 loss 变大一点点，前面这个数应该背多少锅？

关键习惯很机械：先缓存 forward values，从 loss 开始，倒着一次处理一个 local derivative。

3. Core Intuition

Backprop 高效，是因为它复用中间梯度。一个参数可能通过很多路径影响 loss；reverse-mode autodiff 会把这些路径上的贡献全部累加到同一个 .grad 里。

为什么 neural network 适合 reverse mode

神经网络通常是一个 scalar loss、非常多 parameters。Reverse mode 可以用一次 backward sweep 算出这个 loss 对所有参数的梯度。

4. Key Equations

单个节点的 chain rule
$$ \bar{x}=\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial x}=\bar{y}\frac{\partial y}{\partial x} $$

$\bar{y}$ 是 upstream gradient；$\partial y/\partial x$ 是 local gradient。

梯度累加
$$ \frac{\partial L}{\partial x}=\sum_{j:\,x\to y_j}\frac{\partial L}{\partial y_j}\frac{\partial y_j}{\partial x} $$

如果一个变量被多个后续节点使用，回来的 gradient contribution 要相加。

Shape check
$$ \frac{\partial L}{\partial W}\;\text{has the same shape as}\;W $$

单样本层 $z=Wx+b$ 中，若 $x\in\mathbb{R}^{d}$、$W\in\mathbb{R}^{h\times d}$，则 $\partial L/\partial W=(\partial L/\partial z)x^\top$，shape 也是 $h\times d$。

5. Worked Examples

Example A · Lecture 10 computational graph

来源：Lecture 10，computation-graph backprop slides，已转述。

设 $c=a+b$，$d=b+1$，$e=cd$。当 $a=3,b=2$，forward 得 $c=5,d=3,e=15$。Backward：$\partial e/\partial c=d=3$，$\partial e/\partial d=c=5$。所以 $\partial e/\partial a=3$；而 $b$ 走了两条路，来自 $c$ 的 $3$ 和来自 $d$ 的 $5$ 要相加，得到 $\partial e/\partial b=8$。

Example B · HW3 §2.1 shape audit

来源：HW3 §2.1，小型二层网络维度题，已转述。

若 $x\in\mathbb{R}^{3}$，hidden width 是 $4$，输出是 scalar，那么 $W^{(1)}$ 是 $4\times3$，$b^{(1)}$ 长度是 $4$，$W^{(2)}$ 是 $1\times4$。每个 weight gradient 的 shape 必须和对应 weight 一样。

Example C · HW3 §2.1 numerical backprop

来源：HW3 §2.1，二层网络 forward values 和 gradients，已转述。

先算 $z^{(1)}$，用 ReLU mask 得到 $a^{(1)}$，再算 scalar logit 和 binary cross-entropy gradient。核心矩阵形式是 $\partial L/\partial W^{(2)}=(\partial L/\partial z^{(2)})a^{(1)\top}$，以及 $\partial L/\partial W^{(1)}=(\partial L/\partial z^{(1)})x^\top$。

6. Problem-Solving Tips

  • 先画 graph，并给每个 intermediate value 命名。
  • 先算 forward 数值；很多 local derivative 需要 forward cache。
  • Backward 时一次只处理一个节点：upstream gradient × local derivative。
  • 矩阵梯度先写 shape，再写公式。

7. Common Mistakes

  • 变量被重复使用时，忘记把多条路径的 gradient 相加。
  • 把 elementwise multiplication 和 matrix multiplication 混起来。
  • Outer product gradient 里漏掉 transpose。
  • ReLU derivative 应该看 pre-activation $z$，不是看后面的符号猜。

8. Exam Focus

  • 会手算小 computational graph 的 gradient。
  • 能说明 forward pass 为什么要保存某些 tensor / shape。
  • 二层网络要会算 forward、ReLU mask、梯度 shape。
  • 会用 affine layer 的 outer-product gradient formula。

9. Quick Checklist

  • 我能解释 upstream / local / downstream gradient。
  • 我知道 reuse variable 时梯度要 sum。
  • 我会检查 $\partial L/\partial W$ 的 shape。
  • 我能把 affine-layer gradients 写成 outer products。

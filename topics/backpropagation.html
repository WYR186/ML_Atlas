🔁 Backpropagation

Backpropagation is the chain rule turned into an efficient algorithm. Lecture 10 presents it as forward pass plus backward pass on a computation graph, with HW3 supplying the small two-layer network you should be able to work by hand.

1. Concept Understanding

A neural network is trained by minimizing a loss. The hard part is not the update rule itself; gradient descent only says $w_{t+1}=w_t-\alpha\nabla_w L(w_t)$. The hard part is computing the gradient for every parameter in a large graph.

Backpropagation is an efficient local message-passing algorithm for evaluating gradients of an error function $E(w)$ in a feed-forward network. Instead of deriving a new full gradient by hand for every architecture, we decompose the network into small operations and apply the chain rule locally.

  • Computational graph: a directed acyclic graph whose nodes are inputs, parameters, intermediate tensors, and operations.
  • Forward pass: compute predictions and cache whatever each operation needs for its derivative.
  • Backward pass: start at the loss with upstream gradient $1$, then apply local derivative rules in reverse order.

2. Plain-English Explanation

Imagine every operation leaves a tiny receipt during the forward pass: “I multiplied these two numbers,” or “I summed this vector.” Backprop walks backward through those receipts and asks: if the final loss changed a little, how much blame should this earlier value get?

The important habit is mechanical: cache forward values, start from the loss, and move backward one local derivative at a time.

3. Core Intuition

Backprop is efficient because it reuses partial derivatives. A parameter can influence the loss through many downstream paths; reverse-mode autodiff accumulates all those contributions into one gradient field.

Why reverse mode fits neural nets

Neural networks usually have one scalar loss and many parameters. Reverse mode computes gradients of that one scalar with respect to all parameters in roughly one backward sweep.

Two-phase training iteration. Forward computes layer values and stores both pre-activations and activations; this page writes pre-activation as $z$ and activation as $a$, while some texts use $a_j$ for pre-activation and $z_j$ for unit output. Backward starts from the scalar loss and walks the graph in reverse.
Golden rule. Downstream gradient = local gradient $\times$ upstream gradient. If a value feeds multiple later nodes, add all returned contributions.
Software view. PyTorch builds a dynamic graph during the forward pass, then reverse-mode autodiff traverses it when .backward() is called.

4. Key Equations

Gradient notation
$$ \bar{v}\equiv \frac{\partial L}{\partial v} $$

Symbols. $L$: scalar loss at the end of the computation graph； $v$: any intermediate value or parameter； $\bar v$: gradient of the loss with respect to $v$

How to read it. The bar notation measures blame: how strongly changing this value would change the final loss.

How to use. Run the forward pass first. In the backward pass, initialize $\bar L=1$ and propagate gradients to earlier nodes.

Chain rule on one edge
$$ \bar{x}=\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial x}=\bar{y}\frac{\partial y}{\partial x} $$

Symbols. $\bar y$: upstream gradient arriving from later nodes； $\partial y/\partial x$: local derivative of the current operation； $\bar x$: gradient to pass to the previous value

How to read it. Backprop is just the chain rule organized so every reused partial derivative is computed once.

How to use. At each node, multiply the upstream gradient by the local derivative. Repeat this node by node from the loss back to the inputs and parameters.

Gradient accumulation
$$ \bar{x}=\sum_{j:\,x\to y_j}\bar{y}_j\frac{\partial y_j}{\partial x} $$

Symbols. $x\to y_j$: $x$ feeds into several downstream values $y_j$； $\bar y_j$: gradient contribution arriving from path $j$； $\sum_j$: add contributions from all branches

How to read it. If one value affects the loss through multiple routes, total blame is the sum of blame from every route.

How to use. When a variable branches, add all returned gradients into the same accumulator. In code this is why repeated use of a tensor accumulates into one .grad field.

Output error for canonical losses
$$ \delta_k = y_k-t_k $$

Symbols. $y_k$ is the model output for output unit $k$. $t_k$ is the target value. $\delta_k$ is the output-layer error signal, usually the gradient with respect to the output pre-activation under a matching loss/link pair.

How to read it. For sigmoid or softmax paired with cross-entropy, the scary derivative simplifies to prediction minus target.

How to use. Start the output-layer backward pass with this value, then propagate it into weights and hidden units. Check the sign convention in the problem; some notes define the opposite error.

Hidden unit error
$$ \delta_j = h'(a_j)\sum_k w_{kj}\delta_k $$

Symbols. $a_j$ is hidden unit $j$'s pre-activation. $h'(a_j)$ is the activation derivative. $w_{kj}$ connects hidden unit $j$ to upper-layer unit $k$. $\delta_k$ is the upper-layer error signal.

How to read it. A hidden unit receives blame from every upper unit it affects, then scales that blame by its own activation derivative.

How to use. Sum weighted errors from the next layer first, then multiply by the local derivative. For $\tanh$, use $h'(a)=1-\tanh^2(a)$.

Neuron weight gradient
$$ \frac{\partial E_n}{\partial w_{ji}}=\delta_j z_i $$

Symbols. $E_n$ is the loss for example $n$. $w_{ji}$ connects input unit $i$ to unit $j$. $z_i$ is the input-side activation. $\delta_j$ is the error signal at the receiving unit.

How to read it. A weight changes the loss in proportion to the error at the output end and the activation that entered the weight.

How to use. Once $\delta_j$ is known, multiply it by each incoming activation to get the gradient for each incoming weight.

Affine layer backward pass
$$ z=Wa+b,\qquad g_z=\frac{\partial L}{\partial z} $$
$$ \frac{\partial L}{\partial W}=g_z a^\top,\qquad \frac{\partial L}{\partial b}=g_z,\qquad \frac{\partial L}{\partial a}=W^\top g_z $$

Symbols. $a$: input activation to the layer； $W,b$: weight matrix and bias vector； $z$: pre-activation output； $g_z$: upstream gradient at $z$； $g_z a^\top$: outer product that has the same shape as $W$

How to read it. A weight gradient is upstream error times the input that weight saw. The transpose sends the error signal back to the previous layer.

How to use. Use these formulas for a single example after you know $g_z$. For a mini-batch, compute the same contributions per example and sum or average according to the loss convention.

Batch matrix form
$$ \frac{\partial L}{\partial X}=G_YW^\top,\qquad \frac{\partial L}{\partial W}=X^\top G_Y $$

Symbols. $X$ stores input row vectors for a batch. $Y=XW$ is the affine output. $G_Y=\partial L/\partial Y$ is the upstream gradient matrix.

How to read it. The upstream gradient flows back through $W^\top$, while the weight gradient is an input-transpose times upstream-gradient product.

How to use. This is the row-vector batch version often used in code. Compare shapes before multiplying: $X^\top G_Y$ must match $W$.

ReLU backward pass
$$ a=\operatorname{ReLU}(z),\qquad \frac{\partial L}{\partial z}=\frac{\partial L}{\partial a}\odot \mathbf{1}[z>0] $$

Symbols. $\odot$: elementwise multiplication； $\mathbf{1}[z>0]$: mask that is $1$ where the forward pre-activation was positive and $0$ otherwise； $\partial L/\partial a$: upstream gradient after the ReLU

How to read it. Inactive ReLU units were clipped to zero, so small changes behind them do not affect the output locally.

How to use. Keep the upstream gradient only where ReLU was active in the forward pass. Zero it out where the pre-activation was negative.

5. Worked Examples

Example A · Lecture 10 computational graph

Source: Lecture 10, computation-graph backprop slides. Paraphrased.

Let $c=a+b$, $d=b+1$, and $e=cd$. At $a=3,b=2$, forward gives $c=5$, $d=3$, $e=15$. Backward gives $\partial e/\partial c=d=3$ and $\partial e/\partial d=c=5$. Then $\partial e/\partial a=3$, while $b$ receives two paths: from $c$ and from $d$, so $\partial e/\partial b=3+5=8$.

Example B · HW3 §2.1 shape audit

Source: HW3 §2.1. The problem asks for dimensions in a small two-layer network.

If $x\in\mathbb{R}^{3}$, hidden width is $4$, and the output is scalar, then $W^{(1)}$ is $4\times3$, $b^{(1)}$ is length $4$, $W^{(2)}$ is $1\times4$, and every gradient with respect to a weight has the same shape as that weight.

Example C · HW3 §2.1 numerical backprop

Source: HW3 §2.1. The problem asks for forward values and gradients in a two-layer network.

Compute $z^{(1)}$, apply the ReLU mask to get $a^{(1)}$, then compute the scalar logit and binary cross-entropy gradient. The key matrix forms are $\partial L/\partial W^{(2)}=(\partial L/\partial z^{(2)})a^{(1)\top}$ and $\partial L/\partial W^{(1)}=(\partial L/\partial z^{(1)})x^\top$.

6. Problem-Solving Tips

  • Draw the graph first. Label each intermediate value, not just the final formula.
  • Write the forward values before differentiating; many local gradients need cached values.
  • Move backward one node at a time: upstream gradient times local derivative.
  • For HW3-style MLP calculations, use the order: output error $\delta$, activation local gradient, then weight gradient as error signal times previous activation.
  • For matrix gradients, write shapes before writing formulas.
  • In PyTorch, call optimizer.zero_grad() before a new backward pass because gradients accumulate in .grad.
  • For RNN questions, use BPTT: unroll the RNN through time, then apply the same backprop rules on the unfolded graph.

7. Common Mistakes

  • Forgetting to add gradients when a variable is reused in multiple branches.
  • Confusing elementwise multiplication with matrix multiplication.
  • Dropping a transpose in an outer product gradient.
  • Using the activation derivative at $a$ instead of at the pre-activation $z$.
  • Calling .backward() repeatedly in PyTorch without clearing old gradients.
  • Forgetting that reverse-mode is efficient here because the network has many parameters but one scalar loss.

8. Exam Focus

  • Hand-compute gradients on a small computational graph.
  • Explain what information must be saved during the forward pass.
  • For a two-layer network, compute forward values, masks for ReLU, and gradient shapes.
  • Use the outer-product gradient formulas for affine layers.
  • Recognize $\delta=\hat y-y$ as the canonical output-layer starting point for sigmoid/softmax cross-entropy.
  • Redo HW3 §2.1 until you can compute $z^{(1)}$, $a^{(1)}$, $z^{(2)}$, $\partial L/\partial W^{(2)}$, and $\partial L/\partial W^{(1)}$ without looking.
  • Know that BPTT is ordinary backprop on an unrolled RNN, with repeated products causing vanishing or exploding gradients.

9. Quick Checklist

  • I can explain upstream, local, and downstream gradients.
  • I can handle reused variables by summing gradient contributions.
  • I can start backprop from the output error signal $\delta$.
  • I can verify $\partial L/\partial W$ has the same shape as $W$.
  • I can write affine-layer gradients as outer products.
  • I remember PyTorch gradients accumulate unless I call zero_grad().

🔁 Backpropagation · 反向传播

Backpropagation 就是把 chain rule 做成高效算法。Lecture 10 把它讲成 computation graph 上的 forward pass + backward pass；HW3 给了你必须能手算的二层网络例题。

1. Concept Understanding

训练神经网络是在最小化 loss。梯度下降公式本身很短：$w_{t+1}=w_t-\alpha\nabla_w L(w_t)$；真正麻烦的是大模型里每个 parameter 的 gradient 怎么算。

Backpropagation 是一种 local message-passing algorithm，用来高效计算 feed-forward network 中 error function $E(w)$ 对各个参数的 gradients。它不要求你为每个新 architecture 手推一整套公式，而是把网络拆成小 operation，再在 computation graph 上局部套 chain rule。

  • Computational graph：把变量、参数、中间 tensor、operation 连接成有向无环图。
  • Forward pass：算 prediction / loss，同时缓存 backward 需要的信息。
  • Backward pass：从 loss 的 upstream gradient $1$ 开始，反向应用每个节点的 local derivative。

2. Plain-English Explanation / 大白话理解

可以把 forward 想成每一步操作都留了一张“小票”：这里做了乘法，那里做了 sum，这里过了 ReLU。Backward 就是从最后的 loss 倒着翻小票，问：如果 loss 变大一点点，前面这个数应该背多少锅？

关键习惯很机械：先缓存 forward values，从 loss 开始，倒着一次处理一个 local derivative。

3. Core Intuition

Backprop 高效，是因为它复用中间梯度。一个参数可能通过很多路径影响 loss；reverse-mode autodiff 会把这些路径上的贡献全部累加到同一个 .grad 里。

为什么 neural network 适合 reverse mode

神经网络通常是一个 scalar loss、非常多 parameters。Reverse mode 可以用一次 backward sweep 算出这个 loss 对所有参数的梯度。

Two-phase training iteration： Forward 计算各层数值，并保存 pre-activations 和 activations；本页用 $z$ 表示 pre-activation、$a$ 表示 activation，有些教材会用 $a_j$ 表示 pre-activation、$z_j$ 表示 unit output。Backward 从 scalar loss 开始反向走图。
Golden rule： downstream gradient = local gradient $\times$ upstream gradient。一个值流向多个后续节点时，要把所有 contribution 相加。
Software view： PyTorch 在 forward pass 时动态建立 graph，调用 .backward() 时用 reverse-mode autodiff 反向遍历。

4. 关键公式

Gradient notation：bar 符号怎么读
$$ \bar{v}\equiv \frac{\partial L}{\partial v} $$

符号. $L$: computation graph 最后的 scalar loss；$v$: 任意 intermediate value 或 parameter；$\bar v$: loss 对 $v$ 的 gradient

怎么理解. bar notation 可以理解成 blame：这个值稍微改变，会让最终 loss 改变多少。

怎么用. 先做 forward pass。Backward 时从 $\bar L=1$ 开始，把 gradient 一层层往前传。

单条边上的 chain rule
$$ \bar{x}=\frac{\partial L}{\partial x}=\frac{\partial L}{\partial y}\frac{\partial y}{\partial x}=\bar{y}\frac{\partial y}{\partial x} $$

符号. $\bar y$: 从后面节点传回来的 upstream gradient；$\partial y/\partial x$: 当前这个 operation 的 local derivative；$\bar x$: 继续往前传给 $x$ 的 gradient

怎么理解. Backprop 本质就是 chain rule，只是把重复的 partial derivative 组织起来复用。

怎么用. 每到一个节点，就做 upstream gradient × local derivative。沿着 graph 从 loss 往 input / parameters 一步步倒推。

Gradient accumulation：分叉要相加
$$ \bar{x}=\sum_{j:\,x\to y_j}\bar{y}_j\frac{\partial y_j}{\partial x} $$

符号. $x\to y_j$: $x$ 同时喂给多个 downstream values $y_j$；$\bar y_j$: 第 $j$ 条路径传回来的 gradient contribution；$\sum_j$: 把所有 branch 的 contribution 相加

怎么理解. 一个值如果通过多条路径影响 loss，总责任就是每条路径责任的总和。

怎么用. 变量分叉时，把所有回来的 gradient 都加到同一个 accumulator。代码里的同一个 tensor 被重复使用时，也会累加到同一个 .grad。

Canonical loss 的 output error
$$ \delta_k = y_k-t_k $$

符号. $y_k$ 是第 $k$ 个 output unit 的 prediction；$t_k$ 是 target；$\delta_k$ 是 output layer 的 error signal，通常是 matching loss/link 下对 output pre-activation 的 gradient。

怎么理解. Sigmoid 或 softmax 搭配 cross-entropy 时，复杂 derivative 会简化成 prediction minus target。

怎么用. Output layer backward 从这个值开始，再把它传给 weights 和 hidden units。注意题目/讲义的 sign convention，有些地方会定义成相反方向。

Hidden unit error
$$ \delta_j = h'(a_j)\sum_k w_{kj}\delta_k $$

符号. $a_j$ 是 hidden unit $j$ 的 pre-activation；$h'(a_j)$ 是 activation derivative；$w_{kj}$ 连接 hidden unit $j$ 到上一层的 unit $k$；$\delta_k$ 是上层传回来的 error signal。

怎么理解. Hidden unit 从所有受它影响的上层 units 收到“责任”，再乘上自己的 activation derivative。

怎么用. 先把 next layer 的 weighted errors 求和，再乘 local derivative。若 $h=\tanh$，则 $h'(a)=1-\tanh^2(a)$。

Neuron weight gradient
$$ \frac{\partial E_n}{\partial w_{ji}}=\delta_j z_i $$

符号. $E_n$ 是第 $n$ 个样本的 loss；$w_{ji}$ 连接 input unit $i$ 到 unit $j$；$z_i$ 是 input-side activation；$\delta_j$ 是 receiving unit 的 error signal。

怎么理解. 一个 weight 的 gradient = 输出端 error × 输入端当时给它的 activation。

怎么用. 已知 $\delta_j$ 后，对每条 incoming weight，都乘对应的 input activation $z_i$。

Affine layer 的 backward pass
$$ z=Wa+b,\qquad g_z=\frac{\partial L}{\partial z} $$
$$ \frac{\partial L}{\partial W}=g_z a^\top,\qquad \frac{\partial L}{\partial b}=g_z,\qquad \frac{\partial L}{\partial a}=W^\top g_z $$

符号. $a$: 这一层的 input activation；$W,b$: weight matrix 和 bias vector；$z$: pre-activation output；$g_z$: $z$ 处的 upstream gradient；$g_z a^\top$: outer product，shape 和 $W$ 一样

怎么理解. weight gradient = 上游 error × 这个 weight 当时看到的 input。转置 $W^\top$ 则把 error signal 送回上一层。

怎么用. 已知 $g_z$ 后，单样本直接套这些公式。Mini-batch 时对每个 example 算同样的 contribution，再按 loss 的定义 sum 或 average。

Batch matrix form
$$ \frac{\partial L}{\partial X}=G_YW^\top,\qquad \frac{\partial L}{\partial W}=X^\top G_Y $$

符号. $X$ 存一个 batch 的 row-vector inputs；$Y=XW$ 是 affine output；$G_Y=\partial L/\partial Y$ 是 upstream gradient matrix。

怎么理解. Upstream gradient 通过 $W^\top$ 传回 input；weight gradient 是 input-transpose 乘 upstream-gradient。

怎么用. 这是代码里常见的 row-vector batch 写法。先检查 shapes：$X^\top G_Y$ 必须和 $W$ 同 shape。

ReLU 的 backward pass
$$ a=\operatorname{ReLU}(z),\qquad \frac{\partial L}{\partial z}=\frac{\partial L}{\partial a}\odot \mathbf{1}[z>0] $$

符号. $\odot$: elementwise multiplication；$\mathbf{1}[z>0]$: mask：forward 时 $z$ 为正处为 $1$，否则为 $0$；$\partial L/\partial a$: ReLU 后面传回来的 upstream gradient

怎么理解. 没激活的 ReLU unit 被截成了 $0$，所以局部上它后面的微小变化不会影响输出。

怎么用. forward 时 ReLU 激活的位置保留 upstream gradient；pre-activation 为负的位置直接清零。

5. Worked Examples

Example A · Lecture 10 computational graph

来源：Lecture 10，computation-graph backprop slides，已转述。

设 $c=a+b$，$d=b+1$，$e=cd$。当 $a=3,b=2$，forward 得 $c=5,d=3,e=15$。Backward：$\partial e/\partial c=d=3$，$\partial e/\partial d=c=5$。所以 $\partial e/\partial a=3$；而 $b$ 走了两条路，来自 $c$ 的 $3$ 和来自 $d$ 的 $5$ 要相加，得到 $\partial e/\partial b=8$。

6. Problem-Solving Tips

  • 先画 graph，并给每个 intermediate value 命名。
  • 先算 forward 数值；很多 local derivative 需要 forward cache。
  • Backward 时一次只处理一个节点：upstream gradient × local derivative。
  • HW3 风格 MLP 手算按这个顺序走：output error $\delta$、activation local gradient、再用 error signal × previous activation 得 weight gradient。
  • 矩阵梯度先写 shape，再写公式。
  • PyTorch 里每次新 backward 前先调用 optimizer.zero_grad()，因为 gradients 会累加到 .grad。
  • RNN 题用 BPTT：先把 RNN 按时间展开，再在 unfolded graph 上做同样的 backprop。

7. Common Mistakes

  • 变量被重复使用时，忘记把多条路径的 gradient 相加。
  • 把 elementwise multiplication 和 matrix multiplication 混起来。
  • Outer product gradient 里漏掉 transpose。
  • ReLU derivative 应该看 pre-activation $z$，不是看后面的符号猜。
  • PyTorch 里连续调用 .backward()，却忘记清空旧 gradients。
  • 忘记 reverse-mode 在这里高效，是因为 network 有很多 parameters，但最终只有一个 scalar loss。

8. Exam Focus

  • 会手算小 computational graph 的 gradient。
  • 能说明 forward pass 为什么要保存某些 tensor / shape。
  • 二层网络要会算 forward、ReLU mask、梯度 shape。
  • 会用 affine layer 的 outer-product gradient formula。
  • 看到 sigmoid / softmax cross-entropy，要认出 $\delta=\hat y-y$ 是 output layer 的起点。
  • 重做 HW3 §2.1，直到能不看答案算出 $z^{(1)}$、$a^{(1)}$、$z^{(2)}$、$\partial L/\partial W^{(2)}$ 和 $\partial L/\partial W^{(1)}$。
  • 知道 BPTT 是 unrolled RNN 上的普通 backprop，重复乘积会导致 vanishing / exploding gradients。

9. Quick Checklist

  • 我能解释 upstream / local / downstream gradient。
  • 我知道 reuse variable 时梯度要 sum。
  • 我能从 output error signal $\delta$ 开始做 backprop。
  • 我会检查 $\partial L/\partial W$ 的 shape。
  • 我能把 affine-layer gradients 写成 outer products。
  • 我记得 PyTorch gradients 会累加，更新前要 zero_grad()。

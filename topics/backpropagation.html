🔁 Backpropagation

The chain rule realized efficiently on the computational graph.

Mantra

downstream gradient = local gradient × upstream gradient

Shape check (must-pass exam tool)
$$ \frac{\partial L}{\partial W}\;\text{has the same shape as}\;W $$

If you can't derive a gradient cleanly, write down all tensor shapes and back-solve from the matmul rules.

✅ Exam focus
  • For a two-layer net, compute gradients with respect to each $W^{(l)}, b^{(l)}$ and check shapes.
  • Forward caches $z^{(l)}, a^{(l)}$; backward propagates from the loss back through the graph.

🔁 2. Backpropagation · 反向传播

本质：链式法则在计算图上的高效实现。

核心口令

downstream gradient = local gradient × upstream gradient

必考 · Shape Check
$$ \frac{\partial L}{\partial W}\ \text{must have the same shape as}\ W $$
不会推导时：先写出每个张量 shape，用矩阵乘法规则倒推，常能救命。
✅ Exam focus
  • 给两层网络，能写出对每个 $W^{(l)}, b^{(l)}$ 的梯度（含 shape）。
  • 知道 Forward 缓存 $z^{(l)},a^{(l)}$，Backward 从 loss 逐层回传。

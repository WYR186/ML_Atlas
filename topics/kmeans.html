🎯 K-means Clustering

K-means is the clustering algorithm from Lecture 9. It alternates between assigning points to the closest center and updating each center to the mean of its assigned points.

1. Concept Understanding

K-means is an unsupervised learning method for finding hidden structure in unlabeled data $\mathcal{D}=\{x^{(i)}\}_{i=1}^N$. It partitions the dataset into $K$ disjoint clusters, where each point belongs to exactly one cluster and each cluster is represented by a center $\mu_k$.

The objective is the within-cluster sum of squared Euclidean distances, also called distortion or reconstruction error. The algorithm is simple, but the problem is non-convex, so initialization matters.

2. Plain-English Explanation

Drop $K$ magnets onto the scatter plot. Each point runs to its closest magnet. Then each magnet moves to the average location of the points that chose it. Repeat until nothing changes.

The magnets usually settle down, but where they settle can depend heavily on where you dropped them first.

3. Core Intuition

With centers fixed, the best assignment is obvious: choose the nearest center. With assignments fixed, the best center is also obvious: the arithmetic mean of the assigned points.

Alternating these two easy subproblems monotonically decreases the objective and converges in finitely many assignment changes, but only to a local optimum. This finite convergence comes from the fact that there are only finitely many possible hard assignments.

4. Key Equations

Objective
$$ J^*=\min_{\mu_1,\ldots,\mu_K}\min_{r_{ik}}\sum_{i=1}^N\sum_{k=1}^K r_{ik}\|x^{(i)}-\mu_k\|_2^2 $$
$$ r_{ik}\in\{0,1\},\qquad \sum_k r_{ik}=1 $$

What it does. The objective adds the squared Euclidean distance from every point to the center it chose. The row constraint $\sum_k r_{ik}=1$ says each point picks exactly one cluster.

Assignment step
$$ r_{ik}=1\quad\text{if}\quad k=\arg\min_j\|x^{(i)}-\mu_j\|_2^2 $$

What it does. With centers fixed, every point greedily chooses its nearest center. This is the Lloyd assignment step, often compared to the E-step of EM.

Update step
$$ \mu_k=\frac{\sum_i r_{ik}x^{(i)}}{\sum_i r_{ik}} $$

What it does. With assignments fixed, the squared-distance objective is minimized by placing the center at the arithmetic mean of its assigned points.

Per-iteration cost
$$ O(KNd)\text{ for assignments},\qquad O(Nd)\text{ for means} $$

What it does. The assignment step dominates: each of $N$ points compares against $K$ centers, and each distance costs $O(d)$.

5. Worked Examples

Example A · One Lloyd iteration
Source: Lecture 9, k-means / Lloyd algorithm.

Given initial centers, first compute each point's squared distance to every center and assign it to the closest one. Then average the points inside each cluster to obtain the next centers. That is one iteration.

Example B · Pixel segmentation
Source: Lecture 9, k-means applications.

Pixels can be treated as points in grayscale or color space. Running k-means with $K=2$ or $K=3$ groups pixels into intensity or color clusters, producing a simple segmentation.

Example C · Soft assignment relaxation
Source: HW2 Problem 7, paraphrased.

Relaxing assignment variables from one-hot values to soft weights $r_{ik}\in[0,1]$ with $\sum_k r_{ik}=1$ does not improve the optimum. For fixed centers, a weighted average of distances is at least the minimum distance, so an optimal soft solution can be chosen as a hard nearest-center assignment.

Example D · Prototypes for classification
Source: Lecture 9, supervised use of clustering.

To turn k-means into a classifier, run k-means separately inside each labeled class and keep $R$ prototypes per class. A new point is labeled by the class of its closest prototype, so prediction uses learned centroids rather than all training points.

6. Problem-Solving Tips

For hand iteration, draw a distance table: points by centers.
For initialization, remember the standard version randomly chooses $K$ training points as initial centroids, so multiple restarts are useful.
For the M-step, average only points assigned to that cluster.
For proof questions, use “fix one block, optimize the other block” logic.
For choosing $K$, plot distortion versus $K$ and look for an elbow where the improvement slows down.
For the GMM link, say k-means is the small-variance, hard-assignment limit of an equal spherical Gaussian mixture trained by EM.
For limitations, mention local minima, outliers, choice of $K$, and spherical-cluster bias.

7. Common Mistakes

  • Forgetting every point must be assigned to exactly one cluster in hard k-means.
  • Updating centers before recomputing all assignments for the current iteration.
  • Claiming k-means finds the global optimum.
  • Confusing k-means with KNN. K-means learns $K$ centroids from unlabeled data; KNN stores labeled training examples and predicts from nearest neighbors.
  • Ignoring empty clusters; implementations need a rule for them.

8. Exam Focus

  • Run one or two Lloyd iterations by hand.
  • Write the WCSS objective with assignment variables.
  • Derive the mean update from fixed assignments.
  • Explain convergence to local optimum and sensitivity to initialization.
  • State the per-iteration complexity $O(NKd)$ and why the assignment step dominates.
  • Prove the HW2 hard-vs-soft assignment equivalence.

  • I remember k-means is non-convex and initialization-sensitive.

🎯 K-means · 聚类

K-means 是 Lecture 9 的 clustering algorithm：在“把点分给最近中心”和“把中心更新成簇均值”之间交替，也叫 Lloyd iterations。

1. Concept Understanding · 概念理解

K-means 是 unsupervised learning，用来在 unlabeled data $\mathcal{D}=\{x^{(i)}\}_{i=1}^N$ 中找 hidden structure。它把 dataset 分成 $K$ 个互不重叠的 clusters，每个点只属于一个 cluster，每个 cluster 用 center $\mu_k$ 表示。

目标是最小化 within-cluster squared Euclidean distances，也叫 distortion / reconstruction error。算法很简单，但 objective non-convex，所以 initialization 很重要。

2. Plain-English Explanation · 大白话理解

把 $K$ 块磁铁丢到散点图上。每个点跑向最近的磁铁；然后磁铁移动到选择它的点的平均位置。不断重复，直到没人想换队。

磁铁通常会稳定下来，但稳定在哪，很依赖最开始扔在哪里。

3. Core Intuition · 核心直觉

如果 centers 固定，最优 assignment 很明显：选最近中心。如果 assignments 固定，最优 center 也很明显：取 assigned points 的 arithmetic mean。

交替优化这两个简单子问题会让 objective 单调下降，并在有限次 assignment changes 后收敛；但一般只保证 local optimum。有限收敛的原因是 hard assignments 的可能情况有限。

4. Key Equations · 核心公式

Objective
$$ J^*=\min_{\mu_1,\ldots,\mu_K}\min_{r_{ik}}\sum_{i=1}^N\sum_{k=1}^K r_{ik}\|x^{(i)}-\mu_k\|_2^2 $$
$$ r_{ik}\in\{0,1\},\qquad \sum_k r_{ik}=1 $$

这个公式在做什么？ 这个 objective 把每个点到自己 cluster center 的 squared Euclidean distance 加起来。约束 $\sum_k r_{ik}=1$ 表示每个点必须且只能选一个 cluster。

Assignment step
$$ r_{ik}=1\quad\text{if}\quad k=\arg\min_j\|x^{(i)}-\mu_j\|_2^2 $$

这个公式在做什么？ Centers 固定时，每个点都 greedy 地选最近中心。这就是 Lloyd assignment step，也常类比 EM 里的 E-step。

Update step
$$ \mu_k=\frac{\sum_i r_{ik}x^{(i)}}{\sum_i r_{ik}} $$

这个公式在做什么？ Assignments 固定时，让 squared-distance objective 最小的 center 就是这些点的 arithmetic mean。

Per-iteration cost
$$ O(KNd)\text{ for assignments},\qquad O(Nd)\text{ for means} $$

这个公式在做什么？ Assignment step 最贵：$N$ 个点各自比较 $K$ 个 centers，每次 distance 计算要 $O(d)$。

5. Worked Examples · 代表性例题

Example A · 一轮 Lloyd iteration
来源：Lecture 9，k-means / Lloyd algorithm。

给定初始 centers，先计算每个点到每个 center 的 squared distance，并分给最近中心；再对每个 cluster 内的点求平均，得到新的 centers。这就是一轮 iteration。

Example B · Pixel segmentation
来源：Lecture 9，k-means applications。

把 pixels 看成 grayscale 或 color space 里的 points。用 $K=2$ 或 $K=3$ 运行 k-means，就能把图像分成几个 intensity / color clusters，得到简单 segmentation。

Example C · Soft assignment relaxation
来源：HW2 Problem 7，题意转述。

把 assignment variables 从 one-hot 放宽到 soft weights $r_{ik}\in[0,1]$ 且 $\sum_k r_{ik}=1$ 不会让 optimum 更好。固定 centers 时，距离的 weighted average 至少是最小距离，所以最优 soft solution 可以取成 nearest-center hard assignment。

Example D · 用 prototypes 做 classification
来源：Lecture 9，clustering 的 supervised 用法。

如果要把 k-means 用于 classification，可以在每个 labeled class 内分别跑 k-means，每类保留 $R$ 个 prototypes。新点预测时找最近 prototype，并输出该 prototype 所属的 class。

6. Problem-Solving Tips · 解题技巧

手跑 iteration： 画 distance table，行是 points，列是 centers。
Initialization： 标准版本随机从 training data 里选 $K$ 个点当 initial centroids，所以 multiple restarts 很有用。
M-step： 只平均分给该 cluster 的点。
证明题： 用“固定一组变量，优化另一组变量”的 alternate optimization 逻辑。
选择 $K$： 画 distortion vs. $K$，找下降速度明显变慢的 elbow。
GMM 关联： k-means 可看成 equal spherical GMM 用 EM 训练时，variance $\sigma^2\to0$ 的 hard-assignment 极限。
局限性： local minima、outliers、选择 $K$、spherical-cluster bias。

7. Common Mistakes · 常见错误

  • 忘记 hard k-means 中每个点必须 exactly one cluster。
  • 在同一轮中还没算完所有 assignments 就先更新 centers。
  • 声称 k-means 保证 global optimum。
  • 把 k-means 和 KNN 混淆：K-means 从 unlabeled data 学 centroids；KNN 保存 labeled training examples，用 nearest neighbors 预测。
  • 忽略 empty clusters；实际实现需要处理规则。

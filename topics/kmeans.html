🎯 K-means Clustering

K-means is the clustering algorithm from Lecture 9. It alternates between assigning points to the closest center and updating each center to the mean of its assigned points.

1. Concept Understanding

K-means partitions unlabeled data into $K$ clusters. It assumes each point belongs to exactly one cluster and each cluster is represented by a center $\mu_k$.

The objective is the within-cluster sum of squared distances. The algorithm is simple, but the problem is non-convex, so initialization matters.

2. Plain-English Explanation

Drop $K$ magnets onto the scatter plot. Each point runs to its closest magnet. Then each magnet moves to the average location of the points that chose it. Repeat until nothing changes.

The magnets usually settle down, but where they settle can depend heavily on where you dropped them first.

3. Core Intuition

With centers fixed, the best assignment is obvious: choose the nearest center. With assignments fixed, the best center is also obvious: the arithmetic mean of the assigned points.

Alternating these two easy subproblems monotonically decreases the objective and converges in finitely many assignment changes, but only to a local optimum.

4. Key Equations

Objective
$$ J=\sum_{i=1}^n\sum_{k=1}^K r_{ik}\|x^{(i)}-\mu_k\|_2^2 $$
$$ r_{ik}\in\{0,1\},\qquad \sum_k r_{ik}=1 $$
Assignment step
$$ r_{ik}=1\quad\text{if}\quad k=\arg\min_j\|x^{(i)}-\mu_j\|_2^2 $$

Nearest center wins.

Update step
$$ \mu_k=\frac{\sum_i r_{ik}x^{(i)}}{\sum_i r_{ik}} $$

Center becomes the cluster mean.

Per-iteration cost
$$ O(KNd)\text{ for assignments},\qquad O(Nd)\text{ for means} $$

$N$ points, dimension $d$, $K$ clusters.

5. Worked Examples

Example A · One Lloyd iteration
Source: Lecture 9, k-means / Lloyd algorithm.

Given initial centers, first compute each point's squared distance to every center and assign it to the closest one. Then average the points inside each cluster to obtain the next centers. That is one iteration.

Example B · Pixel segmentation
Source: Lecture 9, k-means applications.

Pixels can be treated as points in grayscale or color space. Running k-means with $K=2$ or $K=3$ groups pixels into intensity or color clusters, producing a simple segmentation.

Example C · Soft assignment relaxation
Source: HW2 Problem 7, paraphrased.

Relaxing assignment variables from one-hot values to $[0,1]$ does not improve the optimum. For fixed centers, a weighted average of distances is at least the minimum distance, so an optimal soft solution can be chosen as a hard nearest-center assignment.

6. Problem-Solving Tips

For hand iteration, draw a distance table: points by centers.
For the M-step, average only points assigned to that cluster.
For proof questions, use “fix one block, optimize the other block” logic.
For limitations, mention local minima, outliers, choice of $K$, and spherical-cluster bias.

7. Common Mistakes

  • Forgetting every point must be assigned to exactly one cluster in hard k-means.
  • Updating centers before recomputing all assignments for the current iteration.
  • Claiming k-means finds the global optimum.
  • Ignoring empty clusters; implementations need a rule for them.

8. Exam Focus

  • Run one or two Lloyd iterations by hand.
  • Write the WCSS objective with assignment variables.
  • Derive the mean update from fixed assignments.
  • Explain convergence to local optimum and sensitivity to initialization.
  • Prove the HW2 hard-vs-soft assignment equivalence.

9. Quick Checklist

  • I know the assignment step.
  • I know the mean update step.
  • I can write the objective and constraints.
  • I remember k-means is non-convex and initialization-sensitive.
  • I can explain why squared Euclidean distance favors spherical clusters.

🎯 K-means · 聚类

K-means 是 Lecture 9 的 clustering algorithm：在“把点分给最近中心”和“把中心更新成簇均值”之间交替，也叫 Lloyd iterations。

1. Concept Understanding · 概念理解

K-means 把 unlabeled data 分成 $K$ 个 clusters。每个点只属于一个 cluster，每个 cluster 用 center $\mu_k$ 表示。

目标是最小化 within-cluster sum of squared distances。算法很简单，但 objective non-convex，所以 initialization 很重要。

2. Plain-English Explanation · 大白话理解

把 $K$ 块磁铁丢到散点图上。每个点跑向最近的磁铁；然后磁铁移动到选择它的点的平均位置。不断重复，直到没人想换队。

磁铁通常会稳定下来，但稳定在哪，很依赖最开始扔在哪里。

3. Core Intuition · 核心直觉

如果 centers 固定，最优 assignment 很明显：选最近中心。如果 assignments 固定，最优 center 也很明显：取 assigned points 的 arithmetic mean。

交替优化这两个简单子问题会让 objective 单调下降，并在有限次 assignment changes 后收敛；但一般只保证 local optimum。

4. Key Equations · 核心公式

Objective
$$ J=\sum_{i=1}^n\sum_{k=1}^K r_{ik}\|x^{(i)}-\mu_k\|_2^2 $$
$$ r_{ik}\in\{0,1\},\qquad \sum_k r_{ik}=1 $$
Assignment step
$$ r_{ik}=1\quad\text{if}\quad k=\arg\min_j\|x^{(i)}-\mu_j\|_2^2 $$

最近中心获胜。

Update step
$$ \mu_k=\frac{\sum_i r_{ik}x^{(i)}}{\sum_i r_{ik}} $$

中心变成 cluster mean。

Per-iteration cost
$$ O(KNd)\text{ for assignments},\qquad O(Nd)\text{ for means} $$

$N$ 个点，dimension $d$，$K$ 个 clusters。

5. Worked Examples · 代表性例题

Example A · 一轮 Lloyd iteration
来源：Lecture 9，k-means / Lloyd algorithm。

给定初始 centers，先计算每个点到每个 center 的 squared distance，并分给最近中心；再对每个 cluster 内的点求平均，得到新的 centers。这就是一轮 iteration。

Example B · Pixel segmentation
来源：Lecture 9，k-means applications。

把 pixels 看成 grayscale 或 color space 里的 points。用 $K=2$ 或 $K=3$ 运行 k-means，就能把图像分成几个 intensity / color clusters，得到简单 segmentation。

Example C · Soft assignment relaxation
来源：HW2 Problem 7，题意转述。

把 assignment variables 从 one-hot 放宽到 $[0,1]$ 不会让 optimum 更好。固定 centers 时，距离的 weighted average 至少是最小距离，所以最优 soft solution 可以取成 nearest-center hard assignment。

6. Problem-Solving Tips · 解题技巧

手跑 iteration： 画 distance table，行是 points，列是 centers。
M-step： 只平均分给该 cluster 的点。
证明题： 用“固定一组变量，优化另一组变量”的 alternate optimization 逻辑。
局限性： local minima、outliers、选择 $K$、spherical-cluster bias。

7. Common Mistakes · 常见错误

  • 忘记 hard k-means 中每个点必须 exactly one cluster。
  • 在同一轮中还没算完所有 assignments 就先更新 centers。
  • 声称 k-means 保证 global optimum。
  • 忽略 empty clusters；实际实现需要处理规则。

8. Exam Focus · 考试重点

  • 会手跑一两轮 Lloyd iterations。
  • 会用 assignment variables 写 WCSS objective。
  • 会从 fixed assignments 推 mean update。
  • 能解释 local optimum 和 initialization sensitivity。
  • 会证明 HW2 的 hard-vs-soft assignment equivalence。

  • 我能写 objective 和 constraints。
  • 我记得 k-means non-convex 且依赖 initialization。
  • 我能解释 squared Euclidean distance 为什么偏向 spherical clusters。

🧭 Bayes Classifier & Bayes Error

  • Bayes error $\epsilon_\mu^*$ — the minimum achievable test error, set by the data's intrinsic noise.
  • Bayes classifier — the classifier that achieves it.
Binary 0–1 loss · $\eta(x)=\mathbb{P}(Y=1\mid X=x)$
$$ f_{\text{Bayes}}(x)=\begin{cases}1,&\eta(x)\ge \tfrac{1}{2}\\ 0,&\eta(x)<\tfrac{1}{2}\end{cases} $$
Regression · squared loss
$$ f_{\text{Bayes}}(x)=\mathbb{E}[Y\mid X=x] $$
🧩 Sanity check

If $\eta(x) = 0.3 < 0.5$, the Bayes classifier predicts 0.

🧭 2. Bayes Error / Bayes Classifier

  • Bayes Error $\epsilon_\mu^*$：任何分类器都无法突破的最小测试误差下界（数据固有噪声）。
  • Bayes Classifier：达到该下界的最优分类器。
二分类 0-1 loss 下的 Bayes 决策（$\eta(x)=\mathbb{P}(Y=1\mid X=x)$）
$$ f_{\text{Bayes}}(x)=\begin{cases}1,&\eta(x)\ge \tfrac{1}{2}\\ 0,&\eta(x)<\tfrac{1}{2}\end{cases} $$
回归（平方损失）下
$$ f_{\text{Bayes}}(x)=\mathbb{E}[Y\mid X=x] $$
🧩 Example

$\eta(x)=0.3<0.5$ ⇒ Bayes 分类器预测 $0$。

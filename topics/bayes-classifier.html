Bayes Classifier and Bayes Error

Lecture 21 starts learning theory by asking what error is unavoidable even before we choose KNN, SVM, trees, or neural networks. The answer is the Bayes error: the best possible test error allowed by the data distribution itself.

1. Concept Understanding

The Bayes classifier is the decision rule that minimizes population 0-1 classification error. It is the theoretical gold standard for predictive performance: if a model cannot beat it, no classifier can. It knows the true conditional probability $\eta(x)=\Pr(Y=1\mid X=x)$, so at each $x$ it simply predicts the more likely label.

The Bayes error $\epsilon_\mu^*$ is the error achieved by that ideal classifier. It depends only on the unknown distribution $\mu$, not on the learning algorithm or sample size.

  • If labels are deterministic given $x$, the Bayes error can be 0.
  • If labels are pure coin flips at every $x$, the Bayes error is 0.5 in binary classification.
  • In practice we do not know $\mu$, so Bayes error is a theoretical benchmark, not a directly computable training objective.

2. Plain-English Explanation

Imagine asking the universe for the answer key. Even with the answer key, some examples are genuinely ambiguous: the same feature value may sometimes produce label 0 and sometimes label 1.

Bayes error is the price of that ambiguity. It is not the model being lazy; it is the data refusing to be perfectly predictable.

3. Core Intuition

For a fixed $x$, the best classifier should make the cheaper local mistake. If $\Pr(Y=1\mid X=x)=0.8$, predicting 1 makes error 0.2, while predicting 0 makes error 0.8. So the local optimal rule is majority vote under the true conditional distribution.

This separates two questions:

  • Distribution noise: even the Bayes classifier may make errors.
  • Learning error: our actual algorithm may fail to approach the Bayes classifier.
Connections to familiar models
Naive Bayes: a generative model that tries to approximate the Bayes decision rule by estimating class priors and likelihoods, then adding a conditional-independence assumption.
KNN: nearest-neighbor methods are judged against the Bayes error floor; a classical result says the asymptotic 1-NN error is at most twice the Bayes rate.
Regression: the squared-loss version of the same idea appears below: the Bayes predictor is the conditional expectation $\mathbb{E}[Y\mid X]$.

4. Key Equations

Binary Bayes rule

$$ f_{\text{Bayes}}(x)=\begin{cases}1,&\eta(x)\ge \frac12\\0,&\eta(x)<\frac12\end{cases},\qquad \eta(x)=\Pr(Y=1\mid X=x) $$

Symbols. $X$ is the random input; $x$ is one observed feature value. $Y\in\{0,1\}$ is the true label. $\eta(x)=\Pr(Y=1\mid X=x)$ is the posterior probability of class 1 after seeing $x$. $f_{\text{Bayes}}(x)$ is the prediction made by the optimal rule.

How to read it. The threshold $\frac12$ is majority vote under uncertainty: predict 1 if class 1 is at least as likely as class 0. This rule minimizes 0-1 loss pointwise; for each fixed $x$, choosing the larger posterior leaves the smaller posterior as the unavoidable local error.

How to use. Compute or compare $\Pr(Y=1\mid X=x)$ and $\Pr(Y=0\mid X=x)=1-\eta(x)$. If $\eta(x)=0.73$, predict 1; if $\eta(x)=0.41$, predict 0.

Bayes error

$$ \epsilon_\mu^*=\mathbb{E}_X\left[\min\{\eta(X),1-\eta(X)\}\right] $$

Symbols. $\epsilon_\mu^*$ is the smallest possible true error under data distribution $\mu$. $\mathbb{E}_X[\cdot]$ averages over the marginal distribution of $X$. $\min\{\eta(X),1-\eta(X)\}$ picks the probability of the class the Bayes rule does not predict.

How to read it. This is "average unavoidable mistake." Near $\eta(X)=0$ or $1$, the label is almost certain, so local error is small. Near $\eta(X)=0.5$, the classes are intrinsically ambiguous, so even the best classifier often fails.

How to use. For discrete $X$, sum $\Pr(X=x)\min\{\eta(x),1-\eta(x)\}$ over all $x$. For continuous $X$, replace the sum with an integral against the density of $X$.

Equivalent binary form

$$ \epsilon_\mu^*=\frac12-\frac12\mathbb{E}_X\left[|2\eta(X)-1|\right] $$

Symbols. $|2\eta(X)-1|$ is a confidence margin away from a coin flip. If $\eta(X)=0.5$, the margin is 0; if $\eta(X)=0$ or $1$, the margin is 1.

How to read it. Start from the worst local binary uncertainty, $\frac12$, then subtract certainty. More posterior confidence means a larger absolute-value term, hence lower Bayes error.

How to use. This form is handy when a problem gives posterior confidence or asks for algebraic reasoning. It matches the min form because for any $p\in[0,1]$, $\min(p,1-p)=\frac12-\frac12|2p-1|$.

Squared-loss regression

$$ f_{\text{Bayes}}(X)=\mathbb{E}[Y\mid X],\qquad \epsilon_\mu^*=\mathbb{E}\operatorname{Var}(Y\mid X) $$

Symbols. $f_{\text{Bayes}}(X)$ is the best prediction under squared loss. $\mathbb{E}[Y\mid X]$ is the conditional mean: the average value of $Y$ among examples with the same input. $\operatorname{Var}(Y\mid X)$ is the remaining randomness after $X$ is known.

How to read it. Under squared loss, the best single summary of a conditional distribution is its mean. Any noise left around that mean is not learnable from $X$, so its conditional variance becomes Bayes error.

How to use. Identify the predictable part as the conditional mean. Then compute or read off the conditional variance; averaging it gives the irreducible squared-loss error.

One-line workflow
Prediction: choose the larger posterior probability.
Local error: take the smaller posterior probability.
Total Bayes error: average the local error over the distribution of $X$.

5. Worked Examples

Example 1 · Label flipping noise

Source: Lecture 21, p. 11.

Suppose a true linear separator gives a correct label, then the label is flipped with probability $p<0.5$. At every $x$, the true label has probability $1-p$ and the flipped label has probability $p$. The Bayes classifier uses the original separator, and the Bayes error is $p$.

Example 2 · Regression with additive Gaussian noise

Source: Lecture 21, p. 13.

If $Y=w^{*\top}X+\epsilon$ with $\epsilon\sim\mathcal{N}(0,\delta^2)$ independent of $X$, then $\mathbb{E}[Y\mid X]=w^{*\top}X$ and $\operatorname{Var}(Y\mid X)=\delta^2$. The Bayes error under squared loss is therefore $\delta^2$.

Example 3 · Two Gaussian classes

Source: HW5, Section 1.2.

With $X\mid Y=0\sim\mathcal{N}(-\mu,\sigma^2)$, $X\mid Y=1\sim\mathcal{N}(\mu,\sigma^2)$, and prior $\lambda=\Pr(Y=1)$, compare likelihood times prior. Taking log posterior odds gives a linear threshold:

$$ \tau=-\frac{\sigma^2}{2\mu}\log\!\left(\frac{\lambda}{1-\lambda}\right) $$

Predict class 1 when $x\ge \tau$. Here $\tau$ is the boundary, $\mu$ is the symmetric class mean magnitude, $\sigma^2$ is the shared variance, and $\lambda$ is the class-1 prior. If $\lambda>0.5$, then $\tau$ moves left, so the classifier favors class 1.

6. Problem-Solving Tips

  1. For classification, compute or reason about $\Pr(Y=y\mid X=x)$.
  2. Choose the class with the largest posterior probability.
  3. For Bayes error, integrate or average the probability of the wrong label under the Bayes decision.
  4. For Gaussian class-conditionals, compare log posterior odds and solve for the threshold.
  5. For regression with squared loss, look for $\mathbb{E}[Y\mid X]$ and $\operatorname{Var}(Y\mid X)$.

7. Common Mistakes

  • Confusing Bayes classifier with Naive Bayes. Bayes classifier is the ideal optimal rule; Naive Bayes is a modeling algorithm with an independence assumption.
  • Trying to estimate Bayes error from training error directly. Bayes error is defined using the true distribution.
  • Forgetting priors in the Gaussian example; posterior comparison uses likelihood times prior.
  • Thinking Bayes error can exceed 0.5 in binary classification under the optimal rule.

8. Exam Focus

  • State the binary Bayes classifier using $\eta(x)$ and the 0.5 threshold.
  • Write $\epsilon_\mu^*=\mathbb{E}\min\{\eta(X),1-\eta(X)\}$.
  • Explain why Bayes error measures irreducible noise.
  • Derive the Gaussian threshold from log posterior odds.
  • For regression, know $f_{\text{Bayes}}(X)=\mathbb{E}[Y\mid X]$ and Bayes error $\mathbb{E}\operatorname{Var}(Y\mid X)$.
  • Compare Bayes classifier with Naive Bayes and KNN at the concept level.

9. Quick Checklist

  • Posterior above 0.5 predicts class 1.
  • Local Bayes error is the smaller posterior probability.
  • Deterministic labels give Bayes error 0.
  • Pure random binary labels give Bayes error 0.5.
  • Shared-variance Gaussian class-conditionals give a linear threshold.
  • Bayes error is a lower bound, not a training algorithm.

Bayes Classifier 与 Bayes Error

Lecture 21 先问一个很底层的问题：在讨论 KNN、SVM、tree、neural network 谁更好之前，数据本身允许的最低错误率是多少？这个最低理论下界就是 Bayes error。

1. Concept Understanding · 概念理解

Bayes classifier 是在真实分布下最小化 0-1 分类错误的理想规则，也是 predictive performance 的理论 gold standard：如果它都做不到，任何 classifier 都做不到。它知道 $\eta(x)=\Pr(Y=1\mid X=x)$，所以每个 $x$ 上都预测 posterior probability 更大的类别。

Bayes error $\epsilon_\mu^*$ 是这个理想分类器仍然会犯的错误。它只由数据分布 $\mu$ 决定，不由算法、模型大小、训练集大小决定。

  • 如果 $x$ 完全决定 label，Bayes error 可以是 0。
  • 如果每个 $x$ 上 label 都像抛硬币，二分类 Bayes error 是 0.5。
  • 实际中我们不知道 $\mu$，所以 Bayes error 是 benchmark，不是可以直接训练的 objective。

2. Plain-English Explanation · 大白话理解

可以把 Bayes classifier 想成“上帝视角分类器”：它知道某个 $x$ 下 0 和 1 各有多大概率。

但即使有上帝视角，有些样本也是真的模糊：同一个特征位置可能 80% 是 1、20% 是 0。你预测 1 已经最合理，但那 20% 还是会错。这 20% 就是数据本身的噪声。

3. Core Intuition · 核心直觉

在固定 $x$ 上，最优策略就是选“局部犯错概率更小”的类别。如果 $\Pr(Y=1\mid X=x)=0.8$，预测 1 的错率是 0.2，预测 0 的错率是 0.8。

所以 Bayes error 把问题拆开：

  • distribution noise：数据本身不可预测的部分。
  • learning error：我们的模型没有学到理想规则的部分。
和常见模型的关系
Naive Bayes: 是一种 generative model，通过估计 prior 和 likelihood 来近似 Bayes rule，但额外假设 features conditionally independent given label。
KNN: nearest-neighbor 方法通常拿 Bayes error 当理论下界；经典结论是样本无限多时，1-NN 的错误率不超过 Bayes rate 的两倍。
Regression: 同一个 Bayes optimal 思想在 squared loss 下变成下面的公式：最优 predictor 是 conditional expectation $\mathbb{E}[Y\mid X]$。

4. Key Equations · 关键公式

二分类 Bayes rule

$$ f_{\text{Bayes}}(x)=\begin{cases}1,&\eta(x)\ge \frac12\\0,&\eta(x)<\frac12\end{cases},\qquad \eta(x)=\Pr(Y=1\mid X=x) $$

符号：$X$ 是输入特征 random variable；$x$ 是一个具体观测到的 feature value。$Y\in\{0,1\}$ 是真实 label。$\eta(x)=\Pr(Y=1\mid X=x)$ 表示看到 $x$ 之后 class 1 的 posterior probability；$f_{\text{Bayes}}(x)$ 是 optimal rule 给出的预测。

怎么理解：$\frac12$ 阈值就是 uncertainty 下的 majority vote：class 1 至少和 class 0 一样可能，就预测 1。它是在 0-1 loss 下逐点最优的 classifier；固定一个 $x$ 后，选 posterior 更大的类，较小 posterior 就是 unavoidable local error。

怎么用：比较 $\Pr(Y=1\mid X=x)$ 和 $\Pr(Y=0\mid X=x)=1-\eta(x)$。例如 $\eta(x)=0.73$ 就预测 1；$\eta(x)=0.41$ 就预测 0。

Bayes error

$$ \epsilon_\mu^*=\mathbb{E}_X\left[\min\{\eta(X),1-\eta(X)\}\right] $$

符号：$\epsilon_\mu^*$ 是真实分布 $\mu$ 下能达到的最小 true error。$\mathbb{E}_X[\cdot]$ 表示按 $X$ 的 marginal distribution 做平均。$\min\{\eta(X),1-\eta(X)\}$ 选的是 Bayes rule 没有预测的那个 label 的概率。

怎么理解：它是“平均不可避免错误”。Posterior 接近 0 或 1 时标签很确定，local error 小；接近 0.5 时类别本身模糊，最优 classifier 也容易错。

怎么用：如果 $X$ 是离散的，就算 $\sum_x \Pr(X=x)\min\{\eta(x),1-\eta(x)\}$；如果 $X$ 连续，就把求和换成对 $X$ density 的 integral。

等价形式

$$ \epsilon_\mu^*=\frac12-\frac12\mathbb{E}_X\left[|2\eta(X)-1|\right] $$

符号：$|2\eta(X)-1|$ 是离“抛硬币”有多远的 confidence margin。若 $\eta(X)=0.5$，margin 为 0；若 $\eta(X)=0$ 或 $1$，margin 为 1。

怎么理解：从最糟的二分类不确定性 $\frac12$ 出发，再减去 certainty。Posterior 越确定，绝对值项越大，Bayes error 越低。

怎么用：题目如果给的是 posterior 的确定程度，或需要做代数化简，用这个形式更顺手。它与 min 形式等价，因为任意 $p\in[0,1]$ 都有 $\min(p,1-p)=\frac12-\frac12|2p-1|$。

平方损失回归

$$ f_{\text{Bayes}}(X)=\mathbb{E}[Y\mid X],\qquad \epsilon_\mu^*=\mathbb{E}\operatorname{Var}(Y\mid X) $$

符号：$f_{\text{Bayes}}(X)$ 是 squared loss 下的最优预测函数；$\mathbb{E}[Y\mid X]$ 是 conditional mean，即给定同一个输入 $X$ 时 $Y$ 的平均值；$\operatorname{Var}(Y\mid X)$ 是知道 $X$ 后仍然剩下的随机波动。

怎么理解：Squared loss 下，一个条件分布最好的单点代表是 mean。围绕 mean 剩下的随机噪声无法从 $X$ 学出来，所以它的 conditional variance 成为 Bayes error。

怎么用：先找 conditional mean 作为预测；再计算或读出 conditional variance，对它取平均就是不可消除的 squared-loss error。

一行解题流程
Prediction: 选更大的 posterior probability。
Local error: 取较小的 posterior probability。
Total Bayes error: 对 $X$ 的分布做 average / integrate。

5. Worked Examples · 代表性例题

例 1 · label flipping noise

出处：Lecture 21, p. 11。

真实线性分隔器先给出正确 label，然后以概率 $p<0.5$ 翻转。每个 $x$ 上正确 label 概率是 $1-p$，错误 label 概率是 $p$。Bayes classifier 仍然用原来的分隔器，Bayes error 是 $p$。

例 2 · 回归中的 Gaussian noise

出处：Lecture 21, p. 13。

若 $Y=w^{*\top}X+\epsilon$，且 $\epsilon\sim\mathcal{N}(0,\delta^2)$ 与 $X$ 独立，则 $\mathbb{E}[Y\mid X]=w^{*\top}X$，$\operatorname{Var}(Y\mid X)=\delta^2$。平方损失下 Bayes error 就是 $\delta^2$。

例 3 · 两个 Gaussian class

出处：HW5, Section 1.2。

若 $X\mid Y=0\sim\mathcal{N}(-\mu,\sigma^2)$，$X\mid Y=1\sim\mathcal{N}(\mu,\sigma^2)$，并且 $\lambda=\Pr(Y=1)$，做法是比较 likelihood × prior。取 log posterior odds 后得到线性 threshold：

$$ \tau=-\frac{\sigma^2}{2\mu}\log\!\left(\frac{\lambda}{1-\lambda}\right) $$

当 $x\ge\tau$ 时预测 class 1。这里 $\tau$ 是 decision boundary，$\mu$ 是对称均值的大小，$\sigma^2$ 是 shared variance，$\lambda$ 是 class 1 prior。若 $\lambda>0.5$，$\tau$ 会向左移动，所以 classifier 更偏向预测 class 1。

6. Problem-Solving Tips · 解题技巧

  1. 分类题先找 $\Pr(Y=y\mid X=x)$，不要只看 likelihood。
  2. 二分类用 $\eta(x)$ 与 0.5 比较。
  3. 求 Bayes error 时，对 Bayes decision 下的错误概率做 expectation。
  4. Gaussian class-conditionals 通常取 log posterior odds，再解 threshold。
  5. 平方损失回归先找 conditional mean，再找 conditional variance。

7. Common Mistakes · 常见错误

  • 把 Bayes classifier 和 Naive Bayes 混在一起。前者是理想最优规则，后者是带 independence assumption 的具体算法。
  • 用 training error 直接当 Bayes error。Bayes error 是真实分布下的理论量。
  • Gaussian 例题忘记 prior，导致 class imbalance 下 threshold 错位。
  • 以为二分类 Bayes error 可以大于 0.5；最优规则至少可以选多数类。

8. Exam Focus · 考试重点

  • 会用 $\eta(x)$ 和 0.5 threshold 写 Bayes classifier。
  • 会写 $\epsilon_\mu^*=\mathbb{E}\min\{\eta(X),1-\eta(X)\}$。
  • 会解释 Bayes error 是 irreducible noise。
  • 会从 log posterior odds 推 Gaussian threshold。
  • 回归题记住 $f_{\text{Bayes}}(X)=\mathbb{E}[Y\mid X]$ 与 $\mathbb{E}\operatorname{Var}(Y\mid X)$。
  • 能从概念上区分 Bayes classifier、Naive Bayes 和 KNN。

9. Quick Checklist · 速记清单

  • posterior 超过 0.5 预测 class 1。
  • 局部 Bayes error = 较小 posterior probability。
  • deterministic label ⇒ Bayes error 0。
  • 纯随机二分类 label ⇒ Bayes error 0.5。
  • shared-variance Gaussian class-conditionals ⇒ linear threshold。
  • Bayes error 是 lower bound，不是算法。

🔄 Recurrent Neural Networks

  • Same parameters processed at every time step.
  • Hidden state $h^{(t)}$ summarizes information up to time $t$.
  • BPTT: unroll over time, then run standard backprop on the resulting deep graph.
💥 Core challenge

Long sequences repeatedly multiply by the same recurrent weight, so gradients either vanish or explode.

🔄 4. RNN · 循环神经网络

  • 参数共享：同一组参数处理每个时间步。
  • 隐藏状态 $h^{(t)}$ 作为“记忆”，汇总到时间 $t$ 的信息。
  • BPTT：把 RNN 在时间上 unroll 成深网络再做标准 backprop。
💥 核心挑战

长序列中反复乘同一权重矩阵 → 梯度消失 / 爆炸（vanishing / exploding gradients）。

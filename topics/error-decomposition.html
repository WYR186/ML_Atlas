🧩 Error Decomposition

Three components
$$ \epsilon_\mu(f) = \underbrace{(\epsilon_\mu(f)-\inf_{f'\in\mathcal{F}}\epsilon_\mu(f'))}_{\text{Estimation}} + \underbrace{(\inf_{f'\in\mathcal{F}}\epsilon_\mu(f')-\epsilon_\mu^*)}_{\text{Approximation}} + \underbrace{\epsilon_\mu^*}_{\text{Bayes}} $$
  • Bayes — irreducible noise.
  • Approximation — $\mathcal{F}$ is too weak to express the optimal function.
  • Estimation — finite samples means we don't fit the best function in $\mathcal{F}$.
✅ Exam focus (multiple-choice gold)
  • "More data helps?" → reduces estimation only.
  • "Bigger model helps?" → reduces approximation; may inflate estimation if data is fixed.
  • Overfitting = estimation / generalization gap blowing up.

🧩 3. Error Decomposition

三部分分解
$$ \epsilon_\mu(f) = \underbrace{\big(\epsilon_\mu(f)-\inf_{f'\in\mathcal{F}}\epsilon_\mu(f')\big)}_{\text{Estimation}} + \underbrace{\big(\inf_{f'\in\mathcal{F}}\epsilon_\mu(f')-\epsilon_\mu^*\big)}_{\text{Approximation}} + \underbrace{\epsilon_\mu^*}_{\text{Bayes}} $$
  • Bayes Error：数据本身噪声（不可消除）。
  • Approximation Error：$\mathcal{F}$ 太弱，表达不了最优函数。
  • Estimation Error：样本有限导致学得不准。
✅ Exam focus（高频选择题）
  • “加数据是否有用？” → 只影响 Estimation。
  • “换更强模型是否有用？” → 主要影响 Approximation（但 Estimation 风险可能上升）。
  • 过拟合本质：估计误差 / 泛化间隙变大（模型复杂度过高但数据不足）。

🔁 Value & Policy Iteration

Value iteration

Repeatedly apply the Bellman optimality operator:

$$ Q^{(t)}(s,a)=R(s,a)+\gamma\,\mathbb{E}_{s'}\!\left[\max_{a'}Q^{(t-1)}(s',a')\right] $$

Policy iteration (alternating)

  1. Policy evaluation: solve for $V^\pi$ (linear system or iterative).
  2. Policy improvement: make $\pi$ greedy with respect to $V^\pi$.
✅ Exam focus

DP requires knowing $P$ and $R$. Common follow-up: "Why hard in practice?" → unknown dynamics or huge state space.

🔁 4. DP · Value / Policy Iteration（model-known）

Value Iteration

反复套用 Bellman 最优算子：

$$ Q^{(t)}(s,a)=R(s,a)+\gamma\,\mathbb{E}_{s'}\!\left[\max_{a'}Q^{(t-1)}(s',a')\right] $$

Policy Iteration（两步交替）

  1. 策略评估：求 $V^\pi$（解线性方程或迭代近似）。
  2. 策略改进：令策略对 $V$ 贪婪。
✅ Exam focus

DP 需要已知 $P$ 和 $R$。常考“为什么现实中难用？” → 模型未知 / 状态空间巨大。

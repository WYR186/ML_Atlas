🪄 Kernel Methods

Kernel methods extend the SVM dual from Lecture 7: instead of explicitly mapping data into a larger feature space, compute the inner product in that space through a kernel function.

1. Concept Understanding

A feature map $\phi(x)$ can make a nonlinear pattern linearly separable in a lifted space. Kernel methods use a function $k(x,x')$ that equals $\phi(x)^\top\phi(x')$ without explicitly building $\phi(x)$.

This solves a practical problem: the useful feature space may be huge or even infinite-dimensional, but the SVM dual only needs pairwise inner products.

2. Plain-English Explanation

Think of a kernel as a shortcut for comparing two objects after a secret transformation. You never draw the transformed objects; you only ask, “How similar would they look after that transformation?”

For XOR, the original 2D picture is not linearly separable. After adding the interaction feature $x_1x_2$, the pattern becomes separable by a simple plane.

3. Core Intuition

The SVM dual depends on data only through $x_i^\top x_j$. If we replace $x$ by $\phi(x)$, every dot product becomes $\phi(x_i)^\top\phi(x_j)$. Kernel trick says: compute that number directly as $k(x_i,x_j)$.

Polynomial kernels add interaction features. RBF kernels measure local similarity: nearby points have large kernel values, far points have values near zero. Smaller bandwidth makes the classifier more local and more flexible.

4. Key Equations

Kernel definition
$$ k(x,x')=\phi(x)^\top\phi(x') $$

Symbols. $x$ and $x'$ are two inputs; $\phi$ is the feature map into a possibly high-dimensional space; $k(x,x')$ is the similarity value computed without explicitly forming $\phi(x)$.

How to read it. A kernel is not just any similarity score: it must equal an inner product in some feature space, which is why it can safely replace dot products in algorithms like SVM.

How to use. Whenever a dual algorithm contains $\phi(x_i)^\top\phi(x_j)$, compute $k(x_i,x_j)$ instead. This is the kernel trick.

Kernelized SVM prediction
$$ f(x)=\sum_i\alpha_i y_i\,k(x_i,x)+b $$

Symbols. $x$ is the test point; $x_i$ are training points; $y_i$ are labels; $\alpha_i$ are dual weights; $b$ is the intercept.

How to read it. The prediction is a weighted vote from training examples. Each support vector compares itself to the test point through $k(x_i,x)$, then votes with sign $y_i$ and strength $\alpha_i$.

How to use. In practice, terms with $\alpha_i=0$ disappear. For a new $x$, compute its kernel similarity to support vectors, sum the weighted votes, add $b$, then take $\mathrm{sign}(f(x))$.

Polynomial kernel
$$ k(x,x')=(1+x^\top x')^d $$

Symbols. $x^\top x'$ is the ordinary dot product; $d$ is the polynomial degree; the constant 1 adds lower-order and bias-like terms.

How to read it. Expanding the power creates interaction features up to degree $d$. For $d=2$, the feature space includes constants, linear terms, squares, and pairwise products.

How to use. For explicit feature-map questions, expand the polynomial and match each term to one coordinate of $\phi(x)$. Keep scaling factors such as $\sqrt2$ so the dot product matches exactly.

RBF / Gaussian kernel
$$ k_\sigma(x,x')=\exp\!\left(-\frac{\|x-x'\|_2^2}{2\sigma^2}\right) $$

Symbols. $\|x-x'\|_2^2$ is squared Euclidean distance; $\sigma$ is bandwidth; the exponential converts distance into similarity between 0 and 1.

How to read it. If two points are identical, distance is 0 and the kernel is 1. As distance grows, the exponential shrinks toward 0. Small $\sigma$ makes the shrinkage faster.

How to use. Compare distances first. With small $\sigma$, nearest support vectors dominate; with large $\sigma$, many points have similar influence and the boundary becomes smoother.

XOR lifting from Lecture 7
$$ \phi(x_1,x_2)=(x_1,x_2,x_1x_2) $$

Symbols. $x_1,x_2$ are the original two coordinates; $x_1x_2$ is the new interaction feature that records whether the signs of the coordinates agree.

How to read it. XOR is hard in the original plane because diagonal classes cannot be separated by one line. The interaction coordinate sends same-sign points to one side and opposite-sign points to the other.

How to use. For XOR-style questions, compute $x_1x_2$ for each point. A linear classifier using this third coordinate can separate the classes.

5. Worked Examples

Example A · XOR becomes linear after lifting
Source: Lecture 7, XOR feature-map slides.

Map $(x_1,x_2)$ to $(x_1,x_2,x_1x_2)$. The two points with equal signs have $x_1x_2=+1$, and the two points with opposite signs have $x_1x_2=-1$. A classifier using only the third coordinate can separate them.

Example B · Explicit quadratic feature map
Source: HW2 Problem 3.4, paraphrased.

For $k(x,x')=(1+x^\top x')^2$, expand the square. The feature vector contains a constant term, scaled linear terms $\sqrt2 x_i$, square terms $x_i^2$, and scaled cross terms $\sqrt2 x_i x_j$ for $i<j$.

Example C · RBF as nearest-support-vector behavior
Source: HW2 Problem 3.3, paraphrased.

As $\sigma\to0$, the RBF term for the closest support vectors decays slowest. After factoring out the closest-distance term, all farther support-vector contributions vanish, so the prediction behaves like a weighted nearest-neighbor rule over support vectors.

6. Problem-Solving Tips

When you see an SVM dual, scan for inner products; those are exactly the slots kernels replace.
For polynomial kernels, expand small degrees by hand and match terms to coordinates of $\phi(x)$.
For RBF questions, compare distances. The smallest distance dominates when $\sigma$ is small.
For intuition questions, say “linear in feature space, nonlinear in original input space.”

7. Common Mistakes

  • Thinking a kernel always requires explicitly writing $\phi(x)$. The whole point is often to avoid it.
  • Mixing the two RBF parameterizations: $\exp(-\|x-x'\|^2/(2\sigma^2))$ versus $\exp(-\gamma\|x-x'\|^2)$.
  • Forgetting that not every similarity function is a valid kernel; it must correspond to a positive semidefinite Gram matrix.
  • Saying kernel SVM is linear in the original input space. It is linear only after the feature map.

8. Exam Focus

  • Explain the kernel trick from the SVM dual.
  • Write polynomial and RBF kernel formulas.
  • Construct small explicit feature maps, especially quadratic kernels.
  • Explain the role of $\sigma$ or $\gamma$ in RBF kernels.
  • Connect small-bandwidth RBF behavior to nearest-neighbor intuition.

9. Quick Checklist

  • I can say what $k(x,x')$ represents.
  • I can kernelize $f(x)=\sum_i\alpha_i y_i x_i^\top x+b$.
  • I know the XOR feature map from Lecture 7.
  • I can expand $(1+x^\top x')^2$ into feature coordinates.
  • I can explain why small $\sigma$ makes RBF more local.

🪄 Kernel Methods · 核方法

Kernel methods 是 Lecture 7 接在 SVM dual 后面的自然升级：不显式构造高维 feature map，只用 kernel function 直接算那个高维空间里的 inner product。

1. Concept Understanding · 概念理解

Feature map $\phi(x)$ 可以把原本 nonlinear 的图形 lift 到更高维，让它在 feature space 里 linear separable。Kernel method 用 $k(x,x')$ 表示 $\phi(x)^\top\phi(x')$，但不用真的写出 $\phi(x)$。

它解决的问题是：有用的 feature space 可能非常大，甚至 infinite-dimensional；但 SVM dual 只需要 pairwise inner products。

2. Plain-English Explanation · 大白话理解

Kernel 就像一个“秘密变身后的相似度计算器”。你不用把点真的变身到高维，只问：如果变身之后，这两个点有多像？

对 XOR 来说，原始二维图怎么画直线都分不开；加上 $x_1x_2$ 这个 interaction feature 后，对角关系立刻变成一刀能切开的结构。

3. Core Intuition · 核心直觉

SVM dual 中数据只通过 $x_i^\top x_j$ 出现。若把 $x$ 换成 $\phi(x)$，所有 dot product 都变成 $\phi(x_i)^\top\phi(x_j)$。Kernel trick 就是直接用 $k(x_i,x_j)$ 代替这个数。

Polynomial kernel 会加入 interaction features；RBF kernel 更像 local similarity：距离近 kernel 大，距离远 kernel 接近 0。Bandwidth 越小，边界越局部、越灵活。

4. Key Equations · 核心公式

Kernel definition
$$ k(x,x')=\phi(x)^\top\phi(x') $$

符号. $x,x'$ 是两个输入；$\phi$ 是 feature map，可能映射到很高维；$k(x,x')$ 是不显式构造 $\phi(x)$ 时直接算出来的 similarity value。

怎么理解. Kernel 不是随便一个相似度；它必须等于某个 feature space 里的 inner product，所以才能安全替换 SVM 里的 dot product。

怎么用. 只要 dual algorithm 出现 $\phi(x_i)^\top\phi(x_j)$，就直接算 $k(x_i,x_j)$。这就是 kernel trick。

Kernelized SVM prediction
$$ f(x)=\sum_i\alpha_i y_i\,k(x_i,x)+b $$

符号. $x$ 是 test point；$x_i$ 是 training points；$y_i$ 是 labels；$\alpha_i$ 是 dual weights；$b$ 是 intercept。

怎么理解. Prediction 是 training examples 的 weighted vote。每个 support vector 通过 $k(x_i,x)$ 和 test point 比相似度，再用 $y_i$ 给方向、$\alpha_i$ 给权重。

怎么用. $\alpha_i=0$ 的项直接消失。对新点 $x$，只算它和 support vectors 的 kernel similarity，加权求和后加 $b$，最后看 $\mathrm{sign}(f(x))$。

Polynomial kernel
$$ k(x,x')=(1+x^\top x')^d $$

符号. $x^\top x'$ 是普通 dot product；$d$ 是 polynomial degree；常数 1 会加入 lower-order 和 bias-like terms。

怎么理解. 展开幂次后，会出现最高到 degree $d$ 的 interaction features。$d=2$ 时有常数、线性项、平方项和 pairwise products。

怎么用. 显式 feature map 题就把 polynomial 展开，把每一项对应到 $\phi(x)$ 的一个坐标；注意 $\sqrt2$ 这类 scaling，保证内积完全匹配。

RBF / Gaussian kernel
$$ k_\sigma(x,x')=\exp\!\left(-\frac{\|x-x'\|_2^2}{2\sigma^2}\right) $$

符号. $\|x-x'\|_2^2$ 是 squared Euclidean distance；$\sigma$ 是 bandwidth；exponential 把 distance 转成 0 到 1 的 similarity。

怎么理解. 两点完全相同距离为 0，kernel = 1；距离越远，kernel 越接近 0。$\sigma$ 越小，衰减越快。

怎么用. 先比较 distances。$\sigma$ 小时，最近 support vectors dominate；$\sigma$ 大时，很多点都有相近影响，boundary 更 smooth。

XOR lifting from Lecture 7
$$ \phi(x_1,x_2)=(x_1,x_2,x_1x_2) $$

符号. $x_1,x_2$ 是原始两个坐标；$x_1x_2$ 是新 interaction feature，记录两个坐标的符号是否一致。

怎么理解. XOR 在原平面不能一条直线分开，因为类别在对角线上；interaction coordinate 会把同号点和异号点送到不同侧。

怎么用. 遇到 XOR 类题，先算每个点的 $x_1x_2$。只用第三个坐标就能构造 linear classifier 分开类别。

5. Worked Examples · 代表性例题

Example A · XOR lift 后变线性
来源：Lecture 7，XOR feature-map slides。

把 $(x_1,x_2)$ 映射成 $(x_1,x_2,x_1x_2)$。同号点的 $x_1x_2=+1$，异号点的 $x_1x_2=-1$。只看第三个坐标就能线性分开。

Example B · Quadratic kernel 的显式 feature map
来源：HW2 Problem 3.4，题意转述。

对 $k(x,x')=(1+x^\top x')^2$ 展开。$\phi(x)$ 包含常数项、$\sqrt2 x_i$ 线性项、$x_i^2$ 平方项，以及 $i<j$ 的 $\sqrt2 x_i x_j$ cross terms。

Example C · RBF 小 bandwidth 像 nearest support vector
来源：HW2 Problem 3.3，题意转述。

当 $\sigma\to0$，离测试点最近的 support vectors 衰减最慢。把最近距离那一项提出后，更远的 support vectors 都趋近 0，所以 prediction 近似只看最近 support vectors 的加权标签。

6. Problem-Solving Tips · 解题技巧

看到 SVM dual： 先找 inner products，它们就是可以替换成 kernel 的位置。
Polynomial kernel： 小 degree 直接展开，逐项对应 $\phi(x)$ 的坐标。
RBF 题： 比较 distances；$\sigma$ 很小时最近距离 dominates。
直觉解释： 记住一句话：feature space 里 linear，original input space 里 nonlinear。

7. Common Mistakes · 常见错误

  • 以为 kernel 一定要显式写出 $\phi(x)$；很多时候它就是为了避免显式写。
  • 混淆 RBF 两种参数：$\exp(-\|x-x'\|^2/(2\sigma^2))$ 和 $\exp(-\gamma\|x-x'\|^2)$。
  • 忘记不是所有 similarity function 都是 valid kernel；对应的 Gram matrix 要 positive semidefinite。
  • 说 kernel SVM 在原空间是 linear；它只是在 feature space 里 linear。

8. Exam Focus · 考试重点

  • 会写 polynomial kernel 和 RBF kernel。
  • 会构造小型 explicit feature map，尤其 quadratic kernel。
  • 能解释 RBF 里 $\sigma$ 或 $\gamma$ 的作用。
  • 能把 small-bandwidth RBF 和 nearest-neighbor intuition 连起来。

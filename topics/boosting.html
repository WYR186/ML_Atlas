🚀 Boosting · AdaBoost

Boosting is the sequential ensemble idea at the end of Lecture 8. AdaBoost builds a strong classifier by repeatedly adding weak classifiers that focus on the examples the current ensemble handles poorly.

1. Concept Understanding

AdaBoost maintains weights over training examples. Initially all examples are equally weighted. After each weak classifier, examples that were misclassified receive more weight, so the next weak learner pays more attention to them.

The final classifier is an additive vote $F_T(x)=\sum_t \alpha_t f_t(x)$, where more accurate weak learners receive larger voting weights.

2. Plain-English Explanation

Boosting is like a tutor who keeps a mistake notebook. Every time you miss a type of question, that question gets circled, highlighted, and shown again in the next practice round.

Easy examples fade into the background; hard examples get louder. The final decision is a weighted committee of all the small tutors.

3. Core Intuition

Bagging reduces variance by averaging independent learners. Boosting reduces bias by combining weak learners sequentially, each one correcting the current ensemble's weak spots.

AdaBoost can be derived from minimizing exponential loss. The sample weights are exactly the loss-induced emphasis on examples with low or negative margins $y_iF(x_i)$.

4. Key Equations

Additive ensemble
$ F_t(x)=F_{t-1}(x)+\alpha_t f_t(x) $

Symbols. $F_t(x)$ is the ensemble score after round $t$. $F_{t-1}(x)$ is the previous score. $f_t(x)$ is the weak learner added at round $t$. $\alpha_t$ is its voting weight.

How to read it. Boosting builds the final classifier one weak learner at a time. Each new term nudges the current score toward fixing current mistakes.

How to use. Update the score after each round, then predict with $\operatorname{sign}(F_T(x))$ for binary $\{-1,+1\}$ labels.

Exponential loss
$ L(F)=\frac1m\sum_{i=1}^m \exp(-y_iF(x_i)) $

Symbols. $m$ is the number of training examples. $y_i\in\{-1,+1\}$ is the true label. $F(x_i)$ is the ensemble score. $y_iF(x_i)$ is the margin: positive means correct with confidence, negative means wrong.

How to read it. Exponential loss punishes low or negative margins heavily, so badly handled examples dominate the next round.

How to use. If $y_iF(x_i)<0$, the example is misclassified and $\exp(-y_iF(x_i))$ is large. Those examples get more attention.

Example weights
$ w_i=\exp(-y_iF_{t-1}(x_i)) $

Symbols. $w_i$ is the weight of training example $i$ before round $t$. $F_{t-1}$ is the ensemble before adding $f_t$. A larger $w_i$ means the next weak learner should care more about that example.

How to read it. The weight is an exponential transform of the current margin. Poorly classified points receive large weights.

How to use. Train the next weak classifier using these weights, so it focuses on examples the previous ensemble handled poorly.

Classifier coefficient
$ \alpha_t^*=\frac12\log\frac{1-\epsilon_t}{\epsilon_t} $

Symbols. $\epsilon_t$ is the weighted error of weak learner $t$. $\alpha_t$ is its coefficient in the ensemble. The logarithm compares correct weighted mass $1-\epsilon_t$ against mistaken mass $\epsilon_t$.

How to read it. Better weak learners get larger positive voting weights. A learner with error $0.5$ gets weight $0$, because it is no better than random guessing.

How to use. Compute weighted error, plug into the log formula, then use $\alpha_t$ in the ensemble update. If $\epsilon_t<0.5$, $\alpha_t>0$.

Weight update after round $t$
$ w_i^{(t+1)}\propto w_i^{(t)}\exp\!\left(-\alpha_t y_i f_t(x_i)\right) $

Symbols. $w_i^{(t)}$ is the old sample weight. $\alpha_t$ is the classifier weight. $y_if_t(x_i)$ equals $+1$ for a correct prediction and $-1$ for a mistake. $\propto$ means normalize afterward so weights sum to 1.

How to read it. Correct predictions are multiplied by $e^{-\alpha_t}$ and shrink. Mistakes are multiplied by $e^{\alpha_t}$ and grow.

How to use. Update every sample weight, normalize, then train the next weak learner on the new weighted dataset.

5. Worked Examples

Example A · Lecture 8 boosting scheme
Source: Lecture 8, boosting slide.

Start with a uniform distribution over data. Ask a weak learning oracle for a classifier. Reweight examples where the ensemble is bad. Repeat. This is the high-level AdaBoost loop.

Example B · Why weights focus on mistakes
Source: HW2 Problem 5.2(a-b), paraphrased.

The new loss factors as $w_i\exp(-\alpha_t y_i f_t(x_i))$, where $w_i=\exp(-y_iF_{t-1}(x_i))$. If the current ensemble gets example $i$ wrong, $y_iF_{t-1}(x_i)<0$, so $w_i$ becomes large.

Example C · Deriving the best $\alpha_t$
Source: HW2 Problem 5.2(d-e), paraphrased.

For a fixed weak classifier, the loss becomes proportional to $(1-\epsilon)e^{-\alpha}+\epsilon e^\alpha$. Setting the derivative to zero gives $e^{2\alpha}=(1-\epsilon)/\epsilon$, hence $\alpha^*=\frac12\log((1-\epsilon)/\epsilon)$.

6. Problem-Solving Tips

Identify boosting by: sequential training, reweighted examples, and weighted votes.
When deriving AdaBoost, split sums into correct and incorrect predictions.
Interpret $\alpha_t$ by error: if $\epsilon<0.5$, then $\alpha_t>0$; if $\epsilon=0.5$, it contributes nothing.
For comparison questions, mention boosting's noise sensitivity.

7. Common Mistakes

  • Calling boosting parallel. It is sequential because later learners depend on earlier mistakes.
  • Forgetting the weak learner is chosen using weighted error, not plain error.
  • Assuming a classifier with $\epsilon>0.5$ should be trusted as-is. It should be flipped or rejected.
  • Ignoring noisy labels: boosting can chase them because their weights keep growing.

8. Exam Focus

  • Explain the AdaBoost loop from weights to weak learner to reweighting.
  • Derive the factorized exponential loss.
  • Derive $\alpha_t^*=\frac12\log((1-\epsilon_t)/\epsilon_t)$.
  • Compare bagging and boosting cleanly.

🚀 Boosting · AdaBoost

Boosting 是 Lecture 8 末尾的 sequential ensemble 思想。AdaBoost 通过不断加入 weak classifiers，专门修正当前 ensemble 处理不好的样本，最后组成 strong classifier。

1. Concept Understanding · 概念理解

AdaBoost 会维护 training examples 的 weights。初始时每个样本同权；每加入一个 weak classifier，被错分的样本权重变大，下一轮 weak learner 会更关注它们。

最终 classifier 是 additive vote：$F_T(x)=\sum_t \alpha_t f_t(x)$。更准确的 weak learner 会有更大的 voting weight。

2. Plain-English Explanation · 大白话理解

Boosting 像一个拿着错题本的老师。你错过的题会被圈出来、加粗、下一轮继续练。

简单样本慢慢退到背景里；难样本声音越来越大。最后的判断来自一组小老师的 weighted committee。

3. Core Intuition · 核心直觉

Bagging 通过 averaging independent learners 降低 variance；Boosting 通过 sequential correction 降低 bias，让每个新 learner 盯着当前 ensemble 的弱点。

AdaBoost 可以从 exponential loss 推出来。Sample weights 本质上是在强调 margin $y_iF(x_i)$ 小或为负的样本。

4. Key Equations · 核心公式

Additive ensemble
$ F_t(x)=F_{t-1}(x)+\alpha_t f_t(x) $

符号. $F_t(x)$ 是第 $t$ 轮后的 ensemble score；$F_{t-1}(x)$ 是加入新 learner 前的 score；$f_t(x)$ 是第 $t$ 个 weak learner；$\alpha_t$ 是它的 voting weight。

怎么理解. Boosting 是一轮一轮往当前 score 里加 weak learner，每一轮都在修补当前 ensemble 的薄弱点。

怎么用. 每轮更新 score，二分类 $\{-1,+1\}$ 时最后用 $\operatorname{sign}(F_T(x))$ 做 prediction。

Exponential loss
$ L(F)=\frac1m\sum_{i=1}^m \exp(-y_iF(x_i)) $

符号. $m$ 是 training examples 数量；$y_i\in\{-1,+1\}$ 是真实 label；$F(x_i)$ 是 ensemble score；$y_iF(x_i)$ 是 margin，正值表示分类正确且有信心，负值表示错分。

怎么理解. Exponential loss 会特别惩罚 margin 小或为负的样本，所以这些样本会主导下一轮学习。

怎么用. 如果 $y_iF(x_i)<0$，样本被错分，$\exp(-y_iF(x_i))$ 会很大；下一轮就要更关注它。

Example weights
$ w_i=\exp(-y_iF_{t-1}(x_i)) $

符号. $w_i$ 是第 $i$ 个样本在第 $t$ 轮前的 weight；$F_{t-1}$ 是加入新 learner 前的 ensemble；weight 越大，下一轮越需要关心这个样本。

怎么理解. Weight 是当前 margin 的 exponential transform。当前分得越差，weight 越大。

怎么用. 用这些 weights 训练下一轮 weak classifier，让它更努力处理之前分错或低置信度的样本。

Classifier coefficient
$ \alpha_t^*=\frac12\log\frac{1-\epsilon_t}{\epsilon_t} $

符号. $\epsilon_t$ 是第 $t$ 个 weak learner 的 weighted error；$\alpha_t$ 是它在 ensemble 里的 coefficient；log 里比较的是正确权重质量 $1-\epsilon_t$ 和错误权重质量 $\epsilon_t$。

怎么理解. Weak learner 越准，$\alpha_t$ 越大。若 $\epsilon_t=0.5$，它和 random guess 差不多，所以 $\alpha_t=0$。

怎么用. 先算 weighted error，再代入 log 公式，把 $\alpha_t$ 放进 ensemble update。若 $\epsilon_t<0.5$，则 $\alpha_t>0$。

Weight update after round $t$
$ w_i^{(t+1)}\propto w_i^{(t)}\exp\!\left(-\alpha_t y_i f_t(x_i)\right) $

符号. $w_i^{(t)}$ 是旧 sample weight；$\alpha_t$ 是 classifier weight；$y_if_t(x_i)=+1$ 表示预测正确，$-1$ 表示预测错误；$\propto$ 表示更新后还要 normalize。

怎么理解. 预测正确时权重乘 $e^{-\alpha_t}$ 变小；预测错误时权重乘 $e^{\alpha_t}$ 变大。

怎么用. 更新所有 sample weights，normalize 到总和为 1，再训练下一轮 weak learner。

5. Worked Examples · 代表性例题

Example A · Lecture 8 boosting scheme
来源：Lecture 8，boosting slide。

从 uniform distribution over data 开始；调用 weak learning oracle 得到一个 classifier；把当前 ensemble 表现差的样本 reweight；重复这个过程。这就是 AdaBoost 的高层循环。

Example B · 为什么 weights 会关注错题
来源：HW2 Problem 5.2(a-b)，题意转述。

新 loss 可分解成 $w_i\exp(-\alpha_t y_i f_t(x_i))$，其中 $w_i=\exp(-y_iF_{t-1}(x_i))$。如果当前 ensemble 把样本 $i$ 分错，$y_iF_{t-1}(x_i)<0$，所以 $w_i$ 变大。

Example C · 推出最优 $\alpha_t$
来源：HW2 Problem 5.2(d-e)，题意转述。

固定 weak classifier 后，loss 正比于 $(1-\epsilon)e^{-\alpha}+\epsilon e^\alpha$。令导数为 0 得 $e^{2\alpha}=(1-\epsilon)/\epsilon$，所以 $\alpha^*=\frac12\log((1-\epsilon)/\epsilon)$。

6. Problem-Solving Tips · 解题技巧

识别 boosting： sequential training、reweighted examples、weighted votes。
推 AdaBoost： 把 sum 拆成 correct predictions 和 incorrect predictions 两部分。
解释 $\alpha_t$： 若 $\epsilon<0.5$，则 $\alpha_t>0$；若 $\epsilon=0.5$，它基本没贡献。
比较题： 一定提 boosting 对 noise 更敏感。

7. Common Mistakes · 常见错误

  • 把 boosting 说成 parallel；它是 sequential，因为后一轮依赖前一轮错误。
  • 忘记 weak learner 是按 weighted error 选择，不是 plain error。
  • 以为 $\epsilon>0.5$ 的 classifier 可以直接信任；通常要 flip 或 reject。
  • 忽略 noisy labels：boosting 会反复追着它们，因为它们的 weights 不断变大。

8. Exam Focus · 考试重点

  • 能推导 factorized exponential loss。
  • 能推导 $\alpha_t^*=\frac12\log((1-\epsilon_t)/\epsilon_t)$。
  • 能清楚比较 bagging 和 boosting。

Policy Gradient

1. Concept Understanding

Directly optimize a parameterized policy

Policy gradient maximizes expected trajectory reward by differentiating the policy parameters $\theta$ of $\pi_\theta(a\mid s)$. Instead of first learning an optimal Q-table, it asks: how should we change the policy so high-reward actions become more likely?

Lecture 25 derives vanilla policy gradient / REINFORCE. Lecture 27 then extends the same idea to actor-critic, PPO, and LLM reinforcement learning. These practical algorithms are marked in the PPT as not covered in exam, but they explain how modern RL systems are trained.

2. Plain-English Explanation

Reward good sampled behavior

If a sampled trajectory gets high reward, increase the log-probability of the actions that produced it. If it performs poorly, do not reinforce those actions as much.

Actor-critic adds a coach: the critic estimates whether an action was better than expected, so the actor does not overreact to noisy total rewards.

3. Core Intuition

Why log-probability appears

The environment sampling process is not directly differentiable. The log-derivative trick uses $\nabla P(\tau)=P(\tau)\nabla\log P(\tau)$, so the gradient can be written in terms of $\nabla\log\pi_\theta(a_t\mid s_t)$, which is differentiable.

PPO keeps policy-gradient updates from changing the policy too violently. GRPO, in Lecture 27, removes the learned value model and estimates advantages by comparing multiple completions for the same prompt.

4. Key Equations

Policy-gradient objective
$$ J(\theta)=\mathbb{E}_{\tau\sim P^{\pi_\theta}}[R(\tau)] $$

Symbols. J(θ): policy objective； θ: policy parameters； τ ~ P^{π_θ}: trajectory sampled by policy and environment； R(τ): trajectory return

How to read it. The objective is expected trajectory reward under the current parameterized policy.

How to use. Use it as the starting point for REINFORCE/policy-gradient derivations: differentiate J with respect to θ.

Monte-Carlo estimator
$$ \nabla_\theta J(\theta)\approx \frac1N\sum_{i=1}^{N}R(\tau_i)\sum_{t=0}^{H}\nabla_\theta\log\pi_\theta(a_t^i\mid s_t^i) $$

Symbols. N: number of sampled trajectories； R(τ_i): return of trajectory i； ∇θ log πθ(a_t^i|s_t^i): direction changing probability of sampled action； H: trajectory horizon

How to read it. Estimate the gradient from sampled trajectories: high-return trajectories increase log-probability of the actions they took.

How to use. Use this when rollouts are available but the environment is not differentiable. Average N trajectories to reduce noise.

Advantage version
$$ \nabla J\approx \mathbb{E}[A^\pi(s_t,a_t)\nabla_\theta\log\pi_\theta(a_t\mid s_t)] $$

Symbols. A^π(s_t,a_t): advantage of action a_t； ∇θ log πθ: policy score gradient； E: expectation over sampled states/actions

How to read it. Replace raw return by advantage so actions are reinforced only when they are better than expected for that state.

How to use. Use this in actor-critic and PPO-style algorithms to reduce variance and stabilize updates.

Advantage definition
$$ A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s) $$

Symbols. Q^π(s,a): value after taking action a； V^π(s): average value of state s； A^π(s,a): extra value above/below baseline

How to read it. Advantage compares an action to the state baseline: positive means better than average, negative worse.

How to use. Use it as the policy-gradient weight: increase probability for positive advantage and reduce reinforcement for negative advantage.

LLM policy
$$ \pi_\theta(a_t\mid s_t)=P_\theta(y_t\mid x,y_{1:t-1}) $$

Symbols. x: prompt/input； y_{1:t-1}: tokens generated so far； y_t: next token/action； Pθ: model probability under θ

How to read it. In LLM RL, the state is prompt plus previous tokens, and the action is the next token.

How to use. Use this mapping to translate RL formulas to language models: πθ(a_t|s_t) becomes probability of token y_t.

Log-derivative trick
$$ \nabla J=\int P_\theta(\tau)R(\tau)\nabla\log P_\theta(\tau)\,d\tau,\qquad \nabla\log P_\theta(\tau)=\sum_t\nabla\log\pi_\theta(a_t\mid s_t) $$

Symbols. Pθ(τ): trajectory probability under θ； ∇log Pθ(τ): score function of trajectory probability； Σ_t ∇log πθ(a_t|s_t): sum of policy log-prob gradients； R(τ): trajectory return weighting the update

How to read it. This moves the gradient from the sampling probability into a log-probability gradient that the policy network can compute.

How to use. Use it to derive policy gradient: write ∇P=P∇logP; environment transitions drop out if they do not depend on θ.

5. Worked Examples

Example 1 · Log-derivative derivation (HW5 §4.1)

Write $J=\int P_\theta(\tau)R(\tau)d\tau$. Then $\nabla J=\int P_\theta(\tau)R(\tau)\nabla\log P_\theta(\tau)d\tau$. In an MDP, only policy terms depend on $\theta$, so $\nabla\log P_\theta(\tau)=\sum_t\nabla\log\pi_\theta(a_t|s_t)$.

Example 2 · Actor-critic advantage (Lecture 27, p. 10-11)

If $Q(s,a)=12$ and $V(s)=9$, the advantage is $3$: the action was better than average. If $Q(s,a)=7$, advantage is $-2$: discourage it relative to the state baseline.

Example 3 · GRPO for LLM completions (Lecture 27, p. 16-18)

For one prompt, sample several completions. Compare their rewards inside the group: completions that beat the group average get positive relative advantage; worse completions get negative relative advantage. This avoids training a separate value model.

6. Problem-Solving Tips

How to approach policy-gradient questions
  1. Start from $J(\theta)=\mathbb{E}_{\tau}[R(\tau)]$.
  2. Use $\nabla P=P\nabla\log P$.
  3. Drop environment dynamics from the gradient if they do not depend on $\theta$.
  4. Replace full returns by $Q$, advantage, or a baseline when discussing variance reduction.
  5. For LLM RL, map policy to next-token distribution and reward to final answer correctness.

7. Common Mistakes

Frequent traps
  • Calling vanilla policy gradient off-policy; it needs fresh samples from the current policy.
  • Forgetting the log in $\nabla\log\pi$.
  • Differentiating the environment transition when it does not depend on $\theta$.
  • Using an action-dependent baseline and claiming it is automatically unbiased.
  • Ignoring PPO's reason for clipping: repeated updates on the same trajectories can destroy the policy.

8. Exam Focus

What matters most
  • Core exam: policy-gradient objective, log-derivative trick, on-policy nature, baseline idea.
  • Lecture 27 practical context: actor-critic reduces variance with advantage; PPO limits destructive updates; LLM-as-MDP uses token actions; GRPO compares completions for the same prompt.
  • The PPT explicitly marks actor-critic, PPO, LLM RL, RLVR, and GRPO as not covered in exam.

9. Quick Checklist

Last-minute recall

  • $J(\theta)=E[R(\tau)]$.
  • $\nabla J\approx R(\tau)\sum_t\nabla\log\pi(a_t|s_t)$.
  • On-policy: collect trajectories from current policy.
  • Advantage = $Q-V$; lowers variance.
  • PPO clips policy updates; GRPO uses group-relative rewards.
  • LLM action = next token; reward can be verifiable correctness.

策略梯度

1. 概念理解

直接优化参数化策略

Policy gradient 通过对策略 $\pi_\theta(a\mid s)$ 的参数 $\theta$ 求梯度，最大化期望轨迹奖励。它不一定先学最优 Q 表，而是直接问：怎样改变策略，让高回报动作更容易被采样？

Lecture 25 推导 vanilla policy gradient / REINFORCE；Lecture 27 继续把这个想法扩展到 actor-critic、PPO 和 LLM 强化学习。PPT 标注这些 practical algorithms 不在考试范围，但它们解释了现代 RL 系统怎么训练。

2. 大白话理解

奖励好的采样行为

如果某条采样轨迹回报高，就提高这条轨迹上动作的 log-probability；如果表现差，就少强化这些动作。

Actor-critic 多了一个“教练”：critic 估计某个动作是否比预期更好，避免 actor 被噪声很大的总回报带偏。

3. 核心直觉

为什么会出现 log-probability

环境采样过程通常不能直接对策略参数求导。Log-derivative trick 用 $\nabla P(\tau)=P(\tau)\nabla\log P(\tau)$，把梯度写到可微的 $\nabla\log\pi_\theta(a_t\mid s_t)$ 上。

PPO 的作用是限制 policy-gradient 更新不要太暴力。Lecture 27 中 GRPO 则去掉 learned value model，通过比较同一个 prompt 的多个 completions 来估计 advantages。

4. 关键公式

Policy-gradient 目标
$$ J(\theta)=\mathbb{E}_{\tau\sim P^{\pi_\theta}}[R(\tau)] $$

符号. J(θ): 策略目标函数；θ: 策略参数；τ ~ P^{π_θ}: 由策略和环境采样出的轨迹；R(τ): 整条轨迹回报

怎么理解. 目标是在当前参数化策略下，让采样 trajectory 的期望回报最大。

怎么用. 推导 REINFORCE / policy gradient 时从这里开始：对 θ 求梯度。

Monte-Carlo 估计
$$ \nabla_\theta J(\theta)\approx \frac1N\sum_{i=1}^{N}R(\tau_i)\sum_{t=0}^{H}\nabla_\theta\log\pi_\theta(a_t^i\mid s_t^i) $$

符号. N: 采样轨迹数量；R(τ_i): 第 i 条轨迹回报；∇θ log πθ(a_t^i|s_t^i): 改变该采样动作概率的梯度方向；H: 轨迹长度

怎么理解. 用采样 trajectories 估计梯度：高回报轨迹会提高其中动作的 log-probability。

怎么用. 当能采样 rollout、但不能对环境求导时使用。对 N 条轨迹取平均可以降低噪声。

Advantage 版本
$$ \nabla J\approx \mathbb{E}[A^\pi(s_t,a_t)\nabla_\theta\log\pi_\theta(a_t\mid s_t)] $$

符号. A^π(s_t,a_t): 动作 a_t 的优势；∇θ log πθ: 策略 log 概率梯度；E: 对采样状态和动作取期望

怎么理解. 把 raw return 换成 advantage：只有动作比该 state 的平均水平更好时，才强烈强化它。

怎么用. 在 actor-critic、PPO 等算法中用它降方差、稳定更新。

Advantage 定义
$$ A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s) $$

符号. Q^π(s,a): 做动作 a 后的价值；V^π(s): 状态 s 的平均价值；A^π(s,a): 相对 baseline 多出或少掉的价值

怎么理解. Advantage 把某个 action 和该 state 的平均水平比较：正数表示比平均好，负数表示更差。

怎么用. 把它作为 policy gradient 的权重：advantage 为正就提高该动作概率，为负就降低或少强化。

LLM 策略
$$ \pi_\theta(a_t\mid s_t)=P_\theta(y_t\mid x,y_{1:t-1}) $$

符号. x: prompt / 输入；y_{1:t-1}: 目前已生成 tokens；y_t: 下一个 token / 动作；Pθ: 参数 θ 下的模型概率

怎么理解. 在 LLM 强化学习里，state 是 prompt 加已生成 tokens，action 是下一个 token。

怎么用. 用这个映射把 RL 公式套到语言模型：πθ(a_t|s_t) 就是生成 token y_t 的概率。

Log-derivative trick
$$ \nabla J=\int P_\theta(\tau)R(\tau)\nabla\log P_\theta(\tau)\,d\tau,\qquad \nabla\log P_\theta(\tau)=\sum_t\nabla\log\pi_\theta(a_t\mid s_t) $$

符号. Pθ(τ): 参数 θ 下轨迹 τ 的概率；∇log Pθ(τ): 轨迹概率的 score function；Σ_t ∇log πθ(a_t|s_t): 每一步策略 log 概率梯度之和；R(τ): 给更新加权的轨迹回报

怎么理解. 这个技巧把对采样概率的梯度，转成策略网络能计算的 log 概率梯度。

怎么用. 用它推导 policy gradient：写成 ∇P=P∇logP；环境转移不依赖 θ，所以最后只剩 policy 的 log 概率项。

5. 例题精解

例 1 · Log-derivative 推导（HW5 §4.1）

写 $J=\int P_\theta(\tau)R(\tau)d\tau$。则 $\nabla J=\int P_\theta(\tau)R(\tau)\nabla\log P_\theta(\tau)d\tau$。在 MDP 中，只有策略项依赖 $\theta$，所以 $\nabla\log P_\theta(\tau)=\sum_t\nabla\log\pi_\theta(a_t|s_t)$。

例 2 · Actor-critic advantage（Lecture 27, p. 10-11）

若 $Q(s,a)=12$、$V(s)=9$，advantage 为 $3$：动作比平均表现好。若 $Q(s,a)=7$，advantage 为 $-2$：应减少选择该动作的倾向。

例 3 · LLM completions 的 GRPO（Lecture 27, p. 16-18）

对同一个 prompt 采样多个 completions，在组内比较奖励：高于组平均的 completion 得正 relative advantage，低于组平均的得负 relative advantage。这样可以不用单独训练 value model。

6. 题型与解题步骤

Policy-gradient 题怎么下手
  1. 从 $J(\theta)=\mathbb{E}_{\tau}[R(\tau)]$ 出发。
  2. 使用 $\nabla P=P\nabla\log P$。
  3. 若环境 dynamics 不依赖 $\theta$，梯度里把它去掉。
  4. 讨论降方差时，把总 return 替换成 $Q$、advantage 或 baseline。
  5. LLM RL 题把策略映射成 next-token distribution，把奖励映射成最终答案正确性。

7. 常见错误

高频陷阱
  • 把 vanilla policy gradient 说成 off-policy；它需要当前策略采样的新轨迹。
  • 漏掉 $\nabla\log\pi$ 中的 log。
  • 对不依赖 $\theta$ 的环境转移求导。
  • baseline 依赖 action 还声称自动无偏。
  • 忽略 PPO clipping 的动机：重复使用同一批 trajectories 更新太多会破坏策略。

🧠 Multi-Layer Perceptron

Lecture 10 introduces neural networks as learned feature maps: stack linear transformations with nonlinear activations so the model can represent functions that one linear classifier cannot.

1. Concept Understanding

A multilayer perceptron composes layers of affine maps and nonlinear activations. A purely linear stack collapses into one linear map, so nonlinearity is the ingredient that makes the model expressive.

Architecturally, an MLP is a feedforward network with an input layer, one or more hidden layers, and an output layer. The number of hidden units in a layer is its width; the number of layers is its depth. If a layer receives $n_{\text{in}}$ inputs and has $n_{\text{out}}$ neurons, then its weight matrix has shape $n_{\text{out}}\times n_{\text{in}}$.

MLPs are trained by empirical risk minimization, usually with gradient-based optimization on mini-batches. For classification, the final layer often produces logits passed through sigmoid or softmax.

2. Plain-English Explanation

A linear model draws one straight separator. An MLP builds intermediate features first, like “is this part active?” or “does this pattern appear?”, then combines those features.

Each layer is a small transformation. The activation function bends the space between layers; without that bend, many layers are just one layer wearing a costume.

3. Core Intuition

Lecture 10 motivates MLPs from the XOR failure of perceptrons. XOR is not linearly separable in the original input, but a hidden layer can create features that make it separable.

Depth lets the model reuse features hierarchically. Width gives more hidden units to carve the input space. Universal approximation says a sufficiently wide nonlinear network can approximate continuous functions on compact domains.

For exams, remember the constructive story: one hidden layer with at least two nonlinear units can solve XOR by first building useful logic features, then letting the output layer linearly combine those features.

4. Key Equations

Forward pass, layer by layer
$$ a^{(0)}=x,\qquad z^{(\ell)}=W^{(\ell)}a^{(\ell-1)}+b^{(\ell)},\qquad a^{(\ell)}=\sigma\!\left(z^{(\ell)}\right) $$

Symbols. $x$: one input example； $a^{(0)}$: layer-0 activation, equal to the raw input $x$； $\ell$: layer index； $W^{(\ell)}$: weight matrix of layer $\ell$; shape $n_\ell\times n_{\ell-1}$； $b^{(\ell)}$: bias vector of layer $\ell$; shape $n_\ell$； $z^{(\ell)}$: pre-activation raw score before the nonlinearity； $a^{(\ell)}$: post-activation output passed to the next layer； $\sigma$: activation function, applied elementwise

How to read it. An MLP alternates linear mixing and nonlinear bending. The linear part combines previous features; the activation prevents stacked layers from collapsing into one big linear map.

How to use. Start with $a^{(0)}=x$. For each layer, multiply by $W^{(\ell)}$, add $b^{(\ell)}$, then apply $\sigma$. In homework calculations, write the vector dimensions first so matrix multiplication errors show up immediately.

ReLU activation
$$ \operatorname{ReLU}(z)=\max(0,z) $$

Symbols. $z$: pre-activation value; can be a scalar, vector, or matrix； $\max(0,z)$: elementwise choice between zero and the input value

How to read it. ReLU is a simple gate. A hidden unit either fires with its positive score or stays silent at zero.

How to use. Apply ReLU to every entry: negative values become $0$, positive values remain unchanged. In backprop, the derivative is $0$ on inactive negative entries and $1$ on active positive entries.

Sigmoid activation
$$ \sigma(z)=\frac{1}{1+e^{-z}} $$

Symbols. $z$: pre-activation or logit； $\sigma(z)$: value between $0$ and $1$, often read as a binary-class probability

How to read it. Sigmoid squashes large negative inputs near $0$ and large positive inputs near $1$.

How to use. Use it for binary outputs or gates. Be careful in deep networks: saturated sigmoid units have tiny derivatives, which is one source of vanishing gradients.

Softmax output
$$ \hat y_i=\frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}} $$

Symbols. $K$: number of classes； $z_i$: logit score for class $i$； $\hat y_i$: predicted probability of class $i$； $\sum_{j=1}^{K}$: normalization across all classes

How to read it. Softmax turns arbitrary class scores into a probability distribution. Larger logits get exponentially more probability mass.

How to use. Exponentiate every logit, divide each exponential by the total sum, and pick the class with largest $\hat y_i$ for prediction. For numerical stability in code, subtract $\max_j z_j$ before exponentiating.

Cross-entropy loss
$$ \ell(y,\hat y)=-\sum_{i=1}^{K} y_i\log \hat y_i $$

Symbols. $y_i$: true label indicator for class $i$, often one-hot； $\hat y_i$: predicted probability for class $i$； $\ell$: loss for one example

How to read it. The loss is small only when the model assigns high probability to the correct class. Confidently wrong predictions get punished strongly.

How to use. For a one-hot label with true class $c$, all terms vanish except $i=c$, so $\ell=-\log\hat y_c$. Use it with softmax for multiclass classification.

Softmax + cross-entropy output gradient
$$ \hat y=\operatorname{softmax}(z),\qquad \frac{\partial \ell}{\partial z}=\hat y-y $$

This is the single most-used backprop shortcut in the course. Whenever the network ends in softmax then cross-entropy (multiclass) or sigmoid then BCE (binary, which is the $K=2$ collapse of the same identity), the gradient at the logits is simply predicted minus truth — no chain-rule expansion needed.

Symbols. $z\in\mathbb R^K$: pre-softmax logits at the output layer； $\hat y\in(0,1)^K$: softmax probabilities, $\sum_k\hat y_k=1$； $y\in\{0,1\}^K$: one-hot true label； $\partial\ell/\partial z$: vector of partial derivatives, same shape as $z$.

How to read it. $(\hat y-y)_c=\hat y_c-1$ on the true class $c$ (the only entry where $y$ is non-zero) and $(\hat y-y)_k=\hat y_k$ on every other class. So the gradient pulls the true logit up and pushes every wrong logit down, in proportion to how confidently the model predicted that wrong class.

How to derive it. Write $\ell=-\sum_i y_i\log\hat y_i$ with $\hat y_i=e^{z_i}/\sum_j e^{z_j}$. Compute $\partial\hat y_i/\partial z_k=\hat y_i(\delta_{ik}-\hat y_k)$, then $\partial\ell/\partial z_k=-\sum_i y_i(\delta_{ik}-\hat y_k)=\hat y_k-y_k$. The terms cancel beautifully because softmax outputs are normalized and labels sum to 1.

How to use. Start your backprop pass with $\partial\ell/\partial z=\hat y-y$ at the logits, then apply the affine-layer backward pass to push the gradient through $W^{(L)}, b^{(L)}$ and any earlier layers. This is why deep-learning libraries fuse softmax + cross-entropy into one op (CrossEntropyLoss in PyTorch, softmax_cross_entropy_with_logits in TF) — the analytical gradient is exactly this clean.

Where it shows up. HW3 backprop problems (start with this line, save half the algebra); midterm / final review's softmax-CE worked example; every classification head in the deep-learning blocks (MLP, CNN, Transformer, LLM).

Mini-batch gradient descent
$$ \theta\leftarrow \theta-\alpha\frac{1}{\lvert B\rvert}\sum_{i\in B}\nabla_{\theta}\ell_i(\theta) $$

Symbols. $\theta$: all trainable parameters, including every $W$ and $b$； $\alpha$: learning rate / step size； $B$: mini-batch of training examples； $\lvert B\rvert$: batch size； $\nabla_{\theta}\ell_i(\theta)$: gradient of example $i$'s loss with respect to the parameters

How to read it. The batch gradient estimates the full-data direction without scanning the entire dataset every step.

How to use. Compute gradients for each example in the batch, average them, scale by $\alpha$, and subtract from the parameters. This is the standard training update after backprop.

ERM objective
$$ \min_{\theta}\ \frac{1}{n}\sum_{i=1}^{n}\ell\!\left(y^{(i)}, f_{\theta}(x^{(i)})\right) $$

Symbols. $\theta$: all weights and biases； $f_{\theta}$: MLP prediction function； $\ell$: task loss； $n$: number of training examples

How to read it. Training chooses parameters that make average training loss small. Regression commonly uses MSE; classification commonly uses cross-entropy.

How to use. Pick the loss based on the task, compute gradients by backprop, then update parameters with SGD, Adam, or another gradient optimizer.

5. Worked Examples

Example A · Why linear layers alone do not help
Source: Lecture 10, neural networks as iterated linear prediction.

If $\phi(x)=Ax+b$, then $v^\top\phi(x)=v^\top Ax+v^\top b=(A^\top v)^\top x+\text{constant}$. This is still linear. A nonlinearity $\sigma(Ax+b)$ is required.

Example B · XOR via hidden logic features
Source: Lecture 10 XOR motivation, paraphrased.

XOR is not linearly separable in $(x_1,x_2)$, but a hidden layer can first build logic features. With threshold-style hidden units, take $h_{\text{OR}}=\mathbf{1}[x_1+x_2\ge 0.5]$ and $h_{\text{AND}}=\mathbf{1}[x_1+x_2\ge 1.5]$; then XOR is $1$ exactly when $h_{\text{OR}}-h_{\text{AND}}$ is positive.

Example C · ReLU realizes the identity
Source: HW3 Problem 1.1, paraphrased.

Use $\operatorname{ReLU}(x)-\operatorname{ReLU}(-x)=x$. Two hidden ReLU units can split $x$ into positive and negative parts, then combine them to recover $x$ exactly.

Example D · Approximating $x^2$ on a bounded interval
Source: HW3 Problem 1.7, paraphrased.

On $[0,1]$, split the interval into many small pieces and linearly interpolate $x^2$. ReLU units can build piecewise-linear functions, so enough breakpoints approximate the curve to any desired accuracy.

6. Problem-Solving Tips

Always track shapes. If $x\in\mathbb R^d$ and hidden size is $h$, then $W^{(1)}\in\mathbb R^{h\times d}$.
When asked why nonlinearity matters, show that linear-after-linear collapses to one linear map.
For ReLU construction problems, think in hinges: combine $\max(0,x-a)$ terms to form piecewise-linear functions.
For XOR or logic gates, build hidden features such as AND/OR first, then linearly combine them in the output layer.
For classification loss, identify whether the output is binary sigmoid or multiclass softmax.

7. Common Mistakes

  • Forgetting that without activations, depth adds no nonlinear power.
  • Writing ReLU as $\max(1,z)$ instead of $\max(0,z)$.
  • Calling softmax output a class label; it is a probability vector before argmax.
  • Using sigmoid everywhere in a deep network without noticing saturation and vanishing gradients.
  • Assuming universal approximation means a small network will train easily. It is an existence statement, not an optimization guarantee.
  • Thinking the learned parameters are unique; hidden units can often be permuted, and some networks have sign or scaling symmetries that represent the same function.

8. Exam Focus

  • Write a two-layer forward pass with correct dimensions.
  • State width, depth, and the $n_{\text{out}}\times n_{\text{in}}$ weight-matrix convention.
  • Explain why activations are necessary.
  • Explain why XOR needs hidden nonlinear features and sketch a simple construction.
  • Know ReLU, sigmoid, softmax, and cross-entropy.
  • Recognize universal approximation, vanishing gradients, and weight symmetries as theory-level properties.
  • Design simple ReLU networks for piecewise-linear functions.
  • Explain mini-batch SGD at a high level.

9. Quick Checklist

  • I can write $z=Wx+b$ and $a=\sigma(z)$ layer by layer.
  • I know linear layers without activation collapse.
  • I can explain XOR as motivation for hidden nonlinear features.
  • I know regression uses MSE and classification usually uses cross-entropy.
  • I can use ReLU hinges for simple construction problems.
  • I know softmax plus cross-entropy for multiclass classification.

🧠 MLP · 多层感知机

Lecture 10 把 neural networks 讲成 learned feature maps：把 linear transformations 和 nonlinear activations 叠起来，让模型能表达单个 linear classifier 做不到的函数。

1. Concept Understanding · 概念理解

Multilayer perceptron 由 affine maps 和 nonlinear activations 复合而成。纯 linear stack 会折叠成一个 linear map，所以 nonlinearity 才是表达能力的关键。

结构上，MLP 是 feedforward neural network：input layer、一个或多个 hidden layers、output layer。某一 hidden layer 里 units 的数量叫 width；层数叫 depth。如果一层接收 $n_{\text{in}}$ 个输入、有 $n_{\text{out}}$ 个 neurons，那么 weight matrix 的 shape 是 $n_{\text{out}}\times n_{\text{in}}$。

MLP 用 empirical risk minimization 训练，通常配合 mini-batch gradient optimization。分类任务最后一层常输出 logits，再接 sigmoid 或 softmax。

2. Plain-English Explanation · 大白话理解

Linear model 只能画一条直线 / hyperplane。MLP 会先造一些中间 features，比如“这个局部 pattern 是否出现”，再把这些 features 组合起来。

每层都是一次小变换；activation function 负责把空间“折一下”。如果没有这个折弯，很多层只是一个 layer 换了套衣服。

3. Core Intuition · 核心直觉

Lecture 10 用 perceptron 解决不了 XOR 来引出 MLP。XOR 在原 input space 里不是 linearly separable，但 hidden layer 可以创造让它可分的 features。

Depth 让模型复用 hierarchical features；width 提供更多 hidden units 来切分输入空间。Universal approximation 说足够宽的 nonlinear network 能在 compact domain 上逼近 continuous functions。

考试里要会讲 construction story：一个 hidden layer，至少两个 nonlinear units，就能先造出有用的 logic features，再由 output layer 线性组合来解决 XOR。

4. 关键公式

Forward pass：一层一层往前算
$$ a^{(0)}=x,\qquad z^{(\ell)}=W^{(\ell)}a^{(\ell-1)}+b^{(\ell)},\qquad a^{(\ell)}=\sigma\!\left(z^{(\ell)}\right) $$

符号. $x$: 一个 input example；$a^{(0)}$: 第 0 层 activation，也就是原始输入 $x$；$\ell$: layer index，第几层；$W^{(\ell)}$: 第 $\ell$ 层 weight matrix；shape 是 $n_\ell\times n_{\ell-1}$；$b^{(\ell)}$: 第 $\ell$ 层 bias vector；shape 是 $n_\ell$；$z^{(\ell)}$: pre-activation，过 nonlinearity 前的 raw score；$a^{(\ell)}$: post-activation，传给下一层的 representation；$\sigma$: activation function，elementwise 套到每个坐标

怎么理解. MLP 就是在 linear mixing 和 nonlinear bending 之间交替。Linear part 负责组合上一层 features；activation 负责把空间折弯，避免多层网络退化成一个大 linear map。

怎么用. 从 $a^{(0)}=x$ 开始。每层先乘 $W^{(\ell)}$，再加 $b^{(\ell)}$，最后套 activation $\sigma$。手算题先写每个 vector / matrix 的 dimension，shape 错误会立刻暴露。

ReLU activation
$$ \operatorname{ReLU}(z)=\max(0,z) $$

符号. $z$: pre-activation value；可以是 scalar、vector 或 matrix；$\max(0,z)$: elementwise 地在 $0$ 和原值之间取较大者

怎么理解. ReLU 像一个简单开关：hidden unit 的 score 为正就激活，为负就静默成 $0$。

怎么用. 对每个 entry 单独套 ReLU：负数变 $0$，正数原样保留。做 backprop 时，负数位置 derivative 是 $0$，正数位置 derivative 是 $1$。

Sigmoid activation
$$ \sigma(z)=\frac{1}{1+e^{-z}} $$

符号. $z$: pre-activation / logit；$\sigma(z)$: 落在 $(0,1)$ 的数，常当作 binary-class probability。

怎么理解. Sigmoid 会把很负的输入压到接近 $0$，把很正的输入压到接近 $1$。

怎么用. 常用于 binary output 或 gate。深层网络里要小心 saturation：输入太大或太小时 derivative 很小，会导致 vanishing gradients。

Softmax output
$$ \hat y_i=\frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}} $$

符号. $K$: classes 的数量；$z_i$: 第 $i$ 类的 logit score；$\hat y_i$: 模型预测属于第 $i$ 类的 probability；$\sum_{j=1}^{K}$: 对所有 classes 做 normalization

怎么理解. Softmax 把任意 class scores 变成 probability distribution。logit 越大，拿到的 probability mass 会指数级更大。

怎么用. 先对每个 logit 取指数，再除以所有指数之和；prediction 通常取最大的 $\hat y_i$。代码里为了 numerical stability，常先减去 $\max_j z_j$ 再 exp。

Cross-entropy loss
$$ \ell(y,\hat y)=-\sum_{i=1}^{K} y_i\log \hat y_i $$

符号. $y_i$: 第 $i$ 类的 true label indicator，通常是 one-hot；$\hat y_i$: 第 $i$ 类的 predicted probability；$\ell$: 单个 example 的 loss

怎么理解. 只有模型给正确类别很高 probability 时，loss 才小。自信但错误的 prediction 会被重罚。

怎么用. 如果 label 是 one-hot，真实类别为 $c$，只有 $i=c$ 那一项留下，所以 $\ell=-\log\hat y_c$。Multiclass classification 通常 softmax + cross-entropy 一起用。

Softmax + cross-entropy 输出梯度
$$ \hat y=\operatorname{softmax}(z),\qquad \frac{\partial \ell}{\partial z}=\hat y-y $$

本课最常用的 backprop 捷径。只要网络末端是 softmax + cross-entropy（多类）或 sigmoid + BCE（二类，对应同一恒等式 $K=2$ 退化），logits 处的梯度就是简单的 预测减真实 —— 不用展开 chain rule。

符号. $z\in\mathbb R^K$：输出层 softmax 之前的 logits；$\hat y\in(0,1)^K$：softmax 概率，$\sum_k\hat y_k=1$；$y\in\{0,1\}^K$：one-hot 真实标签；$\partial\ell/\partial z$：与 $z$ 同 shape 的梯度向量。

怎么理解. $(\hat y-y)_c=\hat y_c-1$ 在真实类别 $c$ 处（$y$ 唯一非 0 的位置），其余 $(\hat y-y)_k=\hat y_k$。所以梯度把真实 logit 往上推、把所有错误 logit 往下压，压力大小正比于模型在错误类别上的自信度。

怎么推导. 写 $\ell=-\sum_i y_i\log\hat y_i$，$\hat y_i=e^{z_i}/\sum_j e^{z_j}$。算 $\partial\hat y_i/\partial z_k=\hat y_i(\delta_{ik}-\hat y_k)$，再代回得 $\partial\ell/\partial z_k=-\sum_i y_i(\delta_{ik}-\hat y_k)=\hat y_k-y_k$。能塌得这么干净，是因为 softmax 输出已归一、标签也求和为 1。

怎么用. Backprop 时直接从 $\partial\ell/\partial z=\hat y-y$ 起步，再用 affine-layer backward pass 把梯度穿过 $W^{(L)}, b^{(L)}$ 与更早层。这正是 deep learning library 把 softmax 与 cross-entropy 融合成一个 op（PyTorch 的 CrossEntropyLoss、TF 的 softmax_cross_entropy_with_logits）的原因 —— 解析梯度本身就是这么干净。

典型出处. HW3 backprop 题（直接从这一行起步，省掉一半代数）；midterm / final review 的 softmax-CE worked example；后面 deep learning block（MLP、CNN、Transformer、LLM）每个 classification head 都重复用到。

Mini-batch gradient descent
$$ \theta\leftarrow \theta-\alpha\frac{1}{\lvert B\rvert}\sum_{i\in B}\nabla_{\theta}\ell_i(\theta) $$

符号. $\theta$: 所有 trainable parameters，包括每层的 $W$ 和 $b$；$\alpha$: learning rate / step size；$B$: 一个 mini-batch 的 training examples；$\lvert B\rvert$: batch size；$\nabla_{\theta}\ell_i(\theta)$: 第 $i$ 个 example 的 loss 对参数的 gradient

怎么理解. Mini-batch gradient 用一小批样本近似 full-data gradient，避免每一步都扫完整 dataset。

怎么用. 先算 batch 内每个样本的 gradient，取平均，乘 learning rate $\alpha$，再从参数中减掉。这就是 backprop 后最常见的 training update。

ERM objective
$$ \min_{\theta}\ \frac{1}{n}\sum_{i=1}^{n}\ell\!\left(y^{(i)}, f_{\theta}(x^{(i)})\right) $$

符号. $\theta$: 所有 weights 和 biases；$f_{\theta}$: MLP prediction function；$\ell$: task loss；$n$: training examples 数量。

怎么理解. Training 的目标是让 average training loss 小。Regression 常用 MSE；classification 常用 cross-entropy。

怎么用. 先根据任务选 loss，再用 backprop 算 gradients，最后用 SGD、Adam 或其他 gradient optimizer 更新参数。

5. Worked Examples · 代表性例题

Example A · 只有 linear layers 没用
来源：Lecture 10，neural networks as iterated linear prediction。

若 $\phi(x)=Ax+b$，则 $v^\top\phi(x)=v^\top Ax+v^\top b=(A^\top v)^\top x+\text{constant}$，仍然是 linear。所以必须加入 nonlinearity $\sigma(Ax+b)$。

Example B · 用 hidden logic features 解 XOR
来源：Lecture 10 XOR motivation，题意转述。

XOR 在 $(x_1,x_2)$ 原空间里不是 linearly separable，但 hidden layer 可以先造 logic features。用 threshold-style hidden units，可以设 $h_{\text{OR}}=\mathbf{1}[x_1+x_2\ge 0.5]$，$h_{\text{AND}}=\mathbf{1}[x_1+x_2\ge 1.5]$；当 $h_{\text{OR}}-h_{\text{AND}}$ 为正时正好表示 XOR。

Example C · ReLU 实现 identity
来源：HW3 Problem 1.1，题意转述。

利用 $\operatorname{ReLU}(x)-\operatorname{ReLU}(-x)=x$。两个 hidden ReLU units 分别抓住正半轴和负半轴，再线性组合就能精确恢复 $x$。

Example D · 在 bounded interval 逼近 $x^2$
来源：HW3 Problem 1.7，题意转述。

在 $[0,1]$ 上把区间切成很多小段，用 piecewise-linear interpolation 逼近 $x^2$。ReLU units 可以拼出 piecewise-linear functions，所以 breakpoints 足够多时误差可小于任意 $\epsilon$。

6. Problem-Solving Tips · 解题技巧

永远追踪 shapes。 若 $x\in\mathbb R^d$，hidden size 是 $h$，则 $W^{(1)}\in\mathbb R^{h\times d}$。
解释 nonlinearity： 直接展示 linear-after-linear 会 collapse 成一个 linear map。
ReLU 构造题： 想 hinge functions，用 $\max(0,x-a)$ 拼 piecewise-linear 函数。
XOR / logic gates： 先构造 AND、OR 这类 hidden features，再让 output layer 线性组合。
分类 loss： 先判断是 binary sigmoid 还是 multiclass softmax。

7. Common Mistakes · 常见错误

  • 忘记没有 activation 时，depth 不增加 nonlinear power。
  • 把 ReLU 写成 $\max(1,z)$，正确是 $\max(0,z)$。
  • 把 softmax output 直接当 class label；它在 argmax 前是 probability vector。
  • 深层网络里到处用 sigmoid，却忽略 saturation 和 vanishing gradients。
  • 以为 universal approximation 意味着小网络一定容易训练；它只是 existence statement，不保证 optimization。
  • 以为 learned parameters 唯一；hidden units 可以 permutation，有些网络还存在 sign / scaling symmetries，导致不同参数表示同一个 function。

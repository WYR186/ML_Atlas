🎯 Logistic Regression

Logistic regression is the linear classifier from Lecture 5 that turns a score into a probability and trains by maximum likelihood instead of squared error.

1. Concept Understanding

For binary labels $y\in\{-1,+1\}$, logistic regression computes a linear score $s=w^\top\phi(x)$ and converts it into a class probability:

$$ p(y\mid x)=\frac{1}{1+\exp(-y\,w^\top\phi(x))} $$

It is a discriminative model: it directly models $p(y\mid x;\theta)$ instead of modeling the joint distribution $p(x,y)$ as Naive Bayes does. A bias term can be written explicitly as $a=w^\top x+b$, or absorbed into $\phi(x)$ by adding a constant feature.

The concept solves the classification weakness of linear regression: we want a loss that cares about correct signs and probability confidence, not about matching labels as numeric targets.

2. Plain-English Explanation

Think of $w^\top x$ as a confidence meter. Large positive means “class +1 looks likely,” large negative means “class -1 looks likely,” and near zero means “I am unsure.”

The sigmoid squeezes that meter into a probability between 0 and 1. The log loss then asks: did the model assign high probability to the true class?

3. Core Intuition

Linear regression with MSE keeps pulling on easy examples even after they are classified correctly. Logistic loss mostly cares about the margin $y\,w^\top\phi(x)$: if the margin is large and positive, the loss is tiny; if it is negative, the loss grows quickly.

The model is probabilistic. Under the i.i.d. assumption, maximizing the likelihood of all labels is equivalent to minimizing negative log-likelihood. There is usually no closed form, so Lecture 5 uses gradient descent.

4. Key Equations

Sigmoid
$$ \sigma(z)=\frac{1}{1+e^{-z}} $$

What it does. Turns an unbounded score into a probability; score $0$ is the tie point.

▸ Explain 解释
Intuition理解
An S-curve that interprets a linear score as a probability. Negative scores → near 0, large positives → near 1, $z=0$ → exactly 0.5. Saturates at the extremes, which is why logistic regression has 'flat' gradients for very confident predictions. 一条 S 形曲线，把线性 score 解读为概率。负 score → 接近 0，大的正 score → 接近 1，$z=0$ → 正好 0.5。两端饱和 —— 这就是为什么对 "非常自信" 的预测梯度会变平。
Symbols符号
  • $\sigma(z)$ the logistic / sigmoid function — squashes any real $z$ into $(0,1)$ logistic / sigmoid 函数 —— 把任意实数 $z$ 压到 $(0,1)$
  • $z = w^\top x$ the linear score — typically $w^\top x + b$ 线性 score —— 通常是 $w^\top x + b$
  • $e^{-z}$ exponential — large positive $z$ → tiny denominator → output near 1 指数 —— $z$ 大的正值 → 分母极小 → 输出接近 1
How to use如何运用
Use as the output activation for binary classification; interpret $\sigma(w^\top x)$ as $P(y=1 \mid x)$. Threshold at 0.5 to predict the class. Derivative is $\sigma'(z) = \sigma(z)(1-\sigma(z))$ — appears in every gradient computation. 二分类的输出激活函数；把 $\sigma(w^\top x)$ 当作 $P(y=1 \mid x)$。阈值 0.5 给出预测类别。导数 $\sigma'(z) = \sigma(z)(1-\sigma(z))$ —— 在每次梯度计算中都会出现。
Logit / log-odds
$$ \log\frac{p}{1-p}=w^\top\phi(x)+b $$

What it does. Puts the linear model on log-odds instead of raw probability.

▸ Explain 解释
Intuition理解
Logistic regression does not make probability itself a straight line. It makes the log-odds a straight line, then passes that value through sigmoid to get a probability. Logistic regression 不是让 probability 本身成直线，而是让 log-odds 成直线，再通过 sigmoid 转回 probability。
Symbols符号
  • $p$ predicted probability of class 1 预测为 class 1 的概率
  • $\frac{p}{1-p}$ odds of class 1 versus class 0 class 1 相对 class 0 的 odds
  • $\log\frac{p}{1-p}$ logit / log-odds; the inverse scale of the sigmoid logit / log-odds；sigmoid 的反向尺度
  • $w^\top\phi(x)+b$ linear score with bias 带 bias 的线性 score
How to use如何运用
Use it to explain what the weights mean and why the boundary is linear. A one-unit feature increase adds $w_j$ to log-odds, and setting $p=0.5$ makes the left side $\log 1=0$. 用它解释权重含义和为什么 boundary 是线性的。某个 feature 加 1 会让 log-odds 增加 $w_j$；令 $p=0.5$ 时左边变成 $\log 1=0$。
Decision boundary
$$ p(y=1\mid x)=0.5 \iff w^\top\phi(x)=0 $$

What it does. Converts the $0.5$ probability cutoff into a zero-score sign test.

▸ Explain 解释
Intuition理解
'Sigmoid is 0.5 exactly when its input is 0.' So the decision boundary lives at $w^\top \phi(x) = 0$ — a hyperplane through the origin (or shifted, with bias). The non-linear part is only in the output, not the boundary. "sigmoid 在输入为 0 时正好等于 0.5。" 所以决策边界位于 $w^\top \phi(x) = 0$ —— 过原点的超平面（带 bias 时平移）。非线性只在输出部分，不在边界形状。
Symbols符号
  • $p(y=1 \mid x) = 0.5$ the cutoff probability for classifying as class 1 判为类别 1 的概率阈值
  • $w^\top \phi(x) = 0$ the equivalent linear condition (sigmoid is 0.5 at $z=0$) 等价的线性条件（sigmoid 在 $z=0$ 处取 0.5）
  • $\phi(x)$ feature map (identity for plain logistic regression) 特征映射（普通 logistic regression 中是恒等映射）
How to use如何运用
Use to plot or analyze classifier behavior. The decision surface is a hyperplane in $\phi(x)$-space — that's what makes logistic regression a **linear classifier** despite the non-linear sigmoid output. 用于画图或分析分类器行为。决策面在 $\phi(x)$ 空间是一个超平面 —— 尽管输出经过非线性 sigmoid，logistic regression 仍是**线性分类器**。
Negative log-likelihood
$$ \min_w \sum_{(x_i,y_i)\in D}\log\!\left(1+\exp(-y_i w^\top\phi(x_i))\right) $$

What it does. Trains the classifier with a smooth penalty for wrong or weak margins.

▸ Explain 解释
Intuition理解
Penalty grows when the score has the wrong sign relative to $y_i$. Confident-and-correct → near-zero loss; confident-and-wrong → linear penalty in $|z|$. This is what makes the loss convex and well-behaved. 当 score 的符号与 $y_i$ 相反时惩罚增大。自信且对 → 损失接近 0；自信但错 → 惩罚关于 $|z|$ 线性增长。正是这种形式让 loss 凸且行为良好。
Symbols符号
  • $D$ training set $\{(x_i, y_i)\}$ 训练集 $\{(x_i, y_i)\}$
  • $y_i \in \{-1, +1\}$ label in the $\pm 1$ form (different sign convention than 0/1) $\pm 1$ 形式的标签（与 0/1 约定符号不同）
  • $w^\top \phi(x_i)$ linear margin score 线性 margin score
  • $\log(1 + e^{-z})$ softplus / log-loss — smooth approximation of $\max(0, -z)$ softplus / log-loss —— $\max(0, -z)$ 的光滑近似
How to use如何运用
Standard logistic-regression objective. Minimize via gradient descent (no closed form because of the non-linearity). Add an L2 regularizer $\frac{\lambda}{2}\|w\|^2$ for ridge-style logistic regression. logistic regression 标准目标。用 gradient descent 最小化（因非线性无闭式解）。加 L2 正则 $\frac{\lambda}{2}\|w\|^2$ 即 ridge 版 logistic regression。
Binary cross-entropy (BCE)
$$ \mathcal{L}(y,\hat y)=-\bigl(y\log\hat y+(1-y)\log(1-\hat y)\bigr) $$
$$ \mathrm{NLL}(w)=-\frac{1}{N}\sum_{n=1}^{N}\left[y_n\log\mu_n+(1-y_n)\log(1-\mu_n)\right],\qquad \mu_n=\sigma(w^\top x_n) $$

What it does. Uses the same training idea for $0/1$ labels: give the true class high probability.

▸ Explain 解释
Intuition理解
Two terms — only one is 'on' for any given example. When $y=1$ you want $\hat y$ high (the first term punishes low $\hat y$); when $y=0$ you want $\hat y$ low (the second term punishes high $\hat y$). Confidently wrong → unbounded penalty. 两项里只有一项激活：$y=1$ 时希望 $\hat y$ 大（第一项惩罚 $\hat y$ 太小），$y=0$ 时希望 $\hat y$ 小（第二项惩罚 $\hat y$ 太大）。自信但错 → 惩罚趋近无穷。
Symbols符号
  • $y\in\{0,1\}$ true binary label (0 or 1) 真实二分类标签 $y\in\{0,1\}$
  • $\hat y\in(0,1)$ predicted probability of class 1, usually $\hat y=\sigma(z)$ where $z$ is the logit 预测的 class 1 概率，通常 $\hat y=\sigma(z)$（$z$ 为 logit）
  • $y\log\hat y$ active when the truth is class 1 $y=1$ 时该项激活
  • $(1-y)\log(1-\hat y)$ active when the truth is class 0 $y=0$ 时该项激活
How to use如何运用
Standard loss for any binary classifier with a sigmoid output: logistic regression, MLP with one sigmoid output unit, the two-layer net in HW3. Combined with the sigmoid logit $z$, the gradient simplifies to $\partial\mathcal{L}/\partial z=\hat y-y$ (see the softmax-CE gradient entry under MLP). For numerical stability use the fused 'BCE-with-logits' form $\log(1+e^{-y'z})$ with $y'\in\{-1,+1\}$. 任意 sigmoid 输出二分类的标准 loss：logistic regression、单 sigmoid 输出的 MLP、HW3 的两层网络都用它。结合 sigmoid logit $z$，梯度简化为 $\partial\mathcal{L}/\partial z=\hat y-y$（见 MLP 的 softmax-CE 梯度项）。代码上为数值稳定常用 fused 'BCE-with-logits'：$\log(1+e^{-y'z})$，$y'\in\{-1,+1\}$。
Gradient descent update
$$ w_{t+1}=w_t-\alpha \nabla f(w_t) $$

What it does. Updates weights one step in the direction that lowers the loss.

▸ Explain 解释
Intuition理解
'Walk against the gradient by step size $\alpha$.' On convex losses (logistic regression is convex), this finds the global minimum; learning-rate tuning is the main practical concern. "沿负梯度走 $\alpha$ 步。" 在凸 loss（logistic regression 凸）上能找到全局最小；实际中调学习率是主要工作。
Symbols符号
  • $w_t$ current weight vector at step $t$ 第 $t$ 步的当前权重向量
  • $w_{t+1}$ updated weights after one step 一步更新后的权重
  • $\alpha$ learning rate (positive scalar) 学习率（正标量）
  • $\nabla f(w_t)$ gradient of the loss at $w_t$ $w_t$ 处 loss 的梯度
How to use如何运用
Generic GD update — works for any differentiable loss, not just logistic. For logistic regression specifically, $\nabla f(w) = -\sum_i y_i \sigma(-y_i w^\top x_i)\, x_i$ (with $\pm 1$ labels). Pick $\alpha$ via line search or schedule. 通用 GD 更新 —— 对任意可微 loss 都适用，不限 logistic。logistic regression 中 $\nabla f(w) = -\sum_i y_i \sigma(-y_i w^\top x_i)\, x_i$（$\pm 1$ 标签下）。$\alpha$ 用 line search 或调度选。
Gradient and IRLS
$$ \nabla L(w)=\sum_i(\mu_i-y_i)x_i,\qquad \mu_i=\sigma(w^\top x_i) $$

What it does. Shows each example pushes the weights by its probability error times its input.

▸ Explain 解释
Intuition理解
Each example votes to move the weights by 'how wrong the probability is' times its input direction. The shape mirrors linear regression residuals, but the prediction is passed through sigmoid first. 每个样本都按“概率错了多少”乘上自己的输入方向来推动权重。形式像 linear regression 的 residual，只是预测先过了 sigmoid。
Symbols符号
  • $\mu_i$ predicted probability $P(y_i=1\mid x_i)$ 预测概率 $P(y_i=1\mid x_i)$
  • $\mu_i-y_i$ probability residual: predicted minus true label 概率残差：预测值减真实标签
  • $x_i$ input feature vector for example $i$ 第 $i$ 个样本的输入特征向量
  • $\nabla L(w)$ gradient of the 0/1-label negative log-likelihood $0/1$ 标签 negative log-likelihood 的梯度
How to use如何运用
Use this gradient in batch or mini-batch GD. In matrix form it is $X^\top(\mu-y)$. IRLS / Newton pairs it with the Hessian $X^\top B X$ to take second-order steps. 把这个 gradient 放进 batch 或 mini-batch GD。矩阵形式是 $X^\top(\mu-y)$。IRLS / Newton 会把它和 Hessian $X^\top B X$ 配起来做二阶更新。
Convexity check for $y\in\{0,1\}$ form
$$ \nabla^2 L(w)=X^\top B X,\qquad B=\mathrm{diag}(p_i(1-p_i)) $$

What it does. Shows the curvature is PSD, which is why logistic loss is convex.

▸ Explain 解释
Intuition理解
'Variances $p_i(1-p_i)$ are between 0 and 0.25 — never negative.' That non-negativity is what guarantees convexity; without it, the loss could have multiple local minima and GD would be unreliable. "方差 $p_i(1-p_i)$ 在 0 到 0.25 之间 —— 永远非负。" 这个非负性正是凸性的保障；没有它的话，loss 可能有多个局部最小，GD 就不可靠。
Symbols符号
  • $\nabla^2 L(w)$ Hessian of the logistic loss logistic loss 的 Hessian
  • $X$ design matrix (rows are feature vectors) 设计矩阵（行是特征向量）
  • $B = \mathrm{diag}(p_i(1-p_i))$ diagonal of variances $p_i(1-p_i)$ where $p_i = \sigma(w^\top x_i)$ 方差对角阵，$p_i = \sigma(w^\top x_i)$
  • $p_i (1-p_i) \ge 0$ each diagonal entry non-negative ⇒ $B \succeq 0$ 每个对角项非负 ⇒ $B \succeq 0$
How to use如何运用
Use the sandwich identity: $X^\top B X \succeq 0$ when $B \succeq 0$, so the Hessian is PSD everywhere → the logistic loss is convex → gradient descent converges to the global minimum. 用 sandwich 恒等式：$B \succeq 0$ 时 $X^\top B X \succeq 0$，所以 Hessian 处处 PSD → logistic loss 凸 → gradient descent 收敛到全局最小。
Softmax extension
$$ p(y=c\mid x)=\frac{\exp(w_c^\top x)}{\sum_{j=1}^{C}\exp(w_j^\top x)} $$

What it does. Turns one score per class into probabilities that add up to $1$.

▸ Explain 解释
Intuition理解
Softmax is sigmoid's multiclass cousin: every class gets a score, exponentials make higher scores dominate, and the denominator turns the scores into a probability distribution. Softmax 是 sigmoid 的多分类版本：每个 class 一个 score，指数让高 score 占更多概率质量，分母把它们变成概率分布。
Symbols符号
  • $C$ number of classes 类别总数
  • $w_c^\top x$ logit / score for class $c$ class $c$ 的 logit / score
  • $\exp(w_c^\top x)$ positive unnormalized score for class $c$ class $c$ 的正的未归一化分数
  • $\sum_j \exp(w_j^\top x)$ normalizer that makes probabilities sum to 1 让所有概率加起来为 1 的归一化项
How to use如何运用
Use softmax for multiclass logistic regression. Train with multiclass cross-entropy. In numerical code, subtract the maximum logit or use a fused log-sum-exp implementation to avoid overflow. 多分类 logistic regression 用 softmax。训练时配 multiclass cross-entropy。写代码时先减最大 logit，或直接用 fused log-sum-exp 实现，避免 overflow。

5. Worked Examples

Example A · Why the boundary is still linear
Source: Lecture 5, probability-threshold slide.

If the classifier predicts +1 when $p(y=1\mid x)\ge 0.5$, then $\sigma(w^\top x)\ge 0.5$. Since sigmoid crosses 0.5 at input 0, this is exactly $w^\top x\ge 0$.

Example B · Logistic vs. linear loss
Source: Lecture 5, comparison with quadratic loss.

For a correctly classified point with large positive margin, quadratic classification loss can still be large because it tries to make the score close to the numeric label. Linear regression can also output values outside $[0,1]$ and is sensitive to outliers. Logistic loss becomes close to zero because the model already assigns high probability to the correct Bernoulli label.

Example C · Hessian proves convexity
Source: HW1 Problem 4(a-b), paraphrased.

Stacking examples gives $H=X^\top B X$ with nonnegative diagonal $B$. For any vector $v$, $v^\top H v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge 0$. Therefore logistic loss is convex, so local minima are global minima.

6. Problem-Solving Tips

Identify the label convention. Use $\log(1+\exp(-y s))$ for $y\in\{-1,+1\}$ and binary cross-entropy for $y\in\{0,1\}$.
For probability questions, write the sigmoid first, then threshold at 0.5 if classification is required.
For convexity questions, show the Hessian is $X^\top B X$ and test $v^\top H v$.
For optimization questions, say “no closed form in general; use gradient descent.”
For linear-vs-logistic questions, contrast Gaussian regression targets with Bernoulli class labels. In multiclass classification, linear regression can mask an intermediate class even when the classes are separable.
For separable data, unregularized MLE may send $\|w\|$ toward infinity. Add $L_2$ weight decay, such as $\lambda\|w\|_2^2$, to keep the solution finite and improve generalization.
For XOR, a single logistic-regression boundary cannot solve it. You need nonlinear features or a hidden layer such as an MLP.

7. Common Mistakes

  • Calling logistic regression nonlinear because sigmoid is nonlinear. The decision boundary is still linear in $\phi(x)$.
  • Mixing $y\in\{0,1\}$ and $y\in\{-1,+1\}$ formulas without converting.
  • Expecting a normal-equation closed form like linear regression.
  • Forgetting the i.i.d. assumption when multiplying likelihoods over the dataset.
  • Forgetting that perfectly separable data makes unregularized MLE chase infinite weights.

🎯 Logistic Regression · 逻辑回归

Logistic Regression 是 Lecture 5 的核心：把 linear score 变成 probability，用 maximum likelihood / NLL 来训练，而不是用 squared error 硬拟合分类标签。

1. Concept Understanding · 概念理解

对二分类 $y\in\{-1,+1\}$，模型先算 score $s=w^\top\phi(x)$，再把它变成真实类别的概率：

$$ p(y\mid x)=\frac{1}{1+\exp(-y\,w^\top\phi(x))} $$

它是 discriminative model：直接建模 $p(y\mid x;\theta)$，而不是像 Naive Bayes 那样建模 joint distribution $p(x,y)$。Bias 可以显式写成 $a=w^\top x+b$，也可以把常数 1 加进 $\phi(x)$ 里吸收掉。

它解决的是 linear regression 做 classification 的问题：分类更关心 sign 和 confidence，而不是把标签当普通数字去拟合。

2. Plain-English Explanation · 大白话理解

把 $w^\top x$ 想成一个“信心条”。很正表示更像 +1，很负表示更像 -1，接近 0 表示不确定。

Sigmoid 把这个信心条压到 0 到 1 之间，变成 probability。Log loss 问的是：你有没有给真实类别足够高的概率？

3. Core Intuition · 核心直觉

MSE 会一直拉扯 easy examples，即使它们已经分类正确。Logistic loss 主要看 margin $y\,w^\top\phi(x)$：margin 很大且为正时 loss 很小；margin 为负时 loss 快速变大。

从概率角度看，样本 i.i.d. 时，最大化整份 dataset 的 likelihood 等价于最小化 negative log-likelihood。一般没有 closed form，所以用 gradient descent。

Symbols符号
  • $p(y=1 \mid x) = 0.5$ the cutoff probability for classifying as class 1 判为类别 1 的概率阈值
  • $w^\top \phi(x) = 0$ the equivalent linear condition (sigmoid is 0.5 at $z=0$) 等价的线性条件（sigmoid 在 $z=0$ 处取 0.5）
  • $\phi(x)$ feature map (identity for plain logistic regression) 特征映射（普通 logistic regression 中是恒等映射）
How to use如何运用
Use to plot or analyze classifier behavior. The decision surface is a hyperplane in $\phi(x)$-space — that's what makes logistic regression a **linear classifier** despite the non-linear sigmoid output. 用于画图或分析分类器行为。决策面在 $\phi(x)$ 空间是一个超平面 —— 尽管输出经过非线性 sigmoid，logistic regression 仍是**线性分类器**。
NLL / log loss
$$ \min_w \sum_{(x_i,y_i)\in D}\log\!\left(1+\exp(-y_i w^\top\phi(x_i))\right) $$

这个公式在做什么？ 用一个平滑 loss 惩罚错误或不够强的 margin。

▸ Explain 解释
Intuition理解
Penalty grows when the score has the wrong sign relative to $y_i$. Confident-and-correct → near-zero loss; confident-and-wrong → linear penalty in $|z|$. This is what makes the loss convex and well-behaved. 当 score 的符号与 $y_i$ 相反时惩罚增大。自信且对 → 损失接近 0；自信但错 → 惩罚关于 $|z|$ 线性增长。正是这种形式让 loss 凸且行为良好。
Symbols符号
  • $D$ training set $\{(x_i, y_i)\}$ 训练集 $\{(x_i, y_i)\}$
  • $y_i \in \{-1, +1\}$ label in the $\pm 1$ form (different sign convention than 0/1) $\pm 1$ 形式的标签（与 0/1 约定符号不同）
  • $w^\top \phi(x_i)$ linear margin score 线性 margin score
  • $\log(1 + e^{-z})$ softplus / log-loss — smooth approximation of $\max(0, -z)$ softplus / log-loss —— $\max(0, -z)$ 的光滑近似
How to use如何运用
Standard logistic-regression objective. Minimize via gradient descent (no closed form because of the non-linearity). Add an L2 regularizer $\frac{\lambda}{2}\|w\|^2$ for ridge-style logistic regression. logistic regression 标准目标。用 gradient descent 最小化（因非线性无闭式解）。加 L2 正则 $\frac{\lambda}{2}\|w\|^2$ 即 ridge 版 logistic regression。
Binary cross-entropy (BCE)
$$ \mathcal{L}(y,\hat y)=-\bigl(y\log\hat y+(1-y)\log(1-\hat y)\bigr) $$
$$ \mathrm{NLL}(w)=-\frac{1}{N}\sum_{n=1}^{N}\left[y_n\log\mu_n+(1-y_n)\log(1-\mu_n)\right],\qquad \mu_n=\sigma(w^\top x_n) $$

这个公式在做什么？ 用 $0/1$ 标签表达同一个训练目标：让真实类别概率尽量高。

▸ Explain 解释
Intuition理解
Two terms — only one is 'on' for any given example. When $y=1$ you want $\hat y$ high (the first term punishes low $\hat y$); when $y=0$ you want $\hat y$ low (the second term punishes high $\hat y$). Confidently wrong → unbounded penalty. 两项里只有一项激活：$y=1$ 时希望 $\hat y$ 大（第一项惩罚 $\hat y$ 太小），$y=0$ 时希望 $\hat y$ 小（第二项惩罚 $\hat y$ 太大）。自信但错 → 惩罚趋近无穷。
Symbols符号
  • $y\in\{0,1\}$ true binary label (0 or 1) 真实二分类标签 $y\in\{0,1\}$
  • $\hat y\in(0,1)$ predicted probability of class 1, usually $\hat y=\sigma(z)$ where $z$ is the logit 预测的 class 1 概率，通常 $\hat y=\sigma(z)$（$z$ 为 logit）
  • $y\log\hat y$ active when the truth is class 1 $y=1$ 时该项激活
  • $(1-y)\log(1-\hat y)$ active when the truth is class 0 $y=0$ 时该项激活
How to use如何运用
Standard loss for any binary classifier with a sigmoid output: logistic regression, MLP with one sigmoid output unit, the two-layer net in HW3. Combined with the sigmoid logit $z$, the gradient simplifies to $\partial\mathcal{L}/\partial z=\hat y-y$ (see the softmax-CE gradient entry under MLP). For numerical stability use the fused 'BCE-with-logits' form $\log(1+e^{-y'z})$ with $y'\in\{-1,+1\}$. 任意 sigmoid 输出二分类的标准 loss：logistic regression、单 sigmoid 输出的 MLP、HW3 的两层网络都用它。结合 sigmoid logit $z$，梯度简化为 $\partial\mathcal{L}/\partial z=\hat y-y$（见 MLP 的 softmax-CE 梯度项）。代码上为数值稳定常用 fused 'BCE-with-logits'：$\log(1+e^{-y'z})$，$y'\in\{-1,+1\}$。
Gradient descent
$$ w_{t+1}=w_t-\alpha \nabla f(w_t) $$

这个公式在做什么？ 每一步把权重往能降低 loss 的方向挪一点。

▸ Explain 解释
Intuition理解
'Walk against the gradient by step size $\alpha$.' On convex losses (logistic regression is convex), this finds the global minimum; learning-rate tuning is the main practical concern. "沿负梯度走 $\alpha$ 步。" 在凸 loss（logistic regression 凸）上能找到全局最小；实际中调学习率是主要工作。
Symbols符号
  • $w_t$ current weight vector at step $t$ 第 $t$ 步的当前权重向量
  • $w_{t+1}$ updated weights after one step 一步更新后的权重
  • $\alpha$ learning rate (positive scalar) 学习率（正标量）
  • $\nabla f(w_t)$ gradient of the loss at $w_t$ $w_t$ 处 loss 的梯度
How to use如何运用
Generic GD update — works for any differentiable loss, not just logistic. For logistic regression specifically, $\nabla f(w) = -\sum_i y_i \sigma(-y_i w^\top x_i)\, x_i$ (with $\pm 1$ labels). Pick $\alpha$ via line search or schedule. 通用 GD 更新 —— 对任意可微 loss 都适用，不限 logistic。logistic regression 中 $\nabla f(w) = -\sum_i y_i \sigma(-y_i w^\top x_i)\, x_i$（$\pm 1$ 标签下）。$\alpha$ 用 line search 或调度选。
Gradient and IRLS
$$ \nabla L(w)=\sum_i(\mu_i-y_i)x_i,\qquad \mu_i=\sigma(w^\top x_i) $$

这个公式在做什么？ 每个样本用 “概率误差 × 输入” 来推动权重更新。

▸ Explain 解释
Intuition理解
Each example votes to move the weights by 'how wrong the probability is' times its input direction. The shape mirrors linear regression residuals, but the prediction is passed through sigmoid first. 每个样本都按“概率错了多少”乘上自己的输入方向来推动权重。形式像 linear regression 的 residual，只是预测先过了 sigmoid。
Symbols符号
  • $\mu_i$ predicted probability $P(y_i=1\mid x_i)$ 预测概率 $P(y_i=1\mid x_i)$
  • $\mu_i-y_i$ probability residual: predicted minus true label 概率残差：预测值减真实标签
  • $x_i$ input feature vector for example $i$ 第 $i$ 个样本的输入特征向量
  • $\nabla L(w)$ gradient of the 0/1-label negative log-likelihood $0/1$ 标签 negative log-likelihood 的梯度
How to use如何运用
Use this gradient in batch or mini-batch GD. In matrix form it is $X^\top(\mu-y)$. IRLS / Newton pairs it with the Hessian $X^\top B X$ to take second-order steps. 把这个 gradient 放进 batch 或 mini-batch GD。矩阵形式是 $X^\top(\mu-y)$。IRLS / Newton 会把它和 Hessian $X^\top B X$ 配起来做二阶更新。
Convexity check ($y\in\{0,1\}$ form)
$$ \nabla^2 L(w)=X^\top B X,\qquad B=\mathrm{diag}(p_i(1-p_i)) $$

这个公式在做什么？ 说明曲率是 PSD，因此 logistic loss 是 convex。

▸ Explain 解释
Intuition理解
'Variances $p_i(1-p_i)$ are between 0 and 0.25 — never negative.' That non-negativity is what guarantees convexity; without it, the loss could have multiple local minima and GD would be unreliable. "方差 $p_i(1-p_i)$ 在 0 到 0.25 之间 —— 永远非负。" 这个非负性正是凸性的保障；没有它的话，loss 可能有多个局部最小，GD 就不可靠。
Symbols符号
  • $\nabla^2 L(w)$ Hessian of the logistic loss logistic loss 的 Hessian
  • $X$ design matrix (rows are feature vectors) 设计矩阵（行是特征向量）
  • $B = \mathrm{diag}(p_i(1-p_i))$ diagonal of variances $p_i(1-p_i)$ where $p_i = \sigma(w^\top x_i)$ 方差对角阵，$p_i = \sigma(w^\top x_i)$
  • $p_i (1-p_i) \ge 0$ each diagonal entry non-negative ⇒ $B \succeq 0$ 每个对角项非负 ⇒ $B \succeq 0$
How to use如何运用
Use the sandwich identity: $X^\top B X \succeq 0$ when $B \succeq 0$, so the Hessian is PSD everywhere → the logistic loss is convex → gradient descent converges to the global minimum. 用 sandwich 恒等式：$B \succeq 0$ 时 $X^\top B X \succeq 0$，所以 Hessian 处处 PSD → logistic loss 凸 → gradient descent 收敛到全局最小。
Softmax extension
$$ p(y=c\mid x)=\frac{\exp(w_c^\top x)}{\sum_{j=1}^{C}\exp(w_j^\top x)} $$

这个公式在做什么？ 把每个 class 的 score 变成总和为 1 的 probabilities。

▸ Explain 解释
Intuition理解
Softmax is sigmoid's multiclass cousin: every class gets a score, exponentials make higher scores dominate, and the denominator turns the scores into a probability distribution. Softmax 是 sigmoid 的多分类版本：每个 class 一个 score，指数让高 score 占更多概率质量，分母把它们变成概率分布。
Symbols符号
  • $C$ number of classes 类别总数
  • $w_c^\top x$ logit / score for class $c$ class $c$ 的 logit / score
  • $\exp(w_c^\top x)$ positive unnormalized score for class $c$ class $c$ 的正的未归一化分数
  • $\sum_j \exp(w_j^\top x)$ normalizer that makes probabilities sum to 1 让所有概率加起来为 1 的归一化项
How to use如何运用
Use softmax for multiclass logistic regression. Train with multiclass cross-entropy. In numerical code, subtract the maximum logit or use a fused log-sum-exp implementation to avoid overflow. 多分类 logistic regression 用 softmax。训练时配 multiclass cross-entropy。写代码时先减最大 logit，或直接用 fused log-sum-exp 实现，避免 overflow。

5. Worked Examples · 代表性例题

Example A · 为什么边界仍然线性
来源：Lecture 5，概率阈值部分。

如果规定 $p(y=1\mid x)\ge 0.5$ 就预测 +1，那么 $\sigma(w^\top x)\ge 0.5$。Sigmoid 在输入 0 时等于 0.5，所以边界就是 $w^\top x=0$。

Example B · Logistic loss vs. quadratic loss
来源：Lecture 5，和 linear regression 的 loss 对比。

对一个已经正确且 margin 很大的点，quadratic loss 还可能很大，因为它想把 score 拉到某个数字标签附近。Linear regression 还可能输出 $[0,1]$ 之外的“概率”，且对 outliers 敏感；logistic loss 会接近 0，因为模型已经给真实 Bernoulli label 高概率。

Example C · Hessian 证明 convexity
来源：HW1 Problem 4(a-b)，题意转述。

把样本堆叠后 $H=X^\top B X$，其中 $B$ 的对角元非负。对任意 $v$，$v^\top H v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge 0$。所以 logistic loss 是 convex，local minimum 就是 global minimum。

6. Problem-Solving Tips · 解题技巧

先看 label convention。 $y\in\{-1,+1\}$ 用 $\log(1+\exp(-ys))$；$y\in\{0,1\}$ 用 binary cross-entropy。
概率题： 先写 sigmoid，再根据 0.5 threshold 做分类。
凸性题： 写出 Hessian = $X^\top B X$，再看 $v^\top H v$。
优化题： 说清楚一般没有 closed form，需要 gradient descent。
Linear vs. Logistic： 对比 Gaussian regression target 和 Bernoulli class label。多分类里 linear regression 可能 mask 掉中间类别，即使类别本身可分。
Separable data： 未正则化 MLE 可能让 $\|w\|$ 趋向无穷。加 $L_2$ weight decay，例如 $\lambda\|w\|_2^2$，可以让解有限并改善泛化。
XOR： 单个 logistic-regression boundary 解不了 XOR；需要 nonlinear features 或 MLP 这样的 hidden layer。

7. Common Mistakes · 常见错误

  • 因为 sigmoid 非线性就说 logistic regression 的边界非线性；其实 boundary 在 $\phi(x)$ 空间仍是 linear。
  • 把 $y\in\{0,1\}$ 和 $y\in\{-1,+1\}$ 的公式混着用。
  • 期待像 linear regression 一样有 normal equation closed form。
  • 写 dataset likelihood 时忘记 i.i.d. assumption。
  • 忘记 perfectly separable data 会让 unregularized MLE 追逐无限大的 weights。

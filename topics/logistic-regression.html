🎯 Logistic Regression

Logistic regression is the linear classifier from Lecture 5 that turns a score into a probability and trains by maximum likelihood instead of squared error.

1. Concept Understanding

For binary labels $y\in\{-1,+1\}$, logistic regression computes a linear score $s=w^\top\phi(x)$ and converts it into a class probability:

$$ p(y\mid x)=\frac{1}{1+\exp(-y\,w^\top\phi(x))} $$

It is a discriminative model: it directly models $p(y\mid x;\theta)$ instead of modeling the joint distribution $p(x,y)$ as Naive Bayes does. A bias term can be written explicitly as $a=w^\top x+b$, or absorbed into $\phi(x)$ by adding a constant feature.

The concept solves the classification weakness of linear regression: we want a loss that cares about correct signs and probability confidence, not about matching labels as numeric targets.

2. Plain-English Explanation

Think of $w^\top x$ as a confidence meter. Large positive means “class +1 looks likely,” large negative means “class -1 looks likely,” and near zero means “I am unsure.”

The sigmoid squeezes that meter into a probability between 0 and 1. The log loss then asks: did the model assign high probability to the true class?

3. Core Intuition

Linear regression with MSE keeps pulling on easy examples even after they are classified correctly. Logistic loss mostly cares about the margin $y\,w^\top\phi(x)$: if the margin is large and positive, the loss is tiny; if it is negative, the loss grows quickly.

The model is probabilistic. Under the i.i.d. assumption, maximizing the likelihood of all labels is equivalent to minimizing negative log-likelihood. There is usually no closed form, so Lecture 5 uses gradient descent.

4. Key Equations

Sigmoid
$$ \sigma(z)=\frac{1}{1+e^{-z}} $$

Symbols. $z$ is any real-valued score, usually $z=w^\top\phi(x)$; $e^{-z}$ is the exponential term; $\sigma(z)$ is the predicted probability of the positive class.

How to read it. The sigmoid turns an unbounded score into a number between 0 and 1. If $z$ is large positive, $e^{-z}$ is tiny and $\sigma(z)\approx1$; if $z$ is large negative, $\sigma(z)\approx0$.

How to use. Compute the score first, then plug it into $\sigma$. Since $\sigma(0)=0.5$, probability-threshold classification at 0.5 is the same as checking whether the score is positive.

Derivative. $\sigma'(z)=\sigma(z)(1-\sigma(z))$, the identity that makes logistic-regression gradients and sigmoid backprop collapse cleanly.

Logit / log-odds
$$ \log\frac{p}{1-p}=w^\top\phi(x)+b $$

Symbols. $p=p(y=1\mid x)$, so $\frac{p}{1-p}$ is the odds of class 1 against class 0. The logit is the inverse of the sigmoid.

How to read it. Logistic regression is linear in log-odds, not linear in probability. A one-unit increase in a feature shifts the log-odds by its weight.

How to use. If an exam asks why the boundary is linear, set $p=0.5$. The log-odds become $\log 1=0$, so the boundary is exactly $w^\top\phi(x)+b=0$.

Decision boundary
$$ p(y=1\mid x)=0.5 \iff w^\top\phi(x)=0 $$

Symbols. $p(y=1\mid x)$ is the model's probability for class $+1$; $w$ is the learned weight vector; $\phi(x)$ is the feature representation; $w^\top\phi(x)$ is the score.

How to read it. The boundary is where the model is exactly unsure: positive class and negative class are tied. Because sigmoid is monotone, the tie happens exactly at score 0.

How to use. For classification, compute $w^\top\phi(x)$. Positive score predicts $+1$; negative score predicts $-1$. The boundary is linear in feature space even though the probability curve is nonlinear.

Negative log-likelihood
$$ \min_w \sum_{(x_i,y_i)\in D}\log\!\left(1+\exp(-y_i w^\top\phi(x_i))\right) $$

Symbols. $D$ is the training set; $x_i$ is example $i$; $y_i\in\{-1,+1\}$ is its label; $w^\top\phi(x_i)$ is the score; $y_iw^\top\phi(x_i)$ is the signed margin.

How to read it. If the signed margin is large positive, the true label got high probability and the log term is near 0. If the margin is negative, the model is confidently wrong and the loss becomes large.

How to use. Sum this term over all training examples, then minimize with gradient-based optimization. Do not mix this $y\in\{-1,+1\}$ form with the $y\in\{0,1\}$ cross-entropy form unless you convert labels.

Binary cross-entropy (BCE)
$$ \mathcal{L}(y,\hat y)=-\bigl(y\log\hat y+(1-y)\log(1-\hat y)\bigr) $$

This is the same logistic-regression loss as the NLL above, just rewritten with the $y\in\{0,1\}$ label convention and an explicit predicted probability $\hat y$. It's the form you'll see in every neural-net library, and the form HW3 asks you to backprop through.

$$ \mathrm{NLL}(w)=-\frac{1}{N}\sum_{n=1}^{N}\left[y_n\log\mu_n+(1-y_n)\log(1-\mu_n)\right],\qquad \mu_n=\sigma(w^\top x_n) $$

Symbols. $y\in\{0,1\}$ is the true binary label; $\hat y\in(0,1)$ is the model's predicted probability of class 1, almost always $\hat y=\sigma(z)$ where $z$ is the logit $w^\top x$ (or the output of a deeper net). The two terms are mutually exclusive — only one is "on" for any given example.

How to read it. When $y=1$, the second term vanishes and you're left with $-\log\hat y$ — penalty grows when $\hat y$ is far below 1. When $y=0$, the first term vanishes and you're left with $-\log(1-\hat y)$ — penalty grows when $\hat y$ is far above 0. Confidently wrong → unbounded penalty.

How to use. Sum (or average) this loss over a mini-batch and minimize via gradient descent. Combined with the sigmoid logit $z$, the gradient famously simplifies to $\partial\mathcal{L}/\partial z=\hat y-y$ (see the MLP page's Softmax + cross-entropy output gradient entry — same identity, $K=2$ collapse). For numerical stability, frameworks fuse sigmoid and BCE into one op (BCEWithLogitsLoss), equivalent to the $\log(1+\exp(-yz))$ softplus form above with $y\in\{-1,+1\}$.

Where it shows up. HW3 §1 (two-layer net binary classifier — write forward pass + BCE loss + backprop), every MLP example with a single sigmoid output unit, the Bernoulli-likelihood term inside VAE / diffusion ELBOs.

Gradient descent update
$$ w_{t+1}=w_t-\alpha \nabla f(w_t) $$

Symbols. $w_t$ is the current parameter vector; $\alpha$ is the learning rate / step size; $f(w)$ is the logistic objective; $\nabla f(w_t)$ points in the steepest increasing direction of loss.

How to read it. Move opposite the gradient because we want to reduce loss. A larger $\alpha$ moves faster but can overshoot; a smaller $\alpha$ is safer but slower.

How to use. Repeatedly compute predicted probabilities, form the gradient, and update $w$. Logistic regression generally has no normal-equation closed form.

Gradient and IRLS
$$ \nabla L(w)=\sum_i(\mu_i-y_i)x_i,\qquad \mu_i=\sigma(w^\top x_i) $$

How to read it. The first-order gradient is predicted probability minus target, times the input. This is the logistic version of “error times feature.”

How to use. Gradient descent uses only this gradient. Newton's method also uses the Hessian and is often called IRLS (Iteratively Reweighted Least Squares) for logistic regression; it can converge faster but each step is more expensive.

Convexity check for $y\in\{0,1\}$ form
$$ \nabla^2 L(w)=X^\top B X,\qquad B=\mathrm{diag}(p_i(1-p_i)) $$

Symbols. $X$ is the design matrix with rows $x_i^\top$; $p_i=\sigma(w^\top x_i)$; $B$ is diagonal, with one curvature weight $p_i(1-p_i)$ per example.

How to read it. $p_i(1-p_i)$ is never negative, so $B$ is positive semidefinite. The sandwich form $X^\top B X$ therefore has nonnegative quadratic form $v^\top X^\top B Xv$.

How to use. For convexity proofs, write $v^\top\nabla^2L(w)v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge0$. It is strictly convex when the relevant design matrix has full column rank, so any local minimum is global.

Softmax extension
$$ p(y=c\mid x)=\frac{\exp(w_c^\top x)}{\sum_{j=1}^{C}\exp(w_j^\top x)} $$

How to read it. Binary sigmoid becomes softmax for $C$ classes. Each class gets its own score, and the normalization makes all probabilities sum to 1.

How to use. In numerical work, subtract the largest score or use the log-sum-exp trick before exponentiating; direct exponentials can overflow.

5. Worked Examples

Example A · Why the boundary is still linear
Source: Lecture 5, probability-threshold slide.

If the classifier predicts +1 when $p(y=1\mid x)\ge 0.5$, then $\sigma(w^\top x)\ge 0.5$. Since sigmoid crosses 0.5 at input 0, this is exactly $w^\top x\ge 0$.

Example B · Logistic vs. linear loss
Source: Lecture 5, comparison with quadratic loss.

For a correctly classified point with large positive margin, quadratic classification loss can still be large because it tries to make the score close to the numeric label. Linear regression can also output values outside $[0,1]$ and is sensitive to outliers. Logistic loss becomes close to zero because the model already assigns high probability to the correct Bernoulli label.

Example C · Hessian proves convexity
Source: HW1 Problem 4(a-b), paraphrased.

Stacking examples gives $H=X^\top B X$ with nonnegative diagonal $B$. For any vector $v$, $v^\top H v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge 0$. Therefore logistic loss is convex, so local minima are global minima.

6. Problem-Solving Tips

Identify the label convention. Use $\log(1+\exp(-y s))$ for $y\in\{-1,+1\}$ and binary cross-entropy for $y\in\{0,1\}$.
For probability questions, write the sigmoid first, then threshold at 0.5 if classification is required.
For convexity questions, show the Hessian is $X^\top B X$ and test $v^\top H v$.
For optimization questions, say “no closed form in general; use gradient descent.”
For linear-vs-logistic questions, contrast Gaussian regression targets with Bernoulli class labels. In multiclass classification, linear regression can mask an intermediate class even when the classes are separable.
For separable data, unregularized MLE may send $\|w\|$ toward infinity. Add $L_2$ weight decay, such as $\lambda\|w\|_2^2$, to keep the solution finite and improve generalization.
For XOR, a single logistic-regression boundary cannot solve it. You need nonlinear features or a hidden layer such as an MLP.

7. Common Mistakes

  • Calling logistic regression nonlinear because sigmoid is nonlinear. The decision boundary is still linear in $\phi(x)$.
  • Mixing $y\in\{0,1\}$ and $y\in\{-1,+1\}$ formulas without converting.
  • Expecting a normal-equation closed form like linear regression.
  • Forgetting the i.i.d. assumption when multiplying likelihoods over the dataset.
  • Forgetting that perfectly separable data makes unregularized MLE chase infinite weights.

8. Exam Focus

  • Write the sigmoid probability model and NLL objective.
  • Explain why logistic loss fixes the MSE-for-classification issue.
  • Derive or recognize the gradient form used by gradient descent.
  • Use $H=X^\top B X$ to prove convexity.
  • Explain why the decision boundary is $w^\top\phi(x)=0$.
  • Know the log-odds interpretation, the softmax multiclass extension, and why log-sum-exp is used for numerical stability.

🎯 Logistic Regression · 逻辑回归

Logistic Regression 是 Lecture 5 的核心：把 linear score 变成 probability，用 maximum likelihood / NLL 来训练，而不是用 squared error 硬拟合分类标签。

1. Concept Understanding · 概念理解

对二分类 $y\in\{-1,+1\}$，模型先算 score $s=w^\top\phi(x)$，再把它变成真实类别的概率：

$$ p(y\mid x)=\frac{1}{1+\exp(-y\,w^\top\phi(x))} $$

它是 discriminative model：直接建模 $p(y\mid x;\theta)$，而不是像 Naive Bayes 那样建模 joint distribution $p(x,y)$。Bias 可以显式写成 $a=w^\top x+b$，也可以把常数 1 加进 $\phi(x)$ 里吸收掉。

它解决的是 linear regression 做 classification 的问题：分类更关心 sign 和 confidence，而不是把标签当普通数字去拟合。

2. Plain-English Explanation · 大白话理解

把 $w^\top x$ 想成一个“信心条”。很正表示更像 +1，很负表示更像 -1，接近 0 表示不确定。

Sigmoid 把这个信心条压到 0 到 1 之间，变成 probability。Log loss 问的是：你有没有给真实类别足够高的概率？

3. Core Intuition · 核心直觉

MSE 会一直拉扯 easy examples，即使它们已经分类正确。Logistic loss 主要看 margin $y\,w^\top\phi(x)$：margin 很大且为正时 loss 很小；margin 为负时 loss 快速变大。

从概率角度看，样本 i.i.d. 时，最大化整份 dataset 的 likelihood 等价于最小化 negative log-likelihood。一般没有 closed form，所以用 gradient descent。

4. Key Equations · 核心公式

Sigmoid
$$ \sigma(z)=\frac{1}{1+e^{-z}} $$

符号. $z$ 是任意 real-valued score，通常 $z=w^\top\phi(x)$；$e^{-z}$ 是 exponential term；$\sigma(z)$ 是 positive class 的预测概率。

怎么理解. Sigmoid 把无限范围的 score 压到 0 到 1。$z$ 很大为正时 $\sigma(z)\approx1$；$z$ 很大为负时 $\sigma(z)\approx0$。

怎么用. 先算 score，再代入 $\sigma$。因为 $\sigma(0)=0.5$，用 0.5 做阈值分类等价于看 score 是否大于 0。

导数. $\sigma'(z)=\sigma(z)(1-\sigma(z))$，这是 logistic regression gradient 和 sigmoid backprop 能简化的关键恒等式。

Logit / log-odds
$$ \log\frac{p}{1-p}=w^\top\phi(x)+b $$

符号. $p=p(y=1\mid x)$；$\frac{p}{1-p}$ 是 class 1 相对 class 0 的 odds；logit 是 sigmoid 的 inverse。

怎么理解. Logistic Regression 对 probability 不是线性的，对 log-odds 是线性的。某个 feature 增加 1，会让 log-odds 改变对应 weight。

怎么用. 考 boundary 时令 $p=0.5$，log-odds 变成 $\log 1=0$，所以 boundary 正是 $w^\top\phi(x)+b=0$。

Decision boundary
$$ p(y=1\mid x)=0.5 \iff w^\top\phi(x)=0 $$

符号. $p(y=1\mid x)$ 是 class $+1$ 的概率；$w$ 是 learned weight；$\phi(x)$ 是 feature representation；$w^\top\phi(x)$ 是 score。

怎么理解. Boundary 是模型刚好不确定的位置：正负类概率打平。Sigmoid 单调，所以概率等于 0.5 正好对应 score = 0。

怎么用. 分类时直接算 $w^\top\phi(x)$：正数预测 $+1$，负数预测 $-1$。Probability curve 非线性，但 boundary 在 feature space 中仍然 linear。

NLL / log loss
$$ \min_w \sum_{(x_i,y_i)\in D}\log\!\left(1+\exp(-y_i w^\top\phi(x_i))\right) $$

符号. $D$ 是 training set；$x_i$ 是第 $i$ 个样本；$y_i\in\{-1,+1\}$ 是标签；$w^\top\phi(x_i)$ 是 score；$y_iw^\top\phi(x_i)$ 是 signed margin。

怎么理解. Signed margin 很大为正时，真实标签概率高，loss 接近 0；margin 为负时，模型方向错了，loss 会快速变大。

怎么用. 对所有样本求和后用 gradient descent 最小化。注意不要和 $y\in\{0,1\}$ 的 cross-entropy 公式混用，除非先转换标签。

Binary cross-entropy (BCE)
$$ \mathcal{L}(y,\hat y)=-\bigl(y\log\hat y+(1-y)\log(1-\hat y)\bigr) $$

这就是上面那条 NLL，只不过换成了 $y\in\{0,1\}$ 的标签约定，并直接写出预测概率 $\hat y$。所有 deep learning library 用的就是这个形式，HW3 要你手动 backprop 的也是它。

$$ \mathrm{NLL}(w)=-\frac{1}{N}\sum_{n=1}^{N}\left[y_n\log\mu_n+(1-y_n)\log(1-\mu_n)\right],\qquad \mu_n=\sigma(w^\top x_n) $$

符号. $y\in\{0,1\}$ 是真实二分类标签；$\hat y\in(0,1)$ 是模型预测的 class 1 probability，几乎一定是 $\hat y=\sigma(z)$，其中 $z$ 是 logit $w^\top x$（或更深网络的输出）。两个 $\log$ 项互斥，对任意单个样本只有一项会激活。

怎么理解. $y=1$ 时第二项消失，剩下 $-\log\hat y$ —— $\hat y$ 越远离 1，惩罚越大；$y=0$ 时第一项消失，剩下 $-\log(1-\hat y)$ —— $\hat y$ 越远离 0，惩罚越大。自信但错 → 惩罚趋近无穷。

怎么用. 对一个 mini-batch 求和（或求平均），用 gradient descent 最小化。配合 sigmoid logit $z$，梯度漂亮地塌成 $\partial\mathcal{L}/\partial z=\hat y-y$（见 MLP 页的 Softmax + cross-entropy output gradient 项 —— 同一恒等式，$K=2$ 退化）。代码上为了数值稳定，框架把 sigmoid 和 BCE 融合成一个 op（BCEWithLogitsLoss），等价于上面 $y\in\{-1,+1\}$ 形式的 $\log(1+\exp(-yz))$ softplus。

典型出处. HW3 §1（两层网二分类 —— 写 forward + BCE loss + backprop）；任何带单个 sigmoid 输出的 MLP example；VAE / diffusion ELBO 里的 Bernoulli likelihood term。

Gradient descent
$$ w_{t+1}=w_t-\alpha \nabla f(w_t) $$

符号. $w_t$ 是当前参数；$\alpha$ 是 learning rate；$f(w)$ 是 logistic objective；$\nabla f(w_t)$ 是 loss 增长最快方向。

怎么理解. 要让 loss 下降，就往 gradient 的反方向走。$\alpha$ 太大可能 overshoot，太小会很慢。

怎么用. 每轮算 probability、算 gradient、更新 $w$。Logistic regression 一般没有 normal equation closed form。

Gradient and IRLS
$$ \nabla L(w)=\sum_i(\mu_i-y_i)x_i,\qquad \mu_i=\sigma(w^\top x_i) $$

怎么理解. 一阶 gradient 是 predicted probability minus target，再乘 input，也就是 logistic 版本的“error times feature”。

怎么用. Gradient descent 只用这个 gradient。Newton's method 还会用 Hessian，在 logistic regression 里常叫 IRLS (Iteratively Reweighted Least Squares)；收敛可能更快，但每一步更贵。

Convexity check ($y\in\{0,1\}$ form)
$$ \nabla^2 L(w)=X^\top B X,\qquad B=\mathrm{diag}(p_i(1-p_i)) $$

符号. $X$ 是 design matrix，每行是 $x_i^\top$；$p_i=\sigma(w^\top x_i)$；$B$ 是 diagonal matrix，每个对角元是样本 $i$ 的 curvature weight $p_i(1-p_i)$。

怎么理解. $p_i(1-p_i)$ 永远非负，所以 $B$ 是 positive semidefinite；夹心形式 $X^\top B X$ 的二次型也非负。

怎么用. 证明 convexity 时写：$v^\top\nabla^2L(w)v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge0$。当相关 design matrix full column rank 时是 strictly convex，所以 local minimum 就是 global minimum。

Softmax extension
$$ p(y=c\mid x)=\frac{\exp(w_c^\top x)}{\sum_{j=1}^{C}\exp(w_j^\top x)} $$

怎么理解. 二分类 sigmoid 推广到 $C$ 类就是 softmax。每个 class 有一个 score，归一化后所有 class probabilities 加起来等于 1。

怎么用. 数值计算时先减最大 score，或直接用 log-sum-exp trick；裸算 exponential 容易 overflow。

5. Worked Examples · 代表性例题

Example A · 为什么边界仍然线性
来源：Lecture 5，概率阈值部分。

如果规定 $p(y=1\mid x)\ge 0.5$ 就预测 +1，那么 $\sigma(w^\top x)\ge 0.5$。Sigmoid 在输入 0 时等于 0.5，所以边界就是 $w^\top x=0$。

Example B · Logistic loss vs. quadratic loss
来源：Lecture 5，和 linear regression 的 loss 对比。

对一个已经正确且 margin 很大的点，quadratic loss 还可能很大，因为它想把 score 拉到某个数字标签附近。Linear regression 还可能输出 $[0,1]$ 之外的“概率”，且对 outliers 敏感；logistic loss 会接近 0，因为模型已经给真实 Bernoulli label 高概率。

Example C · Hessian 证明 convexity
来源：HW1 Problem 4(a-b)，题意转述。

把样本堆叠后 $H=X^\top B X$，其中 $B$ 的对角元非负。对任意 $v$，$v^\top H v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge 0$。所以 logistic loss 是 convex，local minimum 就是 global minimum。

6. Problem-Solving Tips · 解题技巧

先看 label convention。 $y\in\{-1,+1\}$ 用 $\log(1+\exp(-ys))$；$y\in\{0,1\}$ 用 binary cross-entropy。
概率题： 先写 sigmoid，再根据 0.5 threshold 做分类。
凸性题： 写出 Hessian = $X^\top B X$，再看 $v^\top H v$。
优化题： 说清楚一般没有 closed form，需要 gradient descent。
Linear vs. Logistic： 对比 Gaussian regression target 和 Bernoulli class label。多分类里 linear regression 可能 mask 掉中间类别，即使类别本身可分。
Separable data： 未正则化 MLE 可能让 $\|w\|$ 趋向无穷。加 $L_2$ weight decay，例如 $\lambda\|w\|_2^2$，可以让解有限并改善泛化。
XOR： 单个 logistic-regression boundary 解不了 XOR；需要 nonlinear features 或 MLP 这样的 hidden layer。

7. Common Mistakes · 常见错误

  • 因为 sigmoid 非线性就说 logistic regression 的边界非线性；其实 boundary 在 $\phi(x)$ 空间仍是 linear。
  • 把 $y\in\{0,1\}$ 和 $y\in\{-1,+1\}$ 的公式混着用。
  • 期待像 linear regression 一样有 normal equation closed form。
  • 写 dataset likelihood 时忘记 i.i.d. assumption。
  • 忘记 perfectly separable data 会让 unregularized MLE 追逐无限大的 weights。

🎯 Logistic Regression

Logistic regression is the linear classifier from Lecture 5 that turns a score into a probability and trains by maximum likelihood instead of squared error.

1. Concept Understanding

For binary labels $y\in\{-1,+1\}$, logistic regression computes a linear score $s=w^\top\phi(x)$ and converts it into a class probability:

$$ p(y\mid x)=\frac{1}{1+\exp(-y\,w^\top\phi(x))} $$

It is a discriminative model: it directly models $p(y\mid x;\theta)$ instead of modeling the joint distribution $p(x,y)$ as Naive Bayes does. A bias term can be written explicitly as $a=w^\top x+b$, or absorbed into $\phi(x)$ by adding a constant feature.

The concept solves the classification weakness of linear regression: we want a loss that cares about correct signs and probability confidence, not about matching labels as numeric targets.

2. Plain-English Explanation

Think of $w^\top x$ as a confidence meter. Large positive means “class +1 looks likely,” large negative means “class -1 looks likely,” and near zero means “I am unsure.”

The sigmoid squeezes that meter into a probability between 0 and 1. The log loss then asks: did the model assign high probability to the true class?

3. Core Intuition

Linear regression with MSE keeps pulling on easy examples even after they are classified correctly. Logistic loss mostly cares about the margin $y\,w^\top\phi(x)$: if the margin is large and positive, the loss is tiny; if it is negative, the loss grows quickly.

The model is probabilistic. Under the i.i.d. assumption, maximizing the likelihood of all labels is equivalent to minimizing negative log-likelihood. There is usually no closed form, so Lecture 5 uses gradient descent.

4. Key Equations

Sigmoid
$$ \sigma(z)=\frac{1}{1+e^{-z}} $$

What it does. Turns an unbounded logit $z$ into a class-1 probability. Remember $\sigma(0)=0.5$ and $\sigma'(z)=\sigma(z)(1-\sigma(z))$.

📖 Symbols, intuition & usage

Symbols. $z$ is any real-valued logit, almost always $z=w^\top\phi(x)$ (or $w^\top x+b$); $\sigma(z)\in(0,1)$ is the predicted probability of the positive class; $e^{-z}$ is the exponential factor in the denominator.

How to read it. An S-curve squashing any score into $(0,1)$. $\sigma(0)=0.5$; large positive $z\to 1$; large negative $z\to 0$. The curve saturates at the extremes — that's why "very confident" predictions get tiny gradients (one source of vanishing gradients in deep nets).

How to use. Compute the linear score first, then plug into $\sigma$. Thresholding at $0.5$ for classification is equivalent to checking whether $z>0$. Memorize $\sigma'(z)=\sigma(z)(1-\sigma(z))$ — it's the identity that makes logistic-regression gradients and sigmoid backprop steps collapse cleanly.

Logit / log-odds
$$ \log\frac{p}{1-p}=w^\top\phi(x)+b $$

What it does. Says the model is linear in log-odds, not in raw probability. Setting $p=0.5$ gives log-odds $0$, so the boundary is linear.

📖 Symbols, intuition & usage

Symbols. $p=p(y=1\mid x)$ is the model's class-1 probability; $p/(1-p)$ is the odds of class 1 against class 0; the LHS $\log(p/(1-p))$ is the logit (the inverse of $\sigma$); $w$ are weights and $b$ is bias.

How to read it. Logistic regression is linear in log-odds, not in raw probability. A one-unit increase in feature $j$ shifts the log-odds by exactly $w_j$ — so $w_j$ has a clean interpretive meaning (an "odds-multiplier" of $e^{w_j}$).

How to use. To answer "why is the boundary linear?" on an exam, set $p=0.5$ — log-odds become $\log 1=0$, so the boundary is exactly $w^\top\phi(x)+b=0$. To convert log-odds back to a probability, apply $\sigma$.

Decision boundary
$$ p(y=1\mid x)=0.5 \iff w^\top\phi(x)=0 $$

What it does. Connects probability thresholding to a sign test: classify by whether the score is above or below zero.

📖 Symbols, intuition & usage

Symbols. $p(y=1\mid x)$ is the model's predicted probability for class $+1$; $w$ is the learned weight vector; $\phi(x)$ is the feature representation (identity for plain logistic regression); $w^\top\phi(x)$ is the linear score.

How to read it. The boundary is the locus of points where the model is exactly indifferent — both classes tied at probability $0.5$. Sigmoid is monotone, so the tie happens exactly at score $0$. The boundary is linear in feature space even though the probability curve is nonlinear, which is why logistic regression is still called a linear classifier despite the sigmoid output.

How to use. For classification, compute $w^\top\phi(x)$: positive score → predict $+1$, negative score → predict $-1$. To draw the boundary, solve $w^\top\phi(x)+b=0$ — for 2D plain logistic this is a line.

Negative log-likelihood
$$ \min_w \sum_{(x_i,y_i)\in D}\log\!\left(1+\exp(-y_i w^\top\phi(x_i))\right) $$

What it does. Trains the classifier by penalizing negative or weak margins. This is the $y\in\{-1,+1\}$ form of logistic loss.

📖 Symbols, intuition & usage

Symbols. $D$ is the training set; $y_i\in\{-1,+1\}$ is the label; $w^\top\phi(x_i)$ is the score; $y_i w^\top\phi(x_i)$ is the signed margin; $\log(1+e^{-z})$ is the softplus — a smooth approximation of $\max(0,-z)$.

How to read it. Confidently correct (large positive margin) → loss $\approx 0$; confidently wrong (negative margin) → loss grows roughly linearly in $|z|$. Always non-negative; convex and differentiable, so SGD works cleanly. Comes from maximizing the i.i.d. Bernoulli likelihood, then taking $-\log$.

How to use. Sum this term over all training examples and minimize via gradient descent. Add an L2 regularizer $\tfrac{\lambda}{2}\|w\|^2$ for ridge-style logistic regression. Don't mix this with the $\{0,1\}$ BCE form unless you convert labels first ($y_{01}=(y_{\pm 1}+1)/2$).

Binary cross-entropy (BCE)
$$ \mathcal{L}(y,\hat y)=-\bigl(y\log\hat y+(1-y)\log(1-\hat y)\bigr) $$
$$ \mathrm{NLL}(w)=-\frac{1}{N}\sum_{n=1}^{N}\left[y_n\log\mu_n+(1-y_n)\log(1-\mu_n)\right],\qquad \mu_n=\sigma(w^\top x_n) $$

What it does. Same NLL with $y\in\{0,1\}$ labels: reward high probability on the true class, punish confident wrong predictions. With logits, the gradient collapses to $\hat y-y$.

📖 Symbols, intuition & usage

Symbols. $y\in\{0,1\}$ is the true binary label; $\hat y=\sigma(z)\in(0,1)$ is the predicted class-1 probability with logit $z$; $\mu_n=\sigma(w^\top x_n)$ in the dataset form; the two log terms are mutually exclusive — only one is "on" per example.

How to read it. $y=1$ keeps $-\log\hat y$ (penalty grows when $\hat y$ is far below 1); $y=0$ keeps $-\log(1-\hat y)$ (penalty grows when $\hat y$ is far above 0). Confidently wrong → unbounded penalty. Same loss as the $\pm 1$ NLL above with labels converted; this is the form every neural-net library uses.

How to use. Standard loss for any sigmoid-output binary classifier (logistic regression, MLP single-sigmoid output, HW3 two-layer net). With the underlying logit, the gradient famously collapses to $\partial\mathcal{L}/\partial z=\hat y-y$. For numerical stability use the fused BCEWithLogitsLoss (computes the softplus form internally instead of $\log(\sigma(z))$).

Gradient descent update
$$ w_{t+1}=w_t-\alpha \nabla f(w_t) $$

What it does. Gives the iterative training step: move weights opposite the loss gradient because logistic regression has no normal-equation closed form.

📖 Symbols, intuition & usage

Symbols. $w_t$ is the current weight vector; $\alpha>0$ is the learning rate / step size; $\nabla f(w_t)$ is the gradient of the logistic objective $f$ at $w_t$ — the steepest ascent direction (the minus sign turns it into descent).

How to read it. Larger $\alpha$ moves faster but can overshoot the minimum; smaller $\alpha$ is safer but slower. Logistic regression has no closed-form solution unlike linear regression's normal equations, so iteration is mandatory; convexity of the loss guarantees that GD converges to the global minimum from any start.

How to use. Each round: (i) compute $\mu_i=\sigma(w^\top x_i)$, (ii) form $\nabla L(w)=\sum_i(\mu_i-y_i)x_i$ (next entry), (iii) update $w$. Pick $\alpha$ via line search, an exponential schedule, or the Lipschitz-based safe value $1/L$ where $L=\tfrac14\sigma_{\max}(X^\top X)$.

Gradient and IRLS
$$ \nabla L(w)=\sum_i(\mu_i-y_i)x_i,\qquad \mu_i=\sigma(w^\top x_i) $$

What it does. Shows the useful gradient shape: probability error times input. IRLS/Newton uses this with curvature for faster but heavier steps.

📖 Symbols, intuition & usage

Symbols. $\nabla L$ is the gradient of the $\{0,1\}$ NLL; $\mu_i\in(0,1)$ is the predicted class-1 probability for sample $i$; $(\mu_i-y_i)$ is the residual (predicted − true), bounded in $[-1,1]$.

How to read it. Beautiful "probability error times input" form — directly mirrors linear regression's normal-equation residual structure $X^\top(\hat y-y)$, just with $\sigma$-mapped predictions instead of raw scores. In matrix form, $\nabla L(w)=X^\top(\mu-y)$.

How to use. Drop into mini-batch SGD as is. IRLS (Iteratively Reweighted Least Squares) / Newton's method combines this gradient with the $X^\top BX$ Hessian (next entry) to take a quasi-second-order step $w_{t+1}=w_t-(X^\top B X)^{-1}X^\top(\mu-y)$ — converges in $O(\log\log(1/\epsilon))$ iterations but each step costs an $O(d^3)$ matrix solve, so it's only worth it when $d$ is moderate.

Convexity check for $y\in\{0,1\}$ form
$$ \nabla^2 L(w)=X^\top B X,\qquad B=\mathrm{diag}(p_i(1-p_i)) $$

What it does. Proves logistic loss is convex: $B$ has nonnegative diagonal entries, so $X^\top B X$ is PSD and local minima are global under rank conditions.

📖 Symbols, intuition & usage

Symbols. $X$ is the design matrix with rows $x_i^\top$; $p_i=\sigma(w^\top x_i)$ is the predicted probability for sample $i$; $B$ is diagonal with entries $p_i(1-p_i)\in[0,\tfrac14]$ — the per-sample curvature weight (peaked at $0.25$ when $p_i=0.5$, vanishing as $p_i\to 0$ or $1$).

How to read it. Each $p_i(1-p_i)$ is non-negative, so $B\succeq 0$ (PSD). By the sandwich identity (see linear-algebra page), $X^\top BX$ is PSD too, so the Hessian is PSD everywhere → loss is globally convex. Saturated samples ($p_i$ near 0 or 1) contribute almost zero curvature — that's why "easy" examples don't pull on the optimum once they're confidently classified.

How to use. For a convexity proof, expand $v^\top\nabla^2 L(w)v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge 0$. Hence local minima are global, and the optimum is unique when $X$ has full column rank with at least one $p_i\in(0,1)$. The same Hessian appears in IRLS / Newton's method (previous entry) as the second-order curvature term.

Softmax extension
$$ p(y=c\mid x)=\frac{\exp(w_c^\top x)}{\sum_{j=1}^{C}\exp(w_j^\top x)} $$

What it does. Extends sigmoid to $C$ classes by normalizing one score per class into probabilities that sum to 1. Use log-sum-exp for stable computation.

📖 Symbols, intuition & usage

Symbols. $C$ is the number of classes; $w_c$ is the per-class weight vector ($C$ vectors total — one per class); the numerator $\exp(w_c^\top x)$ is the unnormalized class-$c$ score; the denominator normalizes outputs to sum to 1.

How to read it. Multi-class generalization of sigmoid. Larger logits get exponentially more probability mass; $C=2$ collapses back to sigmoid after the parameterization shift $w=w_1-w_0$. Note the model is over-parameterized — adding the same constant to every $w_c$ leaves probabilities unchanged, so usually one class is held fixed at $w_C=0$ to remove the redundancy.

How to use. Train with multi-class cross-entropy $-\sum_c y_c\log\hat y_c$ on one-hot $y$; the gradient at logits is again $\hat y - y$ — the same clean "predicted minus truth" identity as binary BCE. Subtract $\max_j z_j$ before exponentiating for numerical stability, or use the fused log-sum-exp / CrossEntropyLoss op.

5. Worked Examples

Example A · Why the boundary is still linear
Source: Lecture 5, probability-threshold slide.

If the classifier predicts +1 when $p(y=1\mid x)\ge 0.5$, then $\sigma(w^\top x)\ge 0.5$. Since sigmoid crosses 0.5 at input 0, this is exactly $w^\top x\ge 0$.

Example B · Logistic vs. linear loss
Source: Lecture 5, comparison with quadratic loss.

For a correctly classified point with large positive margin, quadratic classification loss can still be large because it tries to make the score close to the numeric label. Linear regression can also output values outside $[0,1]$ and is sensitive to outliers. Logistic loss becomes close to zero because the model already assigns high probability to the correct Bernoulli label.

Example C · Hessian proves convexity
Source: HW1 Problem 4(a-b), paraphrased.

Stacking examples gives $H=X^\top B X$ with nonnegative diagonal $B$. For any vector $v$, $v^\top H v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge 0$. Therefore logistic loss is convex, so local minima are global minima.

6. Problem-Solving Tips

Identify the label convention. Use $\log(1+\exp(-y s))$ for $y\in\{-1,+1\}$ and binary cross-entropy for $y\in\{0,1\}$.
For probability questions, write the sigmoid first, then threshold at 0.5 if classification is required.
For convexity questions, show the Hessian is $X^\top B X$ and test $v^\top H v$.
For optimization questions, say “no closed form in general; use gradient descent.”
For linear-vs-logistic questions, contrast Gaussian regression targets with Bernoulli class labels. In multiclass classification, linear regression can mask an intermediate class even when the classes are separable.
For separable data, unregularized MLE may send $\|w\|$ toward infinity. Add $L_2$ weight decay, such as $\lambda\|w\|_2^2$, to keep the solution finite and improve generalization.
For XOR, a single logistic-regression boundary cannot solve it. You need nonlinear features or a hidden layer such as an MLP.

7. Common Mistakes

  • Calling logistic regression nonlinear because sigmoid is nonlinear. The decision boundary is still linear in $\phi(x)$.
  • Mixing $y\in\{0,1\}$ and $y\in\{-1,+1\}$ formulas without converting.
  • Expecting a normal-equation closed form like linear regression.
  • Forgetting the i.i.d. assumption when multiplying likelihoods over the dataset.
  • Forgetting that perfectly separable data makes unregularized MLE chase infinite weights.

🎯 Logistic Regression · 逻辑回归

Logistic Regression 是 Lecture 5 的核心：把 linear score 变成 probability，用 maximum likelihood / NLL 来训练，而不是用 squared error 硬拟合分类标签。

1. Concept Understanding · 概念理解

对二分类 $y\in\{-1,+1\}$，模型先算 score $s=w^\top\phi(x)$，再把它变成真实类别的概率：

$$ p(y\mid x)=\frac{1}{1+\exp(-y\,w^\top\phi(x))} $$

它是 discriminative model：直接建模 $p(y\mid x;\theta)$，而不是像 Naive Bayes 那样建模 joint distribution $p(x,y)$。Bias 可以显式写成 $a=w^\top x+b$，也可以把常数 1 加进 $\phi(x)$ 里吸收掉。

它解决的是 linear regression 做 classification 的问题：分类更关心 sign 和 confidence，而不是把标签当普通数字去拟合。

2. Plain-English Explanation · 大白话理解

把 $w^\top x$ 想成一个“信心条”。很正表示更像 +1，很负表示更像 -1，接近 0 表示不确定。

Sigmoid 把这个信心条压到 0 到 1 之间，变成 probability。Log loss 问的是：你有没有给真实类别足够高的概率？

3. Core Intuition · 核心直觉

MSE 会一直拉扯 easy examples，即使它们已经分类正确。Logistic loss 主要看 margin $y\,w^\top\phi(x)$：margin 很大且为正时 loss 很小；margin 为负时 loss 快速变大。

从概率角度看，样本 i.i.d. 时，最大化整份 dataset 的 likelihood 等价于最小化 negative log-likelihood。一般没有 closed form，所以用 gradient descent。

4. Key Equations · 核心公式

Sigmoid
$$ \sigma(z)=\frac{1}{1+e^{-z}} $$

这个公式在做什么？ 把任意 real-valued logit $z$ 压成 class 1 probability。记住 $\sigma(0)=0.5$，以及导数 $\sigma'(z)=\sigma(z)(1-\sigma(z))$。

📖 符号、直觉与用法

符号. $z$ 是任意 real-valued logit，几乎一定是 $z=w^\top\phi(x)$（或 $w^\top x+b$）；$\sigma(z)\in(0,1)$ 是预测的 positive class 概率；$e^{-z}$ 是分母里的指数项。

怎么理解. S 形曲线把任意 score 压到 $(0,1)$。$\sigma(0)=0.5$；$z$ 大正 → 1；$z$ 大负 → 0。两端 saturate —— 这就是 "极度自信" 的预测梯度变小的原因（深网 vanishing-gradient 来源之一）。

怎么用. 先算线性 score，再代入 $\sigma$；阈值 0.5 分类等价于看 $z>0$。背下导数 $\sigma'(z)=\sigma(z)(1-\sigma(z))$ —— 它让 logistic regression 梯度和 sigmoid backprop 都塌得很干净。

Logit / log-odds
$$ \log\frac{p}{1-p}=w^\top\phi(x)+b $$

这个公式在做什么？ 说明 logistic regression 对 log-odds 是线性的，而不是对 probability 线性。令 $p=0.5$ 时 log-odds 为 0，所以边界是线性的。

📖 符号、直觉与用法

符号. $p=p(y=1\mid x)$ 是模型给的 class-1 概率；$p/(1-p)$ 是正负类的 odds；左边 $\log(p/(1-p))$ 就是 logit（$\sigma$ 的反函数）；$w$ 是权重，$b$ 是 bias。

怎么理解. Logistic regression 对 log-odds 是线性的，不对 raw probability 线性。某个特征 $j$ 加 1，log-odds 就移动 $w_j$ —— 所以 $w_j$ 有个干净的解读："odds-multiplier" 等于 $e^{w_j}$。

怎么用. 题目问 "为什么 boundary 是线性"，把 $p=0.5$ 代入 —— log-odds = $\log 1=0$，所以 boundary 恰是 $w^\top\phi(x)+b=0$。从 log-odds 回到 probability 用 $\sigma$。

Decision boundary
$$ p(y=1\mid x)=0.5 \iff w^\top\phi(x)=0 $$

这个公式在做什么？ 把 probability threshold 变成 sign test：score 大于 0 预测正类，小于 0 预测负类。

📖 符号、直觉与用法

符号. $p(y=1\mid x)$ 是模型对 class $+1$ 预测的概率；$w$ 是学到的权重向量；$\phi(x)$ 是 feature representation（普通 logistic 是 identity）；$w^\top\phi(x)$ 是线性 score。

怎么理解. Boundary 就是模型 "完全不确定" 的轨迹 —— 正负类概率打平在 $0.5$。Sigmoid 单调，所以打平正好对应 score 为 $0$。Boundary 在 feature space 仍是 linear，尽管 probability curve 非线性 —— 这就是为什么 logistic regression 仍称为 linear classifier。

怎么用. 分类时算 $w^\top\phi(x)$：正数预测 $+1$，负数预测 $-1$。要画 boundary 就解 $w^\top\phi(x)+b=0$ —— 二维普通 logistic 下是一条直线。

NLL / log loss
$$ \min_w \sum_{(x_i,y_i)\in D}\log\!\left(1+\exp(-y_i w^\top\phi(x_i))\right) $$

这个公式在做什么？ 用 logistic loss 训练二分类器：margin 错或不够大就罚得多。这是 $y\in\{-1,+1\}$ 的写法。

📖 符号、直觉与用法

符号. $D$ 是 training set；$y_i\in\{-1,+1\}$ 是标签；$w^\top\phi(x_i)$ 是 score；$y_i w^\top\phi(x_i)$ 是 signed margin；$\log(1+e^{-z})$ 是 softplus，也就是 $\max(0,-z)$ 的光滑近似。

怎么理解. 自信且对（margin 大正）→ loss $\approx 0$；自信但错（margin 为负）→ loss 大致按 $|z|$ 线性增长。永远非负，凸又可微，SGD 收敛干净。它来自 i.i.d. Bernoulli likelihood 取最大化后再 $-\log$。

怎么用. 对所有 training example 求和后用 gradient descent 最小化；加 L2 正则 $\tfrac{\lambda}{2}\|w\|^2$ 即 ridge logistic。注意不要和 $\{0,1\}$ 的 BCE 形式混用，除非先转换标签（$y_{01}=(y_{\pm 1}+1)/2$）。

Binary cross-entropy (BCE)
$$ \mathcal{L}(y,\hat y)=-\bigl(y\log\hat y+(1-y)\log(1-\hat y)\bigr) $$
$$ \mathrm{NLL}(w)=-\frac{1}{N}\sum_{n=1}^{N}\left[y_n\log\mu_n+(1-y_n)\log(1-\mu_n)\right],\qquad \mu_n=\sigma(w^\top x_n) $$

这个公式在做什么？ 这是 $y\in\{0,1\}$ 版本的 NLL：真实类概率越高 loss 越小，自信但错会被重罚。配合 logit 时梯度简化成 $\hat y-y$。

Gradient descent
$$ w_{t+1}=w_t-\alpha \nabla f(w_t) $$

这个公式在做什么？ 给出 iterative training step：沿着 loss gradient 的反方向更新，因为 logistic regression 一般没有 normal equation closed form。

Gradient and IRLS
$$ \nabla L(w)=\sum_i(\mu_i-y_i)x_i,\qquad \mu_i=\sigma(w^\top x_i) $$

这个公式在做什么？ 展示 gradient 的核心形状：probability error 乘 input。IRLS / Newton 会再利用 curvature，步子更聪明但更贵。

Convexity check ($y\in\{0,1\}$ form)
$$ \nabla^2 L(w)=X^\top B X,\qquad B=\mathrm{diag}(p_i(1-p_i)) $$

这个公式在做什么？ 用 Hessian 说明 logistic loss 是 convex：$B$ 的对角元非负，所以 $X^\top B X$ 是 PSD；满足 rank 条件时 local minimum 就是 global minimum。

Softmax extension
$$ p(y=c\mid x)=\frac{\exp(w_c^\top x)}{\sum_{j=1}^{C}\exp(w_j^\top x)} $$

这个公式在做什么？ 把 sigmoid 推广到多分类：每个 class 一个 score，归一化成总和为 1 的 probabilities。计算时用 log-sum-exp 保稳定。

5. Worked Examples · 代表性例题

Example A · 为什么边界仍然线性
来源：Lecture 5，概率阈值部分。

如果规定 $p(y=1\mid x)\ge 0.5$ 就预测 +1，那么 $\sigma(w^\top x)\ge 0.5$。Sigmoid 在输入 0 时等于 0.5，所以边界就是 $w^\top x=0$。

Example B · Logistic loss vs. quadratic loss
来源：Lecture 5，和 linear regression 的 loss 对比。

对一个已经正确且 margin 很大的点，quadratic loss 还可能很大，因为它想把 score 拉到某个数字标签附近。Linear regression 还可能输出 $[0,1]$ 之外的“概率”，且对 outliers 敏感；logistic loss 会接近 0，因为模型已经给真实 Bernoulli label 高概率。

Example C · Hessian 证明 convexity
来源：HW1 Problem 4(a-b)，题意转述。

把样本堆叠后 $H=X^\top B X$，其中 $B$ 的对角元非负。对任意 $v$，$v^\top H v=(Xv)^\top B(Xv)=\sum_i p_i(1-p_i)(x_i^\top v)^2\ge 0$。所以 logistic loss 是 convex，local minimum 就是 global minimum。

6. Problem-Solving Tips · 解题技巧

先看 label convention。 $y\in\{-1,+1\}$ 用 $\log(1+\exp(-ys))$；$y\in\{0,1\}$ 用 binary cross-entropy。
概率题： 先写 sigmoid，再根据 0.5 threshold 做分类。
凸性题： 写出 Hessian = $X^\top B X$，再看 $v^\top H v$。
优化题： 说清楚一般没有 closed form，需要 gradient descent。
Linear vs. Logistic： 对比 Gaussian regression target 和 Bernoulli class label。多分类里 linear regression 可能 mask 掉中间类别，即使类别本身可分。
Separable data： 未正则化 MLE 可能让 $\|w\|$ 趋向无穷。加 $L_2$ weight decay，例如 $\lambda\|w\|_2^2$，可以让解有限并改善泛化。
XOR： 单个 logistic-regression boundary 解不了 XOR；需要 nonlinear features 或 MLP 这样的 hidden layer。

7. Common Mistakes · 常见错误

  • 因为 sigmoid 非线性就说 logistic regression 的边界非线性；其实 boundary 在 $\phi(x)$ 空间仍是 linear。
  • 把 $y\in\{0,1\}$ 和 $y\in\{-1,+1\}$ 的公式混着用。
  • 期待像 linear regression 一样有 normal equation closed form。
  • 写 dataset likelihood 时忘记 i.i.d. assumption。
  • 忘记 perfectly separable data 会让 unregularized MLE 追逐无限大的 weights。

8. Exam Focus · 考试重点

  • 会写 sigmoid probability model 和 NLL objective。
  • 会解释 logistic loss 如何修复 MSE classification 的问题。
  • 会识别 / 推导 gradient descent 用到的 gradient。
  • 会用 $H=X^\top B X$ 证明 convexity。
  • 会说明 decision boundary 为什么是 $w^\top\phi(x)=0$。
  • 知道 log-odds interpretation、softmax multiclass extension，以及 log-sum-exp 为什么用于数值稳定。

1. Concept Understanding

A Transformer block is the repeated computation unit behind modern sequence models. Lecture 16 introduces it as self-attention plus per-token MLP computation, normalization, and residual connections; HW4 then asks you to count parameters in a decoder-only version.

  • Masked MHA lets each token read earlier tokens.
  • FFN / MLP transforms each token representation independently after attention mixes context.
  • Residual connections keep gradients and information flowing through many layers.
  • LayerNorm stabilizes activation scale during training.

2. Plain-English Explanation

A Transformer layer is like a study group followed by private thinking time. During attention, every token consults useful previous tokens. During the FFN, each token processes what it learned on its own. Residual connections keep the original notes around so the layer does not accidentally overwrite everything.

3. Core Intuition

The architecture alternates between mixing across positions and transforming within positions. Attention is the across-token communication step. The MLP is the per-token computation step. Stacking many blocks lets shallow layers learn local patterns and deeper layers learn more abstract language features.

For exam-style reasoning, the important split is simple: attention projections mix information across tokens, while feed-forward matrices do most of the per-token nonlinear computation.

4. Key Equations

Block skeleton

$$ X' = X + \mathrm{MHA}(\mathrm{LN}(X)),\qquad X_{\text{out}}=X' + \mathrm{FFN}(\mathrm{LN}(X')) $$

Symbols. $X\in\mathbb{R}^{T\times D}$ is the sequence of token states; $T$ is sequence length; $D$ is model width; $\mathrm{LN}$ is layer normalization; $\mathrm{MHA}$ mixes information across tokens; $\mathrm{FFN}$ is the per-token MLP; $X_{\text{out}}$ is the block output.

How to read it. This is a Pre-LN Transformer block. Normalize $X$, run multi-head attention, then add the original $X$ back through a residual connection. Do the same pattern again with the feed-forward network.

How to use. When explaining architecture, say "attention communicates across positions; FFN transforms each position independently; residuals preserve the input signal."

Multi-head attention projections

$$ Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,\qquad \mathrm{MHA}(X)=\mathrm{Concat}(head_1,\ldots,head_N)W_O $$

Symbols. $W_Q,W_K,W_V,W_O$ are learned projection matrices. In the usual parameter-count simplification each is $D\times D$, even though internally the $N$ heads split the width into smaller pieces.

How to read it. The block learns three views of each token: what it asks for ($Q$), how it is matched ($K$), and what content it contributes ($V$). Heads run attention in parallel, concatenate their outputs, then $W_O$ mixes them back into model width $D$.

How to use. For parameter counting, do not multiply $4D^2$ by the number of heads again. The heads partition the same total width.

Parameter count from HW4 §2.4

$$ \text{attention per layer}=4D^2,\qquad \text{MLP per layer}=2DF $$
$$ \text{full model}=L(4D^2+2DF)+2VD $$

Symbols. $D$ is model width, $L$ is the number of layers, $F$ is the MLP hidden width, and $V$ is vocabulary size. The $2VD$ term counts untied input embeddings and output LM head.

How to read it. The formula adds three parameter sources: attention projections in every layer, MLP matrices in every layer, and vocabulary matrices at the input/output ends.

How to use. Count one layer first: $4D^2$ for $Q,K,V,O$ projections and $2DF$ for the up/down MLP matrices. Multiply by $L$, then add vocabulary matrices. Biases and layer norm parameters are usually ignored unless the problem explicitly asks for them.

5. Worked Examples

HW4 §2.4.1: attention block parameters

Source: HW4 §2.4, paraphrased.

Standard multi-head attention has $W_Q,W_K,W_V,W_O$. Even though there are $N$ heads, their head dimensions sum to $D$, so each projection is $D\times D$. Total: $4D^2$.

HW4 §2.4.2: MLP block parameters

The two-layer MLP uses $W_{up}\in\mathbb{R}^{D\times F}$ and $W_{down}\in\mathbb{R}^{F\times D}$. Total: $DF+FD=2DF$.

HW4 §2.4.3: OLMo-style total

For $D=4096$, $L=32$, $F=11008$, $V=50304$:

$$ 4D^2+2DF=157{,}286{,}400\quad\text{parameters per layer} $$
$$ 32(157{,}286{,}400)+2(50304)(4096)=5{,}445{,}255{,}168 $$

So this simplified count is about 5.45B parameters.

6. Problem-Solving Tips

  1. For architecture questions, name the path: token embedding plus position, repeated decoder blocks, LM head.
  2. For parameter counts, write matrix shapes first. Most mistakes disappear once shapes are explicit.
  3. The number of heads $N$ often cancels in standard MHA parameter counting because all heads concatenate back to width $D$.
  4. Separate attention parameters, MLP parameters, and vocabulary matrices before adding them.

7. Common Mistakes

  • Multiplying MHA parameters by $N$ after already using full $D\times D$ projection matrices.
  • Counting positional encoding as trainable when the problem says sinusoidal or "no learned positional embeddings."
  • Forgetting the output LM head when embeddings are untied.
  • Confusing the FFN hidden width $F$ with vocabulary size $V$.

8. Exam Focus

  • Know the decoder block parts: LN, masked MHA, FFN, residual connections.
  • Know why residuals and LayerNorm make deep stacks trainable.
  • Be able to derive $4D^2+2DF$ per layer.
  • Be able to compute the full formula $L(4D^2+2DF)+2VD$.

9. Quick Checklist

  • Attention mixes across tokens.
  • FFN transforms each token independently.
  • Residuals preserve information and gradients.
  • LayerNorm stabilizes scale.
  • Per-layer simplified parameter count: $4D^2+2DF$.

1. 概念理解 / Concept Understanding

Transformer block 是现代序列模型背后的基本重复单元。Lecture 16 把它介绍成 self-attention + per-token MLP computation + normalization + residual connections；HW4 则进一步让你数 decoder-only 版本的参数量。

  • Masked MHA：让每个 token 读取前面的 token。
  • FFN / MLP：attention 混合上下文后，对每个 token 单独做非线性变换。
  • Residual connections：让信息和梯度穿过很多层时不容易断。
  • LayerNorm：稳定 activation scale，让训练更稳。

2. 大白话理解 / Plain-English Explanation

一个 Transformer layer 像“先小组讨论，再个人消化”。Attention 阶段，每个 token 去问前面哪些 token 有用；FFN 阶段，每个 token 把自己读到的信息单独加工一下。Residual 就是保留原笔记，避免这一层一不小心把重要信息覆盖掉。

3. 核心直觉 / Core Intuition

Transformer 的本质节奏是：先 across positions 混合信息，再 within position 做变换。Attention 负责 token 之间通信，MLP 负责每个 token 内部计算。层数叠深以后，浅层学局部 pattern，深层学更抽象的语言结构。

考试里最重要的拆分很简单：attention projections 负责跨 token 混合信息，feed-forward matrices 负责每个 token 内部的非线性计算。

4. 核心公式 / Key Equations

Block skeleton

$$ X' = X + \mathrm{MHA}(\mathrm{LN}(X)),\qquad X_{\text{out}}=X' + \mathrm{FFN}(\mathrm{LN}(X')) $$

符号. $X\in\mathbb{R}^{T\times D}$ 是整段 token states；$T$ 是 sequence length；$D$ 是 model width；$\mathrm{LN}$ 是 layer normalization；$\mathrm{MHA}$ 负责跨 token 通信；$\mathrm{FFN}$ 是每个 token 独立经过的 MLP；$X_{\text{out}}$ 是 block 输出。

怎么理解. 这是 Pre-LN Transformer block：先对 $X$ 做 layer norm，再做 multi-head attention，然后通过 residual 把原来的 $X$ 加回来；接着对 $X'$ 重复一次 LN + FFN + residual。

怎么用. 解释架构时抓住三句话：attention 跨位置混合信息，FFN 对每个位置单独变换，residual 保留输入信号。

Multi-head attention projections

$$ Q=XW_Q,\qquad K=XW_K,\qquad V=XW_V,\qquad \mathrm{MHA}(X)=\mathrm{Concat}(head_1,\ldots,head_N)W_O $$

符号. $W_Q,W_K,W_V,W_O$ 都是 learned projection matrices。常见参数量估算里它们都按 $D\times D$ 计算；$N$ 个 heads 只是把总宽度切成更窄的 head 维度。

怎么理解. 模型把每个 token 投影成三种视角：$Q$ 表示“我要找什么”，$K$ 表示“我怎么被匹配”，$V$ 表示“我能提供什么内容”。多个 heads 并行算 attention，拼接后再用 $W_O$ 混回宽度 $D$。

怎么用. 数参数时不要在 $4D^2$ 外面再乘 heads 数 $N$；heads 是在同一个总维度 $D$ 里拆分。

HW4 §2.4 参数量公式

$$ \text{attention per layer}=4D^2,\qquad \text{MLP per layer}=2DF $$
$$ \text{full model}=L(4D^2+2DF)+2VD $$

符号. $D$ 是 model width，$L$ 是层数，$F$ 是 MLP hidden width，$V$ 是 vocabulary size。$2VD$ 是 untied input embedding 和 output LM head。

怎么理解. 这个公式把参数分成三块：每层 attention projections、每层 MLP matrices，以及输入/输出端的 vocabulary matrices。

怎么用. 先数一层：attention 的 $Q,K,V,O$ 是 $4D^2$，MLP 的 up/down 两个矩阵是 $2DF$。再乘 $L$，最后加 vocabulary matrices。bias 和 layer norm 参数通常忽略，除非题目特别要求。

所以这个简化估算约为 5.45B parameters。

6. 解题技巧 / Problem-Solving Tips

  1. 架构题先按路径说：token embedding + position，然后重复 decoder blocks，最后 LM head。
  2. 参数量题先写矩阵 shape，shape 写对基本就不乱。
  3. 标准 MHA 的参数量里，head 数 $N$ 往往会 cancel，因为所有 heads 拼回宽度 $D$。
  4. 最后相加时分三块：attention、MLP、vocabulary matrices。

7. 常见错误 / Common Mistakes

  • 已经用 $D\times D$ projection 之后，又额外乘 head 数 $N$。
  • 题目说 sinusoidal / no learned positional embeddings 时，还把 PE 当 trainable parameters。
  • embedding 和 LM head untied 时，忘记 output LM head。
  • 把 FFN hidden width $F$ 和 vocabulary size $V$ 搞混。

8. 考试重点 / Exam Focus

  • 知道 decoder block 组成：LN、masked MHA、FFN、residual connections。
  • 能解释 residual 和 LayerNorm 为什么让深层网络更好训练。
  • 会推一层参数量 $4D^2+2DF$。
  • 会算整模型公式 $L(4D^2+2DF)+2VD$。

9. 速记清单 / Quick Checklist

  • Attention 负责跨 token 混合。
  • FFN 负责每个 token 自己加工。
  • Residual 保信息、保梯度。
  • LayerNorm 稳定尺度。
  • 简化一层参数量：$4D^2+2DF$。

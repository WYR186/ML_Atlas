🔮 Transformer Architecture

Block components

  • LayerNorm.
  • Multi-head attention.
  • Feed-forward network (2-layer MLP).
  • Residual connections.
🔧 Mnemonic

LN → MHA → Add → LN → FFN → Add

Implementations may use Pre-LN or Post-LN.

Multi-head attention

Multiple heads operate in parallel on different representation subspaces (syntax, semantics, coreference, …); their outputs are concatenated and projected back.

🔮 3. Transformer 架构

标准 Block 组件

  • LayerNorm（层归一化）
  • Multi-Head Attention（多头注意力 MHA）
  • Feed-Forward Network（FFN / MLP）
  • Residual Connections（残差）
🔧 Mnemonic

LN → (MHA) → Add → LN → (FFN) → Add

实现可能是 Pre-LN 或 Post-LN 变体。

Multi-Head Attention

多个 head 并行在不同表示子空间学习关系（语法 / 语义 / 指代等），最后拼接 + 投影。

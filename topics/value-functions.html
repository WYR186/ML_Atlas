Value and Q Functions

Lecture 23 defines value functions so we can evaluate how good a policy is before trying to improve it. Values turn delayed rewards into a state-by-state scorecard.

1. Concept Understanding

A state value $V^\pi(s)$ asks: if the agent starts in state $s$ and follows policy $\pi$, what discounted return should it expect?

An action value $Q^\pi(s,a)$ asks: if the agent starts in state $s$, takes action $a$ first, and then follows $\pi$, what discounted return should it expect?

Policy evaluation means computing these values for a fixed policy.

These definitions assume the Markov property: once the current state and action are known, the future does not depend on the earlier history. If the observed state hides important information, as in a POMDP, the same Bellman equations may fail unless the state representation is expanded.

2. Plain-English Explanation

$V(s)$ is the score of standing in a place. $Q(s,a)$ is the score of standing there and taking one specific first action.

If you are planning a route, $V$ says "how good is this location?" while $Q$ says "how good is it if I turn left from here first?"

3. Core Intuition

The difference between $V$ and $Q$ is whether the first action is already fixed. Once the first action is fixed, the rest of the future is still controlled by the policy $\pi$.

This is why value functions connect directly to Bellman equations: current value equals immediate reward plus discounted expected value of future states.

When $P(s'\mid s,a)$ and $R(s,a)$ are known, value functions can be solved with model-based dynamic programming. When the model is unknown, methods like Q-learning replace expectations with sampled transitions. In large state spaces, a table is replaced by a function approximator such as $q(s,a,w)\approx q^*(s,a)$.

4. Key Equations

Discounted return recursion
$$ G_t=r_t+\gamma G_{t+1}=\sum_{k=0}^{\infty}\gamma^k r_{t+k} $$

What it does. Today's return is today's reward plus a discounted copy of tomorrow's return.

State value
$$ V^\pi(s)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s\right] $$

What it does. V^π(s) asks: starting from state s and following policy π, how much discounted reward should I expect?

Action value
$$ Q^\pi(s,a)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s,A_0=a\right] $$

What it does. Q^π(s,a) asks: starting in state s, first take action a, then follow π; what return should I expect?

Relationship under a policy
$$ V^\pi(s)=\mathbb{E}_{a\sim\pi(\cdot\mid s)}[Q^\pi(s,a)] $$

What it does. State value is the policy-weighted average of action values in that state.

Bellman evaluation equation
$$ Q^\pi(s,a)=R(s,a)+\gamma\mathbb{E}_{s'\sim P(\cdot\mid s,a)}[V^\pi(s')] $$
$$ Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\sum_{a'}\pi(a'\mid s')Q^\pi(s',a') $$

What it does. Q equals immediate reward plus discounted expected value of the next state.

Bellman optimality and value iteration
$$ V^*(s)=\max_{a\in\mathcal{A}}Q^*(s,a),\qquad Q^*(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^*(s') $$
$$ Q^{(t)}(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\max_{a'}Q^{(t-1)}(s',a') $$

What it does. Optimal value replaces policy averaging with a max. Value iteration repeatedly applies this optimal Bellman backup until the table stabilizes.

Convergence. The Bellman optimality operator is a gamma-contraction in the infinity norm, so repeated backups converge geometrically to a unique optimal fixed point when gamma < 1.

Sampled Q-learning update
$$ Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right] $$

What it does. Q-learning uses one sampled transition $(s,a,r,s')$ instead of summing over the full transition model. The max target is greedy, so the method is off-policy even if data is collected with epsilon-greedy exploration.

Value bound and advantage
$$ V^*(s),\,Q^*(s,a)\le \frac{R_{\max}}{1-\gamma} $$
$$ A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s) $$

What it does. The bound is the best possible geometric series of rewards. Advantage is positive when an action is better than the state baseline and negative when it is worse.

State-value Bellman expectation
$$ V^\pi(s)=\sum_{a}\pi(a\mid s)\Bigl[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\,V^\pi(s')\Bigr] $$

The Bellman evaluation equation written purely in terms of $V^\pi$ — the form the official RL review and most textbooks use for policy evaluation. Same content as the $Q$-form above, just with the action expectation pushed inside.

What it does. Two layers of averaging: first weight each action by how often $\pi$ would pick it, then weight each successor state by transition probability. The bracketed term is the one-step lookahead from $(s,a)$; multiplying by $\pi(a\mid s)$ and summing gives the lookahead from $s$ alone.

Connection to other entries. Use $V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a)$ to switch between $V$ and $Q$ forms; combine with the matrix form $V^\pi=R^\pi+\gamma P^\pi V^\pi$ to get a single linear system $V^\pi=(I-\gamma P^\pi)^{-1}R^\pi$ for finite MDPs.

Where it shows up. Final review's policy-evaluation slide writes this exact form; HW5 §2 (Bellman backups under stochastic policy); the prerequisite for value iteration / policy iteration / DP backups in the next two pages.

Matrix form for finite MDPs
$$ V^\pi=R^\pi+\gamma P^\pi V^\pi,\qquad V^\pi=(I-\gamma P^\pi)^{-1}R^\pi $$

What it does. For finite states and fixed π, all Bellman equations form one linear system.

Example 1 · deterministic policy

If $\pi(s)$ always selects action right, then the value of state $s$ is exactly the Q-value of first going right: $V^\pi(s)=Q^\pi(s,\text{right})$.

Example 2 · stochastic policy average

Source: Lecture 24, p. 10.

If a policy chooses two actions with probabilities 0.7 and 0.3, then $V^\pi(s)=0.7Q^\pi(s,a_1)+0.3Q^\pi(s,a_2)$.

Example 3 · Q definition from homework

Source: HW5, Section 2.

For infinite horizon with discount, $Q^\pi(s,a)$ fixes the first transition, then averages over stochastic next states and future actions chosen by $\pi$.

Example 4 · One Q-table update

Source: Q-learning numerical practice, paraphrased.

Suppose $Q(s,a)=2$, observed reward $r=1$, $\gamma=0.9$, $\max_{a'}Q(s',a')=4$, and $\alpha=0.5$. The target is $1+0.9\cdot4=4.6$, the TD error is $4.6-2=2.6$, and the updated entry is $2+0.5\cdot2.6=3.3$.

6. Problem-Solving Tips

  1. If the question asks how good a state is, use $V^\pi(s)$.
  2. If the question fixes the first action, use $Q^\pi(s,a)$.
  3. If the policy is stochastic, average Q-values using action probabilities.
  4. For Bellman evaluation, peel off the first reward and put the rest into $V^\pi(s')$.
  5. For a reward trajectory, compute discounted returns backward with $G_t=r_t+\gamma G_{t+1}$.
  6. For finite matrix form, identify $P^\pi$ and $R^\pi$ induced by the policy.
  7. For model-based questions, use the sums over $P(s'\mid s,a)$. For model-free questions, expect sampled transitions and Q-learning-style TD updates.
  8. For policy iteration, remember the loop: evaluate the current policy, improve it greedily, repeat.

7. Common Mistakes

  • Confusing $V^\pi$ with $V^*$; the former is policy-specific.
  • Forgetting that $Q^\pi(s,a)$ fixes only the first action, then follows $\pi$.
  • Using $\max_a Q^\pi(s,a)$ during policy evaluation; max belongs to optimality, not fixed-policy evaluation.
  • Dropping the expectation over stochastic transitions.
  • Applying Bellman equations to an observation that is not Markov. If the state hides needed history, the value function may be ill-defined for that observation alone.
  • Calling Q-learning on-policy. Its target uses $\max_{a'}Q(s',a')$, so it learns a greedy target while behavior may be exploratory.

8. Exam Focus

  • Memorize definitions of $V^\pi$ and $Q^\pi$.
  • Know $V^\pi(s)=\mathbb{E}_{a\sim\pi}[Q^\pi(s,a)]$.
  • Hand-compute discounted returns backward from the end of an episode.
  • Derive the Bellman evaluation equation by splitting first reward plus future return.
  • Recognize the finite MDP matrix equation $V^\pi=R^\pi+\gamma P^\pi V^\pi$.
  • Write Bellman optimality equations for $V^*$ and $Q^*$.
  • Explain value iteration convergence through the gamma-contraction idea.
  • Apply one or two Q-learning updates in a Q-table.
  • Know the value bound $R_{\max}/(1-\gamma)$ and the advantage definition $A^\pi=Q^\pi-V^\pi$.

9. Quick Checklist

  • $V$: state score under policy.
  • $Q$: state plus first action score under policy.
  • Evaluation uses fixed $\pi$.
  • Optimality uses max over actions.
  • Return recursion: $G_t=r_t+\gamma G_{t+1}$.
  • Discounted return is the long-term target.
  • Model-based uses $P$ and $R$; model-free learns from samples.
  • Q-learning target: $r+\gamma\max_{a'}Q(s',a')$.
  • Markov state is the assumption behind the Bellman recursion.

Value Function 与 Q Function

Lecture 23 定义 value function，是为了先评价一个 policy 到底好不好。价值函数把 delayed rewards 压缩成每个 state 或 state-action pair 的长期分数。

1. Concept Understanding · 概念理解

State value $V^\pi(s)$ 问：agent 从 state $s$ 出发并遵循 policy $\pi$，期望 discounted return 是多少？

Action value $Q^\pi(s,a)$ 问：agent 从 $s$ 出发，第一步先做 action $a$，之后遵循 $\pi$，期望 discounted return 是多少？

Policy evaluation 就是固定一个 policy，然后计算这些 values。

这些定义默认满足 Markov property：给定当前 state 和 action 后，未来不再依赖更早的 history。如果观察值隐藏了关键信息，比如 POMDP，那么只用当前 observation 写 Bellman equation 可能不再可靠，除非把 state representation 扩充完整。

2. Plain-English Explanation · 大白话理解

$V(s)$ 是“站在这个位置整体前景如何？” $Q(s,a)$ 是“站在这里，如果第一步先这么走，前景如何？”

路线规划里，$V$ 评价地点，$Q$ 评价“地点 + 第一个转弯”。

3. Core Intuition · 核心直觉

$V$ 和 $Q$ 的区别只在于第一步 action 是否被固定。第一步固定之后，后面的动作仍然按 policy $\pi$ 走。

这就是它们能写成 Bellman equation 的原因：当前 value = immediate reward + discounted future value。

如果 $P(s'\mid s,a)$ 和 $R(s,a)$ 已知，就是 model-based dynamic programming；如果不知道环境模型，就用 Q-learning 这类 model-free 方法从 sampled transitions 更新。状态空间很大时，通常不再存 table，而是用 function approximation，例如 $q(s,a,w)\approx q^*(s,a)$。

4. Key Equations · 关键公式

Discounted return recursion
$$ G_t=r_t+\gamma G_{t+1}=\sum_{k=0}^{\infty}\gamma^k r_{t+k} $$

这个公式在做什么？ 今天的 return = 今天拿到的 reward + 打折后的明天 return。

State value
$$ V^\pi(s)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s\right] $$

这个公式在做什么？ V^π(s) 问：从状态 s 出发，之后按策略 π 行动，期望能拿到多少折扣总回报？

Action value
$$ Q^\pi(s,a)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s,A_0=a\right] $$

这个公式在做什么？ Q^π(s,a) 问：在状态 s 先做动作 a，然后按策略 π 行动，期望回报是多少？

Policy 下的关系
$$ V^\pi(s)=\mathbb{E}_{a\sim\pi(\cdot\mid s)}[Q^\pi(s,a)] $$

这个公式在做什么？ State value 就是在该 state 下，按策略 π 的动作分布对 Q-value 做加权平均。

Bellman evaluation equation
$$ Q^\pi(s,a)=R(s,a)+\gamma\mathbb{E}_{s'\sim P(\cdot\mid s,a)}[V^\pi(s')] $$
$$ Q^\pi(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\sum_{a'}\pi(a'\mid s')Q^\pi(s',a') $$

这个公式在做什么？ Q 等于“即时奖励 + 下一状态未来价值的折扣期望”。这是固定策略下的一步自洽方程。

Bellman optimality 与 value iteration
$$ V^*(s)=\max_{a\in\mathcal{A}}Q^*(s,a),\qquad Q^*(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^*(s') $$
$$ Q^{(t)}(s,a)=R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\max_{a'}Q^{(t-1)}(s',a') $$

这个公式在做什么？ Optimal value 不再按 policy 平均，而是直接取最优 action。Value iteration 就是不断套这个 optimal Bellman backup，直到 table 稳定。

收敛性. Bellman optimality operator 在 infinity norm 下是 gamma-contraction，所以当 discount 小于 1 时，反复 backup 会几何收敛到唯一 optimal fixed point。

Sampled Q-learning update
$$ Q(s,a)\leftarrow Q(s,a)+\alpha\left[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\right] $$

这个公式在做什么？ Q-learning 用一个 sampled transition $(s,a,r,s')$ 代替完整 transition model 上的求和。target 里有 greedy max，所以即使数据来自 ε-greedy exploration，它学的仍是 off-policy greedy target。

Value bound 与 advantage
$$ V^*(s),\,Q^*(s,a)\le \frac{R_{\max}}{1-\gamma} $$
$$ A^\pi(s,a)=Q^\pi(s,a)-V^\pi(s) $$

这个公式在做什么？ 上界来自最乐观的 geometric series；advantage 为正表示这个 action 比 policy 平均表现更好，为负表示更差。

State-value Bellman expectation（V 形式）
$$ V^\pi(s)=\sum_{a}\pi(a\mid s)\Bigl[R(s,a)+\gamma\sum_{s'}P(s'\mid s,a)\,V^\pi(s')\Bigr] $$

完全用 $V^\pi$ 写出的 Bellman evaluation —— RL 官方 review 与多数教材在 policy evaluation 这一节就是用这种写法。和上面 $Q$ 形式的内容相同，只是把对 action 的期望推进了括号里。

这个公式在做什么？ 两层加权平均：先把每个动作按 $\pi$ 的选取概率加权，再把每个后续 state 按转移概率加权。中括号里的项是 $(s,a)$ 的一步前瞻；乘以 $\pi(a\mid s)$ 再求和就是 $s$ 的一步前瞻。

与其他公式的关系. 用 $V^\pi(s)=\sum_a\pi(a\mid s)Q^\pi(s,a)$ 在 V 与 Q 形式间切换；与 matrix form $V^\pi=R^\pi+\gamma P^\pi V^\pi$ 配合，对有限 MDP 可以一步求出 $V^\pi=(I-\gamma P^\pi)^{-1}R^\pi$。

典型出处. Final review 的 policy evaluation slide 写的就是这一行；HW5 §2（stochastic policy 下的 Bellman backup）；后面 value iteration / policy iteration / DP backup 两页的前置依赖。

Finite MDP 的 matrix form
$$ V^\pi=R^\pi+\gamma P^\pi V^\pi,\qquad V^\pi=(I-\gamma P^\pi)^{-1}R^\pi $$

这个公式在做什么？ 有限状态空间、固定策略下，所有 Bellman 方程可以合并成一个线性方程组。

6. Problem-Solving Tips · 解题技巧

  1. 问 state 好不好，用 $V^\pi(s)$。
  2. 固定第一步 action，用 $Q^\pi(s,a)$。
  3. stochastic policy 下，用 action probabilities 对 Q-values 加权平均。
  4. 推 Bellman evaluation 时，把 first reward 单独拆出来，剩下写成 $V^\pi(s')$。
  5. 给一条 reward trajectory 时，用 $G_t=r_t+\gamma G_{t+1}$ 从 episode 末尾往前算 discounted returns。
  6. finite matrix form 里先找 policy-induced $P^\pi$ 和 $R^\pi$。
  7. model-based 题用 $P(s'\mid s,a)$ 上的求和；model-free 题通常给 sampled transition，用 Q-learning / TD update。
  8. Policy iteration 的循环是：evaluate 当前 policy，greedy improve，再重复。

7. Common Mistakes · 常见错误

  • 混淆 $V^\pi$ 和 $V^*$；前者是固定 policy，后者是 optimal。
  • 忘记 $Q^\pi(s,a)$ 只固定第一步 action，之后还是 follow $\pi$。
  • policy evaluation 时用了 $\max_a Q^\pi(s,a)$；max 是 optimality，不是 fixed-policy evaluation。
  • 漏掉 stochastic transition 上的 expectation。
  • 把非 Markov observation 直接当 state 用 Bellman equation；如果 state 缺 history，value 可能对当前 observation 本身并不 well-defined。
  • 把 Q-learning 说成 on-policy；它的 target 用 $\max_{a'}Q(s',a')$，所以 behavior 可以探索，但 target 是 greedy。

8. Exam Focus · 考试重点

  • 默写 $V^\pi$ 和 $Q^\pi$ 定义。
  • 知道 $V^\pi(s)=\mathbb{E}_{a\sim\pi}[Q^\pi(s,a)]$。
  • 能从 episode 末尾往前手算 discounted returns。
  • 能从 first reward + future return 推 Bellman evaluation equation。
  • 认识 finite MDP matrix equation：$V^\pi=R^\pi+\gamma P^\pi V^\pi$。
  • 会写 $V^*$ 和 $Q^*$ 的 Bellman optimality equations。
  • 能用 gamma-contraction 解释 value iteration 收敛。
  • 会在 Q-table 里连续做 1-2 次 Q-learning update。
  • 记住 value bound $R_{\max}/(1-\gamma)$ 和 advantage 定义 $A^\pi=Q^\pi-V^\pi$。

9. Quick Checklist · 速记清单

  • $V$：policy 下的 state score。
  • $Q$：policy 下的 state + first action score。
  • Evaluation 固定 $\pi$。
  • Optimality 才对 action 取 max。
  • Return recursion：$G_t=r_t+\gamma G_{t+1}$。
  • 长期目标是 discounted return。
  • Model-based 用 $P,R$；model-free 从 samples 学。
  • Q-learning target：$r+\gamma\max_{a'}Q(s',a')$。
  • Bellman recursion 背后的假设是 Markov state。

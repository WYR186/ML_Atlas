Value and Q Functions

Lecture 23 defines value functions so we can evaluate how good a policy is before trying to improve it. Values turn delayed rewards into a state-by-state scorecard.

1. Concept Understanding

A state value $V^\pi(s)$ asks: if the agent starts in state $s$ and follows policy $\pi$, what discounted return should it expect?

An action value $Q^\pi(s,a)$ asks: if the agent starts in state $s$, takes action $a$ first, and then follows $\pi$, what discounted return should it expect?

Policy evaluation means computing these values for a fixed policy.

2. Plain-English Explanation

$V(s)$ is the score of standing in a place. $Q(s,a)$ is the score of standing there and taking one specific first action.

If you are planning a route, $V$ says "how good is this location?" while $Q$ says "how good is it if I turn left from here first?"

3. Core Intuition

The difference between $V$ and $Q$ is whether the first action is already fixed. Once the first action is fixed, the rest of the future is still controlled by the policy $\pi$.

This is why value functions connect directly to Bellman equations: current value equals immediate reward plus discounted expected value of future states.

4. Key Equations

State value

$$ V^\pi(s)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s\right] $$

Action value

$$ Q^\pi(s,a)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s,A_0=a\right] $$

Relationship under a policy

$$ V^\pi(s)=\mathbb{E}_{a\sim\pi(\cdot\mid s)}[Q^\pi(s,a)] $$

For a deterministic policy, this becomes $V^\pi(s)=Q^\pi(s,\pi(s))$.

Bellman evaluation equation

$$ Q^\pi(s,a)=R(s,a)+\gamma\mathbb{E}_{s'\sim P(\cdot\mid s,a)}[V^\pi(s')] $$

Matrix form for finite MDPs

$$ V^\pi=R^\pi+\gamma P^\pi V^\pi,\qquad V^\pi=(I-\gamma P^\pi)^{-1}R^\pi $$

5. Worked Examples

Example 1 · deterministic policy

Source: Lecture 23, p. 19.

If $\pi(s)$ always selects action right, then the value of state $s$ is exactly the Q-value of first going right: $V^\pi(s)=Q^\pi(s,\text{right})$.

Example 2 · stochastic policy average

Source: Lecture 24, p. 10.

If a policy chooses two actions with probabilities 0.7 and 0.3, then $V^\pi(s)=0.7Q^\pi(s,a_1)+0.3Q^\pi(s,a_2)$.

Example 3 · Q definition from homework

Source: HW5, Section 2.

For infinite horizon with discount, $Q^\pi(s,a)$ fixes the first transition, then averages over stochastic next states and future actions chosen by $\pi$.

6. Problem-Solving Tips

  1. If the question asks how good a state is, use $V^\pi(s)$.
  2. If the question fixes the first action, use $Q^\pi(s,a)$.
  3. If the policy is stochastic, average Q-values using action probabilities.
  4. For Bellman evaluation, peel off the first reward and put the rest into $V^\pi(s')$.
  5. For finite matrix form, identify $P^\pi$ and $R^\pi$ induced by the policy.

7. Common Mistakes

  • Confusing $V^\pi$ with $V^*$; the former is policy-specific.
  • Forgetting that $Q^\pi(s,a)$ fixes only the first action, then follows $\pi$.
  • Using $\max_a Q^\pi(s,a)$ during policy evaluation; max belongs to optimality, not fixed-policy evaluation.
  • Dropping the expectation over stochastic transitions.

8. Exam Focus

  • Memorize definitions of $V^\pi$ and $Q^\pi$.
  • Know $V^\pi(s)=\mathbb{E}_{a\sim\pi}[Q^\pi(s,a)]$.
  • Derive the Bellman evaluation equation by splitting first reward plus future return.
  • Recognize the finite MDP matrix equation $V^\pi=R^\pi+\gamma P^\pi V^\pi$.

9. Quick Checklist

  • $V$: state score under policy.
  • $Q$: state plus first action score under policy.
  • Evaluation uses fixed $\pi$.
  • Optimality uses max over actions.
  • Discounted return is the long-term target.

Value Function 与 Q Function

Lecture 23 定义 value function，是为了先评价一个 policy 到底好不好。价值函数把 delayed rewards 压缩成每个 state 或 state-action pair 的长期分数。

1. Concept Understanding · 概念理解

State value $V^\pi(s)$ 问：agent 从 state $s$ 出发并遵循 policy $\pi$，期望 discounted return 是多少？

Action value $Q^\pi(s,a)$ 问：agent 从 $s$ 出发，第一步先做 action $a$，之后遵循 $\pi$，期望 discounted return 是多少？

Policy evaluation 就是固定一个 policy，然后计算这些 values。

2. Plain-English Explanation · 大白话理解

$V(s)$ 是“站在这个位置整体前景如何？” $Q(s,a)$ 是“站在这里，如果第一步先这么走，前景如何？”

路线规划里，$V$ 评价地点，$Q$ 评价“地点 + 第一个转弯”。

3. Core Intuition · 核心直觉

$V$ 和 $Q$ 的区别只在于第一步 action 是否被固定。第一步固定之后，后面的动作仍然按 policy $\pi$ 走。

这就是它们能写成 Bellman equation 的原因：当前 value = immediate reward + discounted future value。

4. Key Equations · 关键公式

State value

$$ V^\pi(s)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s\right] $$

Action value

$$ Q^\pi(s,a)=\mathbb{E}\left[\sum_{t=0}^{\infty}\gamma^t r_t\mid \pi,S_0=s,A_0=a\right] $$

Policy 下的关系

$$ V^\pi(s)=\mathbb{E}_{a\sim\pi(\cdot\mid s)}[Q^\pi(s,a)] $$

deterministic policy 下就是 $V^\pi(s)=Q^\pi(s,\pi(s))$。

Bellman evaluation equation

$$ Q^\pi(s,a)=R(s,a)+\gamma\mathbb{E}_{s'\sim P(\cdot\mid s,a)}[V^\pi(s')] $$

Finite MDP 的 matrix form

$$ V^\pi=R^\pi+\gamma P^\pi V^\pi,\qquad V^\pi=(I-\gamma P^\pi)^{-1}R^\pi $$

5. Worked Examples · 代表性例题

例 1 · deterministic policy

出处：Lecture 23, p. 19。

如果 $\pi(s)$ 在 state $s$ 总是选 right，那么 $V^\pi(s)$ 就等于第一步选 right 的 Q-value：$V^\pi(s)=Q^\pi(s,\text{right})$。

例 2 · stochastic policy average

出处：Lecture 24, p. 10。

如果 policy 以 0.7 和 0.3 的概率选两个 actions，则 $V^\pi(s)=0.7Q^\pi(s,a_1)+0.3Q^\pi(s,a_2)$。

例 3 · HW 中的 Q 定义

出处：HW5, Section 2。

infinite horizon discount setting 中，$Q^\pi(s,a)$ 固定第一步 transition，之后对 stochastic next states 和 policy 选择的 future actions 做 expectation。

6. Problem-Solving Tips · 解题技巧

  1. 问 state 好不好，用 $V^\pi(s)$。
  2. 固定第一步 action，用 $Q^\pi(s,a)$。
  3. stochastic policy 下，用 action probabilities 对 Q-values 加权平均。
  4. 推 Bellman evaluation 时，把 first reward 单独拆出来，剩下写成 $V^\pi(s')$。
  5. finite matrix form 里先找 policy-induced $P^\pi$ 和 $R^\pi$。

7. Common Mistakes · 常见错误

  • 混淆 $V^\pi$ 和 $V^*$；前者是固定 policy，后者是 optimal。
  • 忘记 $Q^\pi(s,a)$ 只固定第一步 action，之后还是 follow $\pi$。
  • policy evaluation 时用了 $\max_a Q^\pi(s,a)$；max 是 optimality，不是 fixed-policy evaluation。
  • 漏掉 stochastic transition 上的 expectation。

8. Exam Focus · 考试重点

  • 默写 $V^\pi$ 和 $Q^\pi$ 定义。
  • 知道 $V^\pi(s)=\mathbb{E}_{a\sim\pi}[Q^\pi(s,a)]$。
  • 能从 first reward + future return 推 Bellman evaluation equation。
  • 认识 finite MDP matrix equation：$V^\pi=R^\pi+\gamma P^\pi V^\pi$。

9. Quick Checklist · 速记清单

  • $V$：policy 下的 state score。
  • $Q$：policy 下的 state + first action score。
  • Evaluation 固定 $\pi$。
  • Optimality 才对 action 取 max。
  • 长期目标是 discounted return。

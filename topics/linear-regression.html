📈 Linear Regression

Linear regression predicts a continuous value by fitting a linear score to data. Lecture 4 frames it as a three-part machine learning recipe: choose a model, choose a loss, then optimize the loss.

1. Concept Understanding

In regression, each training example has features $x^{(i)}$ and a real-valued target $y^{(i)}\in\mathbb{R}$. Linear regression assumes the prediction is a weighted combination of features:

$$ \hat y^{(i)} = w^\top \phi(x^{(i)}) $$

The feature map $\phi(x)$ may be the raw input, the input plus a bias feature, or a polynomial expansion. The problem it solves is: find parameters $w$ that make predicted values close to observed values.

2. Plain-English Explanation

Imagine placing a straight ruler through scattered points. For each point, measure the vertical miss between the ruler and the point. Linear regression chooses the ruler position that makes the total squared miss as small as possible.

The square matters: one very bad miss is punished more than several tiny misses. That is useful for smooth optimization, but it also makes the method sensitive to outliers.

3. Core Intuition

The squared-loss objective is a bowl-shaped quadratic whenever the design matrix has enough rank. The bottom of that bowl is where the gradient is zero, which gives the normal equation.

Feature engineering does not change the core method. A quadratic curve is still “linear regression” after replacing $x$ by $\phi(x)=(x^2,x,1)$. The model is linear in $w$, even if it is nonlinear in the original input.

Lecture 4 also shows why this is not the right loss for classification: MSE keeps penalizing examples that are already confidently correct.

4. Key Equations

Design-matrix objective
$$ \min_w \; \frac12\|Y-Xw\|_2^2 $$

Symbols. $w \in \mathbb{R}^d$: weight vector being optimized — one weight per feature； $X \in \mathbb{R}^{n \times d}$: design matrix; row $i$ is feature vector $x_i^\top$； $Y \in \mathbb{R}^n$: vector of target values $(y_1, \ldots, y_n)^\top$； $Xw \in \mathbb{R}^n$: vector of predictions $(\hat{y}_1, \ldots, \hat{y}_n)^\top$； $\|\cdot\|_2^2$: squared L2 norm — sum of squared entries； $\frac{1}{2}$: convenience factor; cancels with the 2 from differentiating the square

How to read it. Geometrically: project $Y$ onto the column space of $X$. Squared error penalizes large residuals quadratically, so it's sensitive to outliers but mathematically clean — convex, differentiable, and unique-minimum whenever $X^\top X$ is invertible.

How to use. Stack training inputs into rows of $X$, targets into $Y$. Find $w$ that minimizes the sum of squared residuals (predicted minus true). Solve in closed form via the normal equation when $d$ is small, or via gradient descent when $d$ is large. To include a bias term, prepend a column of 1's to $X$ and treat it as one more component of $w$.

Gradient
$$ \nabla_w \frac12\|Y-Xw\|_2^2 = X^\top(Xw-Y) $$

Symbols. $\nabla_w$: gradient with respect to $w$; same shape as $w$ (a $d$-vector)； $Xw - Y \in \mathbb{R}^n$: residual vector — predictions minus targets； $X^\top \in \mathbb{R}^{d \times n}$: transpose of the design matrix； $X^\top(Xw - Y)$: column-by-column inner product of features against the residual

How to read it. $X^\top r$ measures how much each feature column 'explains' the leftover error. If a feature is positively correlated with the residual, increasing its weight reduces error — that's exactly the direction the negative gradient points.

How to use. Plug into gradient descent: $w_{t+1} = w_t - \alpha\,X^\top(Xw_t - Y)$. Set the gradient to zero for the closed-form solution. The $j$-th component $[X^\top r]_j$ tells you how to nudge weight $j$ to reduce error, where $r = Xw - Y$ is the residual.

Normal equation
$$ X^\top Xw^* = X^\top Y,\qquad w^*=(X^\top X)^{-1}X^\top Y $$

Symbols. $w^*$: optimal weight vector — the minimizer； $X^\top X \in \mathbb{R}^{d \times d}$: Gram matrix — symmetric, positive-semidefinite； $(X^\top X)^{-1}$: inverse of the Gram matrix; exists iff $X$ has linearly independent columns ($\mathrm{rank}(X)=d$)； $X^\top Y \in \mathbb{R}^d$: feature-target correlation vector

How to read it. 'Stop where the gradient is zero.' The condition $X^\top(Xw - Y) = 0$ says the residual is orthogonal to every feature column — geometrically, $Xw^*$ is the projection of $Y$ onto the column space of $X$, and the leftover $Y - Xw^*$ has zero correlation with any feature.

How to use. Set the gradient $X^\top(Xw - Y) = 0$, rearrange. The first form is the linear system to solve (don't actually invert the matrix in code — use `np.linalg.solve` or a Cholesky factorization for stability and speed); the second form is the explicit formula. If $X^\top X$ is singular (e.g. $n < d$ or duplicated features), use ridge regression instead.

Ridge regularization
$$ \min_w \frac12\|Y-Xw\|_2^2+\frac{\lambda}{2}\|w\|_2^2,\qquad w^*=(X^\top X+\lambda I)^{-1}X^\top Y $$

Symbols. $\lambda \ge 0$: regularization strength (a hyperparameter)； $\|w\|_2^2$: $\sum_j w_j^2$ — sum of squared weights； $\frac{\lambda}{2}\|w\|_2^2$: penalty term that shrinks weights toward 0； $I \in \mathbb{R}^{d \times d}$: identity matrix； $X^\top X + \lambda I$: always invertible when $\lambda > 0$ (positive-definite)

How to read it. Two pressures fighting: 'fit the data well' vs. 'keep weights small.' Small weights → smoother model → less overfitting and a stable solution even when $X^\top X$ is singular. Bayesian view: ridge $=$ MAP estimate under a Gaussian prior $w \sim \mathcal{N}(0, \frac{1}{\lambda} I)$.

How to use. Add the L2 penalty to the OLS objective. Pick $\lambda$ via cross-validation: small $\lambda \approx$ OLS, large $\lambda \approx$ all-zero weights. The closed-form solution just adds $\lambda I$ to the Gram matrix before inverting. Standardize features first — without it, weights with naturally large scales get over-penalized.

5. Worked Examples

Example A · Building the matrix form
Source: Lecture 4, linear model with bias.

For a one-dimensional model $\hat y=w_1x+w_2$, each example becomes a row $[x^{(i)},1]$. The parameter vector is $[w_1,w_2]^\top$. This turns many scalar equations into one matrix product $Xw$.

Example B · One-parameter least squares
Source: HW1 Problem 3(e), paraphrased.

For two points that both lie on the line $y=2x$, the loss for $\hat y=wx$ is $(2-w)^2+(4-2w)^2$. Differentiating gives $10w-20=0$, so $w=2$. A quick sanity check: both residuals become zero.

Example C · Many exact fits, one minimum-norm fit
Source: HW1 Problem 3(a-d), paraphrased.

When $X\in\mathbb{R}^{n\times d}$ has full row rank and $d\ge n$, every target $Y$ can be fit exactly. There may be infinitely many $w$ values, differing by null-space vectors. Gradient descent from $w_0=0$ stays in the row space of $X$ and converges to the exact solution with the smallest Euclidean norm.

6. Problem-Solving Tips

Translate first. Identify whether the problem uses $Xw$ or $X^\top w$ notation, then write dimensions next to every matrix.
For a closed form, write the objective, compute the gradient, set it to zero, then solve the normal equation.
For polynomial regression, build $\phi(x)$ first. After that, the algebra is identical to ordinary linear regression.
For rank questions, ask whether $X^\top X$ is invertible, whether $Xw=Y$ is solvable, and whether the solution is unique.

7. Common Mistakes

  • Forgetting the bias column of ones when the model includes an intercept.
  • Writing $(X^\top X)^{-1}$ when the matrix may be singular or ill-conditioned.
  • Confusing linear in features with linear in parameters. Polynomial features can still use linear regression.
  • Using MSE classification as if it were logistic regression. MSE is not calibrated for binary class probabilities.

8. Exam Focus

  • Derive the normal equation from the MSE objective.
  • Explain when the closed form exists and why ridge helps.
  • Construct the design matrix for a bias term or polynomial features.
  • Explain the overparameterized case: exact interpolation, null space, and minimum-norm solution.
  • State why linear regression is awkward for classification.

9. Quick Checklist

  • I can write the model $\hat y=w^\top\phi(x)$.
  • I can derive $X^\top Xw=X^\top Y$ from squared loss.
  • I know what breaks when $X^\top X$ is not invertible.
  • I can add ridge regularization and write its solution.
  • I can explain why MSE over-penalizes easy classification examples.

📈 Linear Regression · 线性回归

Linear Regression 用线性打分预测连续值。Lecture 4 的主线很清楚：先选 model，再选 loss，最后把 optimization 解出来。

1. Concept Understanding · 概念理解

回归任务里，每个样本有 feature $x^{(i)}$ 和连续标签 $y^{(i)}\in\mathbb{R}$。线性回归假设预测值是 feature 的加权和：

$$ \hat y^{(i)} = w^\top \phi(x^{(i)}) $$

$\phi(x)$ 可以是原始输入、带 bias 的输入，也可以是 polynomial features。它解决的问题是：找到一组参数 $w$，让预测值尽量贴近真实 $y$。

2. Plain-English Explanation · 大白话理解

可以把它想成拿一把尺子去贴散点图。每个点到尺子的竖直距离就是 error。Linear Regression 选择那条“总体最贴”的线，让所有 error 的平方和最小。

为什么平方？小误差影响小，大误差会被放大。这样数学上很顺滑，但也意味着 outlier 会特别有影响力。

3. Core Intuition · 核心直觉

MSE objective 通常是一个 bowl-shaped quadratic。找最优点就是走到碗底；在碗底 gradient = 0，于是得到 normal equation。

Polynomial regression 本质也没变：把 $x$ 换成 $\phi(x)=(x^2,x,1)$ 后，模型对参数 $w$ 仍然是 linear 的。

Lecture 4 还强调：用 linear regression 做 classification 会出问题，因为 MSE 会继续惩罚已经分得很对的 easy examples。

4. Key Equations · 核心公式

MSE objective
$$ \min_w \; \frac12\|Y-Xw\|_2^2 $$

符号. $w \in \mathbb{R}^d$: 待优化的权重向量 —— 每个特征一个权重；$X \in \mathbb{R}^{n \times d}$: 设计矩阵；第 $i$ 行是特征向量 $x_i^\top$；$Y \in \mathbb{R}^n$: 目标值向量 $(y_1, \ldots, y_n)^\top$；$Xw \in \mathbb{R}^n$: 预测值向量 $(\hat{y}_1, \ldots, \hat{y}_n)^\top$；$\|\cdot\|_2^2$: L2 范数的平方 —— 各项平方求和；$\frac{1}{2}$: 方便因子；与平方求导出来的 2 相消

怎么理解. 几何上：把 $Y$ 投影到 $X$ 的列空间上。平方误差对大残差是二次惩罚，对 outlier 敏感，但数学上很干净 —— 凸、可导、当 $X^\top X$ 可逆时有唯一最小值。

怎么用. 把训练输入堆成 $X$ 的行、目标堆成 $Y$。找让残差平方和（预测 − 真实）最小的 $w$。$d$ 小时走 normal equation 闭式解，$d$ 大、数据多时走 gradient descent。要加 bias，在 $X$ 前面加一列全 1，把它当成 $w$ 的一个分量。

Gradient
$$ \nabla_w \frac12\|Y-Xw\|_2^2 = X^\top(Xw-Y) $$

符号. $\nabla_w$: 对 $w$ 求梯度；与 $w$ 同形状（$d$ 维向量）；$Xw - Y \in \mathbb{R}^n$: 残差向量 —— 预测 − 真实；$X^\top \in \mathbb{R}^{d \times n}$: 设计矩阵的转置；$X^\top(Xw - Y)$: 各列特征与残差的内积

怎么理解. $X^\top r$ 衡量每个特征列与残余误差的相关程度。某个特征与残差正相关 → 增大它的权重能降低误差 —— 这正是负梯度的方向。

怎么用. 代入 gradient descent: $w_{t+1} = w_t - \alpha\,X^\top(Xw_t - Y)$。或令梯度等于 0 得到闭式解。第 $j$ 个分量 $[X^\top r]_j$ 告诉你 "怎样调整第 $j$ 个权重才能减小误差"（$r = Xw - Y$ 是残差）。

Normal equation
$$ X^\top Xw^* = X^\top Y,\qquad w^*=(X^\top X)^{-1}X^\top Y $$

符号. $w^*$: 最优权重向量 —— 使目标函数最小的解；$X^\top X \in \mathbb{R}^{d \times d}$: Gram 矩阵 —— 对称、半正定；$(X^\top X)^{-1}$: Gram 矩阵的逆；当且仅当 $X$ 列线性无关（即满列秩 $\mathrm{rank}(X) = d$）时存在；$X^\top Y \in \mathbb{R}^d$: 特征与目标的相关向量

怎么理解. "梯度为 0 处停下"。条件 $X^\top(Xw - Y) = 0$ 表示残差与每个特征列正交 —— 几何上 $Xw^*$ 是 $Y$ 在 $X$ 列空间上的投影，残差 $Y - Xw^*$ 与任何特征都不再相关。

怎么用. 令梯度 $X^\top(Xw - Y) = 0$ 整理即可。第一个形式是要解的线性方程组（代码里别真的求逆，用 `np.linalg.solve` 或 Cholesky 既稳定又快）；第二个形式是显式解。当 $X^\top X$ 奇异（如 $n < d$ 或特征重复）时，改用 ridge regression。

Ridge regularization
$$ \min_w \frac12\|Y-Xw\|_2^2+\frac{\lambda}{2}\|w\|_2^2,\qquad w^*=(X^\top X+\lambda I)^{-1}X^\top Y $$

符号. $\lambda \ge 0$: 正则强度（超参数）；$\|w\|_2^2$: $\sum_j w_j^2$ —— 权重平方和；$\frac{\lambda}{2}\|w\|_2^2$: 把权重拉向 0 的惩罚项；$I \in \mathbb{R}^{d \times d}$: 单位矩阵；$X^\top X + \lambda I$: $\lambda > 0$ 时一定可逆（正定）

怎么理解. 两股力在拔河："拟合好数据" vs. "权重不要太大"。权重小 → 模型更平滑 → 减少过拟合，且即使 $X^\top X$ 奇异也能有稳定解。Bayesian 视角：ridge $=$ 在 Gaussian prior $w \sim \mathcal{N}(0, \frac{1}{\lambda} I)$ 下的 MAP 估计。

怎么用. 在 OLS 目标里加上 L2 惩罚项。$\lambda$ 用 cross-validation 选：$\lambda$ 小 ≈ OLS，$\lambda$ 大 ≈ 全 0 解。闭式解就是在反矩阵前给 Gram 矩阵加 $\lambda I$。先做特征标准化 —— 否则尺度天然大的权重会被惩罚得过狠。

5. Worked Examples · 代表性例题

Example A · 写成矩阵形式
来源：Lecture 4，带 bias 的一维线性模型。

如果模型是 $\hat y=w_1x+w_2$，每个样本对应一行 $[x^{(i)},1]$，参数是 $[w_1,w_2]^\top$。这样一堆标量方程就合成一个 $Xw$。

Example B · 单参数 least squares
来源：HW1 Problem 3(e)，题意转述。

两个点都落在 $y=2x$ 上，模型是 $\hat y=wx$。loss 是 $(2-w)^2+(4-2w)^2$。求导得到 $10w-20=0$，所以 $w=2$。检查一下：两个 residual 都是 0。

Example C · 多个 exact fit，GD 选 minimum-norm
来源：HW1 Problem 3(a-d)，题意转述。

当 $X\in\mathbb{R}^{n\times d}$ 满行秩且 $d\ge n$ 时，任意 $Y$ 都能被 exact fit。解可能有无穷多个，它们相差一个 null-space vector。从 $w_0=0$ 开始的 gradient descent 会留在 row space 里，最后选出 Euclidean norm 最小的那个解。

6. Problem-Solving Tips · 解题技巧

先看 notation。 题里是 $Xw$ 还是 $X^\top w$？先把 shape 写在旁边。
闭式解题型： 写 objective → 求 gradient → 令 0 → 解 normal equation。
Polynomial features： 先构造 $\phi(x)$，之后就是普通 linear regression。
Rank / invertibility： 问自己 $X^\top X$ 是否可逆、$Xw=Y$ 是否有解、解是否唯一。

7. Common Mistakes · 常见错误

  • 模型有 intercept 却忘记加一列全 1 的 bias feature。
  • 不检查 invertibility 就直接写 $(X^\top X)^{-1}$。
  • 把 “linear in features” 和 “linear in parameters” 混掉；polynomial features 仍然可以是 linear regression。
  • 把 MSE classification 当成 logistic regression 用；MSE 不是为概率分类设计的。

🎒 Bagging (Bootstrap Aggregating)

Bagging is the parallel ensemble idea from Lecture 8: train many base learners on bootstrap samples, then aggregate their predictions to reduce variance.

1. Concept Understanding

Bagging means bootstrap aggregating. Each model is trained on a dataset sampled with replacement from the original training set. At prediction time, classification usually uses majority vote.

It is especially useful for high-variance learners like decision trees. A single deep tree can wobble a lot when the data changes slightly; averaging many such trees makes the final prediction more stable.

2. Plain-English Explanation

Instead of asking one unstable tree, ask a room full of trees that each saw a slightly different version of the class notes. Then take the majority answer.

One tree may overreact to noise. Many trees voting together are harder to sway, as long as they do not all make the same mistake.

3. Core Intuition

Averaging independent noisy predictors reduces variance. Bagging creates diversity through bootstrap samples; random forests add even more diversity by considering only a random subset of features at each split.

Bagging does not usually fix high bias. If every base learner is too simple and wrong in the same way, voting will preserve that systematic error.

4. Key Equations

Bootstrap sample
$$ D_t=\{(x_{i_s},y_{i_s})\}_{s=1}^{n},\qquad i_s\sim\text{Uniform}\{1,\dots,n\} $$

Symbols. $D_t$ is the resampled training set for base learner $t$. The original dataset has $n$ examples. $s$ is the draw number, $i_s$ is the index drawn on that draw, and the uniform distribution means every original example has the same chance each time.

How to read it. A bootstrap set is built by drawing $n$ examples with replacement. Some original points may appear multiple times; some may be absent.

How to use. For each base learner, sample $n$ indices with replacement, train $f_t$ on $D_t$, then repeat independently for the next learner.

Majority vote
$$ F(x)=\operatorname{sign}\!\left(\sum_{t=1}^{T} f_t(x)\right) $$

Symbols. $F(x)$ is the ensemble prediction. $T$ is the number of trained base models. $f_t(x)\in\{-1,+1\}$ is model $t$'s vote on example $x$. $\operatorname{sign}$ converts the vote sum into a binary class.

How to read it. Each model votes; the ensemble adds the votes; the final label is whichever side has the larger total.

How to use. Run all trees on the test example, add their $+1/-1$ votes, and choose the sign. For multiclass, choose the most frequent class; for regression, average predictions.

Variance of an average
$$ \operatorname{Var}\!\left(\frac1T\sum_t f_t\right)\approx \frac{\sigma^2}{T} $$

Symbols. $T$ is ensemble size. $f_t$ is one base learner's prediction. $\sigma^2$ is the variance of one base learner. The approximation assumes the learners are roughly independent and similarly variable.

How to read it. Averaging independent noisy predictors makes random fluctuation cancel out, so variance drops by about a factor of $T$.

How to use. Use this as the variance-reduction intuition for bagging. If trees are highly correlated, the reduction is much smaller than $\sigma^2/T$.

Random forest split idea
$$ \text{consider about }\sqrt d\text{ features per split} $$

Symbols. $d$ is the total number of input features. $\sqrt d$ is the common rough number of candidate features checked at each tree split.

How to read it. A random forest does not let every split inspect every feature. It randomly narrows the feature menu before choosing the best local split.

How to use. Mention this when explaining why random forests improve plain bagging: feature subsampling lowers correlation among trees.

5. Worked Examples

Example A · Lecture 8 bagging algorithm
Source: Lecture 8, bagging slide.

For each $t=1,\dots,T$, draw $n$ training examples with replacement, train a base classifier $f_t$, and return a majority-vote classifier over $f_1,\dots,f_T$.

Example B · Random forest adds feature randomness
Source: Lecture 8, random forest slide.

A random forest still bootstraps datasets, but each tree split only searches a random feature subset. This lowers correlation among trees, which helps voting reduce variance.

Example C · Bagging vs boosting comparison
Source: HW2 Problem 5.1, paraphrased.

Bagging trains independently in parallel and mainly reduces variance. Boosting trains sequentially and focuses on previously misclassified examples, so it often reduces bias but is more sensitive to noise.

6. Problem-Solving Tips

Identify bagging by: bootstrap samples, independent base learners, majority vote or average.
When asked “what changes,” say variance decreases; bias usually stays similar.
For random forests, mention both data randomness and feature randomness.
For comparison questions, contrast parallel vs sequential and variance vs bias.

7. Common Mistakes

  • Saying bagging reduces bias as its main effect. Its main exam answer is variance reduction.
  • Forgetting bootstrap means sampling with replacement.
  • Assuming voting helps if all models make identical errors. Correlated errors limit the gain.
  • Calling random forest just “many trees” without feature subsampling.

8. Exam Focus

  • State the bagging algorithm step by step.
  • Explain why averaging reduces variance.
  • Explain how random forests differ from plain bagging.
  • Compare bagging and boosting in one concise paragraph.

9. Quick Checklist

  • I know bootstrap means with replacement.
  • I know bagging trains base learners in parallel.
  • I can explain variance reduction.
  • I can define random forest as bagging plus feature subsampling.
  • I can contrast bagging with boosting.

🎒 Bagging · 装袋法

Bagging 是 Lecture 8 的 parallel ensemble 思想：在 bootstrap samples 上训练多个 base learners，再 aggregate predictions，主要目标是降低 variance。

1. Concept Understanding · 概念理解

Bagging = bootstrap aggregating。每个模型都在从原训练集有放回抽样得到的数据集上训练。预测时，classification 通常用 majority vote。

它特别适合 decision trees 这种 high-variance learners。单棵深树对数据微小变化很敏感；很多树一起投票，最终 prediction 更稳定。

2. Plain-English Explanation · 大白话理解

不要只问一棵容易紧张的树；问一屋子树。每棵树都看过稍微不同版本的讲义，然后大家投票。

一棵树可能被噪声带跑偏；很多树一起投票就不容易被单个噪声点影响。前提是它们不能全犯同一个错误。

3. Core Intuition · 核心直觉

对 independent noisy predictors 做 average 会降低 variance。Bagging 用 bootstrap samples 制造 diversity；Random Forest 又在每个 split 只看随机 feature subset，让树之间更不相关。

Bagging 通常不解决 high bias。如果每个 base learner 都太弱、错法一致，那么投票只会保留这种 systematic error。

4. Key Equations · 核心公式

Bootstrap sample
$$ D_t=\{(x_{i_s},y_{i_s})\}_{s=1}^{n},\qquad i_s\sim\text{Uniform}\{1,\dots,n\} $$

符号. $D_t$ 是第 $t$ 个 base learner 的重采样训练集；原始 dataset 有 $n$ 个样本；$s$ 是第几次抽样；$i_s$ 是第 $s$ 次抽到的样本 index；Uniform 表示每次抽样时每个原始样本概率相同。

怎么理解. Bootstrap 就是“有放回抽样”：抽 $n$ 次组成一个新训练集。同一个样本可以重复出现，也可能完全没被抽到。

怎么用. 对每个 base learner，先抽 $n$ 个 indices 组成 $D_t$，在这个 dataset 上训练 $f_t$，然后对下一个 learner 重新抽。

Majority vote
$$ F(x)=\operatorname{sign}\!\left(\sum_{t=1}^{T} f_t(x)\right) $$

符号. $F(x)$ 是 ensemble prediction；$T$ 是 base models 数量；$f_t(x)\in\{-1,+1\}$ 是第 $t$ 个模型对样本 $x$ 的 vote；$\operatorname{sign}$ 把 vote sum 变成二分类 label。

怎么理解. 每棵树投一票，ensemble 把票加起来，哪边票更多就选哪边。

怎么用. 测试时让所有 trees 预测，把 $+1/-1$ 加起来看正负号。Multiclass 用最多票的 class；regression 用 average。

Variance of an average
$$ \operatorname{Var}\!\left(\frac1T\sum_t f_t\right)\approx \frac{\sigma^2}{T} $$

符号. $T$ 是 ensemble size；$f_t$ 是一个 base learner 的 prediction；$\sigma^2$ 是单个 learner 的 variance；这个近似默认 learners 基本 independent 且 variance 类似。

怎么理解. 多个 independent noisy predictors 做 average，随机波动会互相抵消，所以 variance 大约除以 $T$。

怎么用. 这是 bagging 降 variance 的核心直觉。如果 trees 高度相关，实际下降会远小于 $\sigma^2/T$。

Random forest split idea
$$ \text{每个 split 只考虑约 }\sqrt d\text{ 个 features} $$

符号. $d$ 是总 feature 数；$\sqrt d$ 是每次 tree split 常用的候选 feature 数量。

怎么理解. Random Forest 不让每个 split 都看全部 features，而是先随机抽一小部分 feature，再在里面挑 best split。

怎么用. 解释 Random Forest vs plain Bagging 时要提：feature subsampling 会降低 trees 之间的 correlation。

5. Worked Examples · 代表性例题

Example A · Lecture 8 bagging algorithm
来源：Lecture 8，bagging slide。

对每个 $t=1,\dots,T$，有放回抽 $n$ 个 training examples，训练 base classifier $f_t$，最后对 $f_1,\dots,f_T$ 做 majority vote。

Example B · Random Forest 加 feature randomness
来源：Lecture 8，random forest slide。

Random Forest 仍然使用 bootstrap datasets，但每次 tree split 只在随机 feature subset 中找 best split。这样能降低 trees 之间的 correlation，投票才更有效。

Example C · Bagging vs Boosting
来源：HW2 Problem 5.1，题意转述。

Bagging 独立并行训练，主要降低 variance。Boosting 串行训练，后续模型关注前面错分的样本，通常降低 bias，但对 noise 更敏感。

6. Problem-Solving Tips · 解题技巧

识别 bagging： bootstrap samples、independent base learners、majority vote / average。
问 effect： 主答 variance decreases；bias 通常差不多。
Random Forest： 同时说 data randomness 和 feature randomness。
比较题： parallel vs sequential，variance vs bias。

7. Common Mistakes · 常见错误

  • 把 bagging 的主效果说成降低 bias；考试标准答案通常是降低 variance。
  • 忘记 bootstrap 是 sampling with replacement。
  • 以为所有模型犯同样错误时投票仍然有用；correlated errors 会限制收益。
  • 把 Random Forest 只说成 “many trees”，漏掉 feature subsampling。

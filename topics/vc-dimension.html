Hoeffding and VC Dimension

Lecture 22 moves from finite hypothesis classes to richer classes by using concentration inequalities and VC dimension. The guiding question is: how much model complexity can the data support?

1. Concept Understanding

Hoeffding's inequality says empirical averages of bounded independent random variables concentrate around their expectations.

VC dimension measures how many points a binary hypothesis class can shatter. A set is shattered if the class can realize every possible binary labeling on that set.

  • Higher VC dimension means the class can express more label patterns.
  • Finite VC dimension gives uniform generalization guarantees.
  • Infinite or very large complexity means more samples are needed to control overfitting.

2. Plain-English Explanation

VC dimension asks: how many points can this model label in absolutely any way I request? If it can label many arbitrary patterns, it is powerful, but also dangerous with small data.

Hoeffding is the statistical safety net for one fixed guess. VC dimension is the extra tax we pay when we search over many guesses.

3. Core Intuition

A model class that can shatter many points can also memorize many random labels. That flexibility makes training error less trustworthy. VC bounds correct for this by adding a complexity term that shrinks as $n$ grows.

The main message is not that the bound is always tight; Lecture 22 notes it can be loose. The main message is the direction: more complexity requires more data.

Philosophical takeaway. "If someone can explain every phenomenon, their explanations are worthless." VC dimension is the formal measurement of that ability-to-explain: a class with infinite VC dimension can fit any random noise just as easily as a real pattern, so its training fit carries no signal about generalization. Bounded flexibility is what makes learning meaningful.

4. Key Equations

Hoeffding
$$ \Pr\left(|\bar Z_n-\mathbb{E}\bar Z_n|\ge \epsilon\right)\le 2\exp\left(-\frac{2n\epsilon^2}{(b-a)^2}\right) $$

What it does. The bound says sample averages concentrate around expectations; more samples or a smaller range makes large deviations exponentially unlikely.

Fixed classifier bound
$$ \epsilon_\mu(f)\le \hat\epsilon_{\mathcal{D}}(f)+\sqrt{\frac{\log(2/\delta)}{2n}} $$

What it does. Training error plus a confidence radius upper-bounds test error, but only when the classifier was fixed before looking at the data.

VC dimension definition
$$ \operatorname{VCdim}(\mathcal{F})=\max\{|S|:\mathcal{F}\text{ shatters }S\} $$

What it does. VC dimension is the largest point set on which the class can realize all binary labelings; it measures class flexibility.

Typical VC-style bound
$$ \epsilon_\mu(f)\le \hat\epsilon_{\mathcal{D}}(f)+\mathcal{O}\!\left(\sqrt{\frac{\operatorname{VCdim}(\mathcal{F})+\log(1/\delta)}{n}}\right) $$

What it does. This is a scaling rule for generalization gap: complexity and confidence increase the gap, while sample size shrinks it.

Which bound should I use?

Use Hoeffding when the classifier is fixed before data. Use a VC-style or uniform bound when the classifier is selected from a class after seeing the training set.

Fundamental Theorem of Statistical Learning

The single high-value theorem from learning theory worth a full sentence on the cheat sheet. For binary classification with 0-1 loss, the following three statements are equivalent:

  1. The hypothesis class $\mathcal{H}$ is PAC-learnable.
  2. $\mathcal{H}$ has finite VC dimension ($\mathrm{VCdim}(\mathcal{H})<\infty$).
  3. Uniform convergence holds over $\mathcal{H}$ — empirical risk concentrates around true risk for every $h\in\mathcal{H}$ simultaneously.

Why it matters. "PAC-learnable" sounds like a property of the algorithm; "finite VC" is a structural property of the class; "uniform convergence" is a probabilistic property of the empirical risk landscape. The theorem says these are all the same thing in the binary 0-1 setting — so finiteness of $|\mathcal{H}|$ is sufficient but not necessary for PAC-learnability.

Finite versus infinite classes. For a finite class, $\log|\mathcal{H}|$ can be the complexity term. For an infinite class, raw cardinality is no longer useful; $\mathrm{VCdim}(\mathcal{H})$ replaces it. Larger VC dimension means a more flexible class, and the bound asks for more data because the gap scales roughly like $\sqrt{\mathrm{VCdim}(\mathcal{H})/n}$.

Canonical example. Threshold functions $h_c(x)=\mathbf{1}\{x\ge c\}$ on the real line form an infinite class ($c\in\mathbb{R}$), yet $\mathrm{VCdim}=1$ (Example 1 below). By the theorem, this class is PAC-learnable — and indeed it is, with $\mathcal{O}(\tfrac{1}{\epsilon}\log\tfrac{1}{\delta})$ samples. Without the theorem, you might wrongly conclude that infinite classes can never be PAC-learnable.

Exam template. When asked "is class $\mathcal{H}$ PAC-learnable?", don't try to invent a sample-complexity bound by hand — compute $\mathrm{VCdim}(\mathcal{H})$. Finite VC dimension ⇒ yes; infinite VC dimension ⇒ no. The reverse direction (using PAC-learnability to deduce uniform convergence) appears on theoretical questions about why ERM works.

Standard VC dimensions to memorize

A handful of canonical hypothesis classes whose VC dimension shows up over and over on quizzes / finals. Memorize the values and one sentence of why for each.

Hypothesis class $\mathrm{VCdim}$ Why / quickest counterexample
Thresholds on $\mathbb{R}$
$h_c(x)=\mathbf{1}\{x\ge c\}$		$1$Two ordered points $x_1<x_2$ cannot get the labeling $(+,-)$ — the rule is monotone.
Intervals on $\mathbb{R}$
$h_{a,b}(x)=\mathbf{1}\{x\in[a,b]\}$		$2$Three points $x_1<x_2<x_3$ cannot get the labeling $(+,-,+)$ — a single interval can't include the outer two while excluding the middle.
Lines in $\mathbb{R}^2$ (linear classifiers)$3$Three non-collinear points are shatterable; four points fail under an XOR-style labeling.
Non-homogeneous halfspaces in $\mathbb{R}^d$
$h_{w,b}(x)=\mathrm{sign}(w^\top x+b)$		$d+1$Generalization of the 2D case. The "+1" is the bias degree of freedom.
Homogeneous halfspaces in $\mathbb{R}^d$
$h_w(x)=\mathrm{sign}(w^\top x)$		$d$Boundary must pass through origin — one fewer degree of freedom than the non-homogeneous case.
Axis-aligned rectangles in $\mathbb{R}^2$$4$Four extreme points (top / bottom / left / right) shatter; for any 5 points, the innermost cannot be labeled "$-$" if the four outer ones are "$+$".
Neural nets with sign activation$\mathcal{O}(|E|\log|E|)$Scales with the number of edges $|E|$. The full proof is technical, but the takeaway is "VC scales with parameter count, not depth."
$\sin(\alpha x)$ classifiers
$h_\alpha(x)=\mathrm{sign}(\sin(\alpha x))$		$\infty$Cranking $\alpha$ up makes the function oscillate fast enough to realize any binary labeling on any finite point set. One real parameter, infinite VC — the textbook warning that "few parameters" does not mean "low complexity."

How to use the table. When a question asks "what is $\mathrm{VCdim}$ of class X?", first try to match X to a row above; many quiz problems are direct rephrasings of one of these. When asked to prove a stated value, follow the two-part pattern: (i) lower bound by exhibiting a shatterable set of size $d$, (ii) upper bound by showing every set of size $d+1$ has at least one impossible labeling.

Connection to the bound. Plugging any of these into the typical VC-style bound, the generalization gap scales as $\sqrt{\mathrm{VCdim}/n}$. So a more expressive class (larger VC) buys you smaller approximation error but requires more data to keep the estimation gap small — exactly the bias-variance trade-off, written in learning-theory notation.

5. Worked Examples

Example 1 · thresholds on the real line

Source: HW5, Section 1.3.

The class $h_c(x)=\mathbf{1}\{x\ge c\}$ can shatter one point: choose the threshold on either side. It cannot shatter two ordered points because the labeling $(1,0)$ violates the monotone shape of the threshold rule. So the VC dimension is 1.

Example 2 · linear classifiers in $\mathbb{R}^2$

Source: Lecture 22, p. 26.

Some set of three points can be shattered by lines in the plane, but no arrangement of four points can realize every labeling; an XOR-style labeling blocks linear separation. Thus the VC dimension is 3.

Example 3 · coin flipping concentration

Source: Lecture 22, p. 22.

If a coin is flipped 1000 times, the empirical head frequency is an average of bounded independent variables. Hoeffding converts the desired confidence level into a numerical tolerance around the true head probability.

6. Problem-Solving Tips

  1. To prove VC dimension is at least $d$, exhibit one set of $d$ points that can be shattered.
  2. To prove VC dimension is at most $d$, show every set of $d+1$ points fails at least one labeling.
  3. For thresholds, use ordering and monotonicity.
  4. For Hoeffding, identify the bounded random variable, its empirical average, and its expectation.
  5. For sample complexity, solve the complexity term so it is at most the target error.

7. Common Mistakes

  • Showing one set of $d+1$ points cannot be shattered and claiming an upper bound. You need all sets of size $d+1$ to fail.
  • Thinking shattering means fitting one labeling. It means fitting every labeling.
  • Applying a fixed-$f$ Hoeffding bound to a data-selected model.
  • Reading the VC bound as exact test error. It is an upper bound and may be loose.

8. Exam Focus

  • State shattering and VC dimension cleanly.
  • Know the two-part proof pattern: lower bound by construction, upper bound by impossible labeling.
  • Use Hoeffding for fixed hypotheses and VC bounds for uniform control.
  • Remember finite VC dimension implies PAC learnability for binary classification.
  • Explain why infinite hypothesis classes can still be PAC-learnable when VC dimension is finite.

9. Quick Checklist

  • Shatter = realize all labelings.
  • VC dimension = largest shatterable set size.
  • Thresholds on $\mathbb{R}$ have VC dimension 1.
  • Lines in $\mathbb{R}^2$ have VC dimension 3.
  • Complexity term shrinks like roughly $\sqrt{d/n}$.
  • Finite class: use $\log|\mathcal{H}|$; infinite class: use VC dimension.

Hoeffding 与 VC Dimension

Lecture 22 从有限 hypothesis class 推到更一般的模型类：用 concentration inequality 控制固定函数，用 VC dimension 衡量整个 class 的复杂度。

1. Concept Understanding · 概念理解

Hoeffding's inequality 说明 bounded independent random variables 的 empirical average 会集中在 expectation 附近。

VC dimension 衡量一个二分类 hypothesis class 能 shatter 多大的点集。shatter 的意思是：对这个点集的任意 0/1 labeling，class 里都能找到一个函数实现它。

  • VC dimension 越大，模型能表达的 label pattern 越多。
  • 有限 VC dimension 能给 uniform generalization guarantee。
  • 复杂度太高时，需要更多样本来控制 overfitting。

2. Plain-English Explanation · 大白话理解

VC dimension 问的是：给我几个点，我随便指定红蓝标签，你这个模型都能画出来吗？能随便画的点越多，模型越强，也越容易在小数据上乱记。

Hoeffding 是“固定一个答案时”的安全网；VC dimension 是“我从很多答案里挑一个时”额外要交的复杂度税。

3. Core Intuition · 核心直觉

一个能 shatter 很多点的 class，也可能记住很多 random labels，所以 training error 更不可信。VC bound 用 complexity term 修正这种不可信度，样本数 $n$ 越大，这个 term 越小。

Lecture 22 也提醒：这个 bound 可能很松。它最重要的不是精确数值，而是方向：模型越复杂，需要越多数据。

哲学层面. "如果一个人什么现象都能解释，那他的解释就一文不值。" VC dimension 正是对这种 "解释能力" 的形式化测量：infinite VC dimension 的 class 拟合 random noise 与拟合真实 pattern 一样轻松，所以 training fit 对 generalization 完全无信号。学习有意义的前提，是 flexibility 必须有上限。

4. Key Equations · 关键公式

Hoeffding
$$ \Pr\left(|\bar Z_n-\mathbb{E}\bar Z_n|\ge \epsilon\right)\le 2\exp\left(-\frac{2n\epsilon^2}{(b-a)^2}\right) $$

这个公式在做什么？ 控制 sample average 偏离真实期望的概率；样本越多、允许误差越大，右边会指数级变小。

固定 classifier bound
$$ \epsilon_\mu(f)\le \hat\epsilon_{\mathcal{D}}(f)+\sqrt{\frac{\log(2/\delta)}{2n}} $$

这个公式在做什么？ 对一个事先固定的 classifier，用 training error 加一个 confidence radius 来 upper-bound test error。

VC dimension 定义
$$ \operatorname{VCdim}(\mathcal{F})=\max\{|S|:\mathcal{F}\text{ shatters }S\} $$

这个公式在做什么？ 定义模型 class 最多能 shatter 几个点；它衡量 hypothesis class 的表达能力。

典型 VC-style bound
$$ \epsilon_\mu(f)\le \hat\epsilon_{\mathcal{D}}(f)+\mathcal{O}\!\left(\sqrt{\frac{\operatorname{VCdim}(\mathcal{F})+\log(1/\delta)}{n}}\right) $$

这个公式在做什么？ 把模型复杂度和 confidence cost 加到 generalization gap 里；VC dimension 越大，需要的样本越多。

应该用哪个 bound？

如果 classifier 在看数据前已经固定，用 Hoeffding。若 classifier 是看完 training set 后从整个 class 里挑出来的，用 VC-style / uniform bound。

Fundamental Theorem of Statistical Learning（统计学习基本定理）

学习理论里值得在 cheat sheet 上完整写下的那条定理。对二分类 + 0-1 loss，下面三件事 等价：

  1. hypothesis class $\mathcal{H}$ 是 PAC-learnable；
  2. $\mathcal{H}$ 的 VC dimension 有限（$\mathrm{VCdim}(\mathcal{H})<\infty$）；
  3. $\mathcal{H}$ 上 uniform convergence 成立 —— 对每个 $h\in\mathcal{H}$ 同时有 empirical risk 集中在 true risk 附近。

为什么重要. "PAC-learnable" 听起来是算法的性质，"finite VC" 是 class 的结构性质，"uniform convergence" 是 empirical risk 的概率性质 —— 定理告诉你这三件事在二分类 0-1 setting 下是同一件事。所以 $|\mathcal{H}|$ 有限是 PAC-learnability 的 sufficient 但 不 necessary 条件。

有限类 vs 无限类. 对 finite class，可以用 $\log|\mathcal{H}|$ 当 complexity term。对 infinite class，raw cardinality 已经没用了，要用 $\mathrm{VCdim}(\mathcal{H})$ 替代。VC dimension 越大，class 越灵活，bound 需要更多数据，因为 generalization gap 大致按 $\sqrt{\mathrm{VCdim}(\mathcal{H})/n}$ 缩小。

典型例子. 实数轴上的 threshold function $h_c(x)=\mathbf{1}\{x\ge c\}$ 是 infinite class（$c\in\mathbb{R}$），但 $\mathrm{VCdim}=1$（下面例 1）。由定理可知它仍然 PAC-learnable，sample complexity 大约 $\mathcal{O}(\tfrac{1}{\epsilon}\log\tfrac{1}{\delta})$。没有这条定理，可能会误以为 infinite class 都不能 PAC-learnable。

考试模板. 题目问 "$\mathcal{H}$ PAC-learnable 吗？"，不要硬手算 sample complexity bound —— 直接算 $\mathrm{VCdim}(\mathcal{H})$。finite VC dimension ⇒ 是；infinite VC dimension ⇒ 否。反方向（用 PAC-learnability 推 uniform convergence）出现在解释 ERM 为什么有效的理论题里。

怎么用这张表. 题目问 "class X 的 $\mathrm{VCdim}$ 是多少？"，先尝试与上表逐行匹配 —— 多数 quiz 题就是上面某一行的换皮。如果要你 证明 某个值，按两步模板：(i) 给出大小为 $d$ 的可 shatter 集做 lower bound；(ii) 证明任意大小为 $d+1$ 的集合都至少有一个 labeling 做不到，得 upper bound。

5. Worked Examples · 代表性例题

例 1 · real line 上的 threshold

出处：HW5, Section 1.3。

$h_c(x)=\mathbf{1}\{x\ge c\}$ 可以 shatter 一个点：threshold 放在点左边或右边即可。但不能 shatter 两个有序点，因为 labeling $(1,0)$ 违反 threshold 的 monotone 结构。所以 VC dimension 是 1。

例 2 · $\mathbb{R}^2$ 中的 linear classifier

出处：Lecture 22, p. 26。

平面中的直线可以 shatter 某组三个点；但四个点总会遇到类似 XOR 的 labeling，线性分隔无法实现所有情况。因此 VC dimension 是 3。

例 3 · coin flipping concentration

出处：Lecture 22, p. 22。

抛硬币 1000 次时，head frequency 是 bounded independent variables 的平均值。Hoeffding 可以把 confidence level 转成 true head probability 附近的误差范围。

6. Problem-Solving Tips · 解题技巧

  1. 证明 VC dimension 至少是 $d$：构造一组能被 shatter 的 $d$ 个点。
  2. 证明 VC dimension 至多是 $d$：说明任意 $d+1$ 个点都会有某种 labeling 做不到。
  3. threshold 题常用 ordering 和 monotonicity。
  4. Hoeffding 题先找 bounded random variable、empirical average、expectation。
  5. sample complexity 题把 complexity term 控制到目标 error 以下。

7. Common Mistakes · 常见错误

  • 只展示一组 $d+1$ 个点不能 shatter 就说上界成立；上界需要所有 $d+1$ 点集都失败。
  • 以为 shatter 是拟合一种 labeling；其实是所有 labelings 都能拟合。
  • 把 fixed-$f$ Hoeffding bound 套到 data-selected model。
  • 把 VC bound 当精确 test error；它只是可能很松的上界。

8. Exam Focus · 考试重点

  • 能清楚定义 shattering 和 VC dimension。
  • 掌握两步证明：下界靠构造，上界靠 impossible labeling。
  • 固定 hypothesis 用 Hoeffding；整个 class 用 VC / uniform bound。
  • 记住二分类里 finite VC dimension implies PAC learnability。
  • 能解释为什么 infinite hypothesis class 只要 VC dimension 有限，也可以 PAC-learnable。

9. Quick Checklist · 速记清单

  • Shatter = 实现所有 labelings。
  • VC dimension = 最大可 shatter 点集大小。
  • $\mathbb{R}$ 上 threshold 的 VC dimension 是 1。
  • $\mathbb{R}^2$ 中 line classifier 的 VC dimension 是 3。
  • 复杂度项大致随 $\sqrt{d/n}$ 缩小。
  • Finite class 用 $\log|\mathcal{H}|$；infinite class 用 VC dimension。

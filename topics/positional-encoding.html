🌊 Positional Encoding

Self-attention is permutation-invariant, so token positions must be injected explicitly.

Sinusoidal PE
$$ PE_{(pos,2i)}=\sin\!\Big(\tfrac{pos}{10000^{2i/d}}\Big),\;PE_{(pos,2i+1)}=\cos\!\Big(\tfrac{pos}{10000^{2i/d}}\Big) $$
✅ Exam focus

$PE(pos+k)$ is a linear function of $PE(pos)$ (a 2-D rotation depending only on $k$). This lets the model learn relative positions easily.

🌊 2. Positional Encoding · 位置编码

Self-attention 对输入顺序不敏感（permutation invariant），需要显式注入位置信息。

Sinusoidal PE
$$ PE_{(pos,2i)}=\sin\!\Big(\tfrac{pos}{10000^{2i/d}}\Big),\quad PE_{(pos,2i+1)}=\cos\!\Big(\tfrac{pos}{10000^{2i/d}}\Big) $$
✅ Exam focus

$PE(pos+k)$ 可表示为 $PE(pos)$ 的线性变换（旋转 / 相位移动），便于模型学习相对位置关系。

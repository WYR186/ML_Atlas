🖼️ Convolutional Neural Networks

  • Local connectivity: each filter sees a small spatial patch (edges, textures).
  • Weight sharing: same filter slides across the input → translation invariance with far fewer parameters.
  • Typical block: Conv → Pool → Conv → Pool → ... → FC.
Output size (must-know)
$$ \text{Output}=\left\lfloor\frac{N+2P-F}{S}\right\rfloor+1 $$
$N$ input, $P$ padding, $F$ kernel, $S$ stride. For 2D, apply per axis.
⚠️ Pitfalls
  • Forgetting the floor.
  • Writing $P$ instead of $2P$.
  • Mixing up $F$ (kernel) with $S$ (stride).
🧩 Plug in numbers

$N=32,\,F=5,\,P=2,\,S=1$ → $\lfloor (32+4-5)/1\rfloor+1 = 32$. Padding 2 cancels the kernel-5 shrink.

🖼️ 3. CNN

  • 局部连接：感受野关注局部（边缘/纹理）。
  • 权重共享：同一卷积核滑动 → 参数更少 + 平移不变性。
  • 核心结构：Conv（特征提取）→ Pooling（降采样）→ FC（分类/回归）。
必考 · Output Size（一维，2D 对 H/W 分别算）
$$ \text{Output}=\left\lfloor\frac{N+2P-F}{S}\right\rfloor+1 $$
$N$ 输入；$P$ padding；$F$ kernel；$S$ stride。
⚠️ Pitfall
  • 忘记取 floor。
  • 把 $2P$ 写成 $P$。
  • 用错 $F$ 与 $S$。
🧩 Example · 输出尺寸

$N=32,F=5,P=2,S=1$：

$$ \left\lfloor\frac{32+4-5}{1}\right\rfloor+1 = 31+1 = 32 $$

$P=2$ 抵消 $F=5$ 的缩小效应。

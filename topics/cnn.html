Convolutional Neural Networks

A CNN is a neural network designed for grid-like data, especially images. Lecture 12 emphasizes two ideas: each filter looks at a local patch, and the same filter is reused across the image. The big themes are hierarchy, locality, translation equivariance, and local invariance.

1. Concept Understanding

A fully connected layer treats every pixel position as unrelated. For images, that wastes parameters and ignores spatial structure. A $1000\times1000$ RGB image has 3 million input numbers, so a first hidden layer with 1000 units would need 3 billion weights before even counting bias terms. CNNs solve this by using convolution layers, pooling layers, nonlinear activations, and eventually fully connected heads.

  • Local connectivity: a filter sees a small receptive field, not the whole image at once.
  • Weight sharing: the same filter slides over many positions, so one edge detector can be reused everywhere.
  • Spatial structure: shuffling pixels destroys an image for CNNs because neighbors matter; an MLP has no built-in notion of pixel neighborhood.
  • Filter volume: one filter has shape $F_h\times F_w\times C_{\text{in}}$; using $C_{\text{out}}$ filters creates $C_{\text{out}}$ output feature maps.
  • Pooling: a fixed operation such as max or average summarizes a local window, usually reduces spatial size, and adds no learned parameters.

2. Plain-English Explanation

Think of a convolution filter as a tiny stencil that scans over an image. At each location it asks, “does this little pattern appear here?” One stencil might detect vertical edges; another might detect a corner; deeper layers combine those into object parts.

Pooling is like making a lower-resolution summary: keep the strongest signal in each small neighborhood, or average the neighborhood, so later layers do not have to track every pixel exactly.

3. Core Intuition

Images have repeated local patterns. An edge can appear in the top-left or bottom-right; it is still the same edge. Weight sharing gives CNNs translation equivariance: shifting the input tends to shift the feature map rather than forcing a brand-new detector.

Deeper layers grow the effective receptive field: a unit in layer 1 may depend on a tiny patch, but a unit several layers later depends on a much larger region of the original image. That is how CNNs build hierarchy: edges become corners, corners become textures, and textures become object parts.

Why CNNs use fewer parameters

If a large image feeds a fully connected layer, every input pixel gets a separate weight for every hidden unit. A convolution only learns a small filter and reuses it everywhere. This is the same reason a $3\times3$ convolution with 16 RGB filters has only $3\cdot3\cdot3\cdot16+16=448$ parameters.

4. Key Equations

Spatial output size
$$ H_{\text{out}}=\left\lfloor\frac{H_{\text{in}}+2P_h-F_h}{S_h}\right\rfloor+1,\qquad W_{\text{out}}=\left\lfloor\frac{W_{\text{in}}+2P_w-F_w}{S_w}\right\rfloor+1 $$

What it does. Padded input size minus filter size tells you how much room the filter has to move; dividing by stride counts the moves; the final $+1$ counts the starting position.

Convolution parameter count
$$ \#\text{params}=F_hF_wC_{\text{in}}C_{\text{out}}+C_{\text{out}}=(F_hF_wC_{\text{in}}+1)C_{\text{out}} $$

What it does. Each output channel has one filter, and each filter spans all input channels, so one filter has $F_hF_wC_{\text{in}}$ weights.

One output activation
$$ y_{u,v,k}=b_k+\sum_{c=1}^{C_{\text{in}}}\sum_{i=0}^{F_h-1}\sum_{j=0}^{F_w-1}W_{i,j,c,k}\,x_{uS_h+i-P_h,\;vS_w+j-P_w,\;c} $$

What it does. One output number is a weighted sum of a local patch, plus a bias. The same kernel weights are reused at every spatial location.

Pooling output
$$ y_{u,v,c}^{\max}=\max_{(i,j)\in\text{window}(u,v)}x_{i,j,c},\qquad y_{u,v,c}^{\text{avg}}=\frac{1}{F_hF_w}\sum_{(i,j)\in\text{window}(u,v)}x_{i,j,c} $$

What it does. Pooling uses a local window like convolution, but usually has no learned weights and no bias.

Cross-correlation note
$$ \text{deep-learning convolution usually means cross-correlation} $$

What it does. Most CNN layers use cross-correlation. Learning still works because the kernel entries are learned; flipping convention mainly changes how we name the operation.

5. Worked Examples

Example A · HW3 §3.1 output shape and parameters

Source: HW3 §3.1. Paraphrased.

Input is $3\times32\times32$. Use 16 filters of size $3\times3$, stride $1$, padding $1$. Spatial size is $\lfloor(32+2-3)/1\rfloor+1=32$, so output is $16\times32\times32$. Parameters are $3\cdot3\cdot3\cdot16+16=448$.

Example B · HW3 §3.1 average-pooling-like convolution

Source: HW3 §3.1. Paraphrased.

A $2\times2$ kernel whose entries are all $0.25$, with stride $2$ and no padding, replaces each non-overlapping $2\times2$ patch by its average. That is exactly average pooling when the kernel is fixed and has no learned bias.

Example C · HW3 §3.3 convolution as a matrix

Source: HW3 §3.3. Paraphrased.

Flatten a small image into a vector and flatten the outputs too. The convolution becomes a sparse matrix multiplication. Each row has only the kernel entries in the positions covered by that sliding window; neighboring rows reuse the same values shifted over. In backprop, the gradient passed to the input is multiplied by the transpose of this sparse convolution matrix.

6. Problem-Solving Tips

  • Compute height and width separately; do not assume square inputs unless the problem says so.
  • Track channels: filters span all input channels and create output channels.
  • For parameter count, multiply kernel height, kernel width, input channels, and number of filters; then add biases if present.
  • For pooling, remember there are usually no learned parameters.
  • For multi-layer CNNs, feed each layer's output shape into the next layer. The final answer is often wrong because of one early stride or padding mistake.
Layer variants to recognize
  • $1\times1$ pointwise convolution: changes the channel count without changing height or width. It is often used as a bottleneck.
  • Dilated convolution: inserts gaps inside the kernel to expand receptive field without adding more kernel parameters.
  • Transposed convolution: a learned upsampling layer used in segmentation and generative decoders; it is often described as fractionally strided convolution.
  • Batch normalization in CNNs: normalizes each channel using statistics shared across batch and spatial locations, then applies learned scale and shift.

7. Common Mistakes

  • Using $P$ instead of $2P$ in the output-size formula.
  • Forgetting the floor when stride does not divide evenly.
  • Counting one kernel per pixel location; CNNs share the same kernel across locations.
  • Forgetting that a $3\times3$ filter on RGB input has $3\times3\times3$ weights, not just $9$.
  • Counting pooling parameters. Standard max pooling and average pooling are fixed operations.

8. Exam Focus

  • Output volume size with stride and padding.
  • Number of trainable parameters in convolution layers.
  • Max pooling and average pooling by hand on a small grid.
  • Explain local connectivity, weight sharing, and why CNNs suit images.
  • Know why ReLU is preferred over sigmoid in deep CNNs: it keeps gradients healthier and is cheap to compute.
  • Recognize the architecture landmarks: LeNet-5 for early digit recognition, AlexNet for deep ImageNet CNNs with ReLU/dropout, VGG for stacked $3\times3$ filters, GoogLeNet for Inception modules, and ResNet for residual skip connections.

9. Quick Checklist

  • I can compute $N_{\text{out}}=\lfloor(N_{\text{in}}+2P-F)/S\rfloor+1$ for every layer in a stack.
  • I can count convolution weights including channels and bias.
  • I can explain the difference between convolution, pooling, stride, and padding.
  • I can turn a tiny convolution into a sparse matrix pattern.
  • I remember the biological analogy: simple cells resemble local filters; complex cells resemble pooling over local responses.
  • If convolution is written as a sparse matrix $A$, I know backprop to the input uses $A^\top$.

CNN · 卷积神经网络

CNN 是专门处理 grid-like data 的神经网络，尤其适合 image。Lecture 12 的核心是两件事：filter 只看局部 patch；同一个 filter 在整张图上重复使用。总主题是 hierarchy、locality、translation equivariance 和 local invariance。

1. Concept Understanding

Fully-connected layer 会把每个像素位置都当成独立特征，参数量巨大，也不利用空间结构。一个 $1000\times1000$ RGB image 有 300 万个输入数，如果第一层有 1000 个 hidden units，光第一层就需要 30 亿个 weights，还没算 bias。CNN 用 convolution layer、pooling layer、activation，最后接 fully connected head 来解决这个问题。

  • Local connectivity：filter 只看小的 receptive field，不是一上来就看全图。
  • Weight sharing：同一个 filter 在不同位置滑动，edge detector 可以全图复用。
  • Spatial structure：如果把 pixels 随机打乱，图像内容会被破坏；MLP 本身没有内置“相邻像素有关”的假设。
  • Filter volume：一个 filter 的 shape 是 $F_h\times F_w\times C_{\text{in}}$；用 $C_{\text{out}}$ 个 filters 就得到 $C_{\text{out}}$ 张 feature maps。
  • Pooling：用 max / average 等固定操作总结局部窗口，通常会降低 spatial size，而且没有 learnable parameters。

2. Plain-English Explanation / 大白话理解

把 convolution filter 想成一个小模板，在图片上从左到右、从上到下扫描。每扫到一个位置，它就问：“这个局部有没有我关心的 pattern？”浅层可能看边缘，深层会把边缘组合成纹理、部件、物体。

Pooling 像是在做低清版摘要：每个小区域只保留最大反应，或者取平均，让后面的层不用追踪每一个像素。

3. Core Intuition

图片里的局部模式会重复出现。边缘出现在左上角还是右下角，本质仍然是边缘。Weight sharing 给 CNN 带来 translation equivariance：输入平移时，feature map 也大致平移，而不是需要重新学习一个 detector。

层数越深，effective receptive field 越大：第一层 unit 可能只依赖一个小 patch，但后面几层的 unit 会依赖原图里更大的区域。这就是 CNN 的 hierarchy：边缘组合成角点，角点组合成纹理，纹理再组合成 object parts。

为什么 CNN 参数少

大图接 fully connected layer 时，每个 pixel 对每个 hidden unit 都要单独学 weight。Convolution 只学一个小 filter，然后全图复用。同样是 RGB input，一个 $3\times3$ convolution 加 16 个 filters 只有 $3\cdot3\cdot3\cdot16+16=448$ 个参数。

4. 关键公式

Spatial output size：输出高宽怎么算
$$ H_{\text{out}}=\left\lfloor\frac{H_{\text{in}}+2P_h-F_h}{S_h}\right\rfloor+1,\qquad W_{\text{out}}=\left\lfloor\frac{W_{\text{in}}+2P_w-F_w}{S_w}\right\rfloor+1 $$

这个公式在做什么？ padded input size 减 filter size，表示 filter 可移动的范围；除以 stride 是数能移动几步；最后 $+1$ 是把初始位置算进去。

Convolution parameter count
$$ \#\text{params}=F_hF_wC_{\text{in}}C_{\text{out}}+C_{\text{out}}=(F_hF_wC_{\text{in}}+1)C_{\text{out}} $$

这个公式在做什么？ 每个 output channel 对应一个 filter。一个 filter 会跨过所有 $C_{\text{in}}$ 个 input channels，所以一个 filter 有 $F_hF_wC_{\text{in}}$ 个 weights。

一个输出位置怎么来的
$$ y_{u,v,k}=b_k+\sum_{c=1}^{C_{\text{in}}}\sum_{i=0}^{F_h-1}\sum_{j=0}^{F_w-1}W_{i,j,c,k}\,x_{uS_h+i-P_h,\;vS_w+j-P_w,\;c} $$

这个公式在做什么？ 一个 output number = 局部 patch 的 weighted sum + bias。同一组 kernel weights 会在所有空间位置重复使用。

Pooling output
$$ y_{u,v,c}^{\max}=\max_{(i,j)\in\text{window}(u,v)}x_{i,j,c},\qquad y_{u,v,c}^{\text{avg}}=\frac{1}{F_hF_w}\sum_{(i,j)\in\text{window}(u,v)}x_{i,j,c} $$

这个公式在做什么？ Pooling 也看一个 local window，但通常没有 learned weights，也没有 bias。

Cross-correlation 小提醒
$$ \text{deep-learning convolution usually means cross-correlation} $$

这个公式在做什么？ 大多数 CNN layer 实际做的是 cross-correlation。因为 kernel 是学出来的，是否翻转主要影响命名，不影响学习机制。

Example A · HW3 §3.1 输出尺寸和参数量

来源：HW3 §3.1，已转述。

输入 $3\times32\times32$，16 个 $3\times3$ filters，stride $1$，padding $1$。空间尺寸：$\lfloor(32+2-3)/1\rfloor+1=32$，所以输出是 $16\times32\times32$。参数量：$3\cdot3\cdot3\cdot16+16=448$。

Example B · HW3 §3.1 类似 average pooling 的卷积

来源：HW3 §3.1，已转述。

如果 $2\times2$ kernel 的每个值都是 $0.25$，stride $2$，no padding，那么每个不重叠的 $2\times2$ patch 都会被替换成平均值。这个 fixed kernel、no bias 的 convolution 等价于 average pooling。

Example C · HW3 §3.3 convolution 写成矩阵

来源：HW3 §3.3，已转述。

把小图片 flatten 成向量，输出也 flatten。Convolution 可以写成 sparse matrix multiplication。每一行只在当前 sliding window 覆盖的位置放 kernel 权重，相邻行是同一组权重的平移版本。做 backprop 时，传回 input 的 gradient 会乘这个 sparse convolution matrix 的 transpose。

6. Problem-Solving Tips

  • Height 和 width 分开算，不要默认一定是正方形。
  • 一定追踪 channel：filter 会跨过所有 input channels，并产生 output channels。
  • 参数量先乘 kernel height、kernel width、input channels、filters 数量，再看有没有 bias。
  • Pooling 通常没有 learnable parameters。
  • 多层 CNN 题要一层一层传 shape；很多错答案都是前面某一层 stride / padding 少算了一步。
需要认识的 layer variants
  • $1\times1$ pointwise convolution：只改 channels，不改 height / width，常用作 bottleneck。
  • Dilated convolution：在 kernel 里“打洞”，扩大 receptive field，但不增加 kernel 参数量。
  • Transposed convolution：learned upsampling layer，常用于 segmentation / generative decoder，也叫 fractionally strided convolution。
  • Batch normalization in CNNs：对每个 channel 用 batch 和 spatial locations 上的统计量做 normalization，再学习 scale 和 shift。

7. Common Mistakes

  • Output size 公式里把 $2P$ 写成 $P$。
  • Stride 不能整除时忘记 floor。
  • 以为每个空间位置都有独立 kernel；CNN 的 kernel 是共享的。
  • RGB 输入上的 $3\times3$ filter 有 $3\times3\times3$ 个权重，不是只有 $9$ 个。
  • 给 pooling layer 数 trainable parameters。标准 max pooling / average pooling 是 fixed operation。

8. Exam Focus

  • 带 stride / padding 的 output volume size。
  • Convolution layer 的 trainable parameter count。
  • 在小 grid 上手算 max pooling / average pooling。
  • 解释 local connectivity、weight sharing，以及为什么 CNN 适合 image。
  • 会解释为什么 deep CNN 常用 ReLU 而不是 sigmoid：ReLU 缓解 vanishing gradient，计算也更便宜。
  • 能一句话识别架构演进：LeNet-5 用于早期 digit recognition，AlexNet 推动 deep ImageNet CNN 并使用 ReLU/dropout，VGG 用堆叠 $3\times3$ filters，GoogLeNet 用 Inception modules，ResNet 用 residual / skip connections。

9. Quick Checklist

  • 我会逐层计算 $N_{\text{out}}=\lfloor(N_{\text{in}}+2P-F)/S\rfloor+1$。
  • 我会把 channels 和 bias 算进参数量。
  • 我能区分 convolution、pooling、stride、padding。
  • 我能把小卷积看成 sparse matrix pattern。
  • 我记得 biological analogy：simple cells 类似 local filters；complex cells 类似对局部响应做 pooling。
  • 如果 convolution 写成 sparse matrix $A$，backprop 到 input 会用 $A^\top$。

📐 Linear Algebra

1. Concept Understanding

Formal definitions and the problem they solve

Linear algebra is the language for working with feature vectors, model weights, and gradients. In ML you constantly write $w^\top x$, $X^\top X$, $\nabla f$, $\nabla^2 f$ — all of those are objects this section formalizes.

The handful of definitions you really need:

  • Vector / matrix: $x\in\mathbb{R}^d$ is an ordered list; $A\in\mathbb{R}^{m\times n}$ is an operator $\mathbb{R}^n\to\mathbb{R}^m$.
  • Dot product $x^\top y=\sum_i x_iy_i$ — the scalar measure of similarity / projection.
  • Norm: $\|x\|_2=\sqrt{x^\top x}$, $\|x\|_1=\sum_i|x_i|$, $\|x\|_\infty=\max_i|x_i|$.
  • Rank, column space, null space: how many independent directions $A$ has, where it sends inputs, and what it sends to zero.
  • Eigen / SVD: $Au=\lambda u$ and $X=U\Sigma V^\top$ — the canonical "what does this matrix really do" decompositions.
  • Symmetric, PSD, PD: $A=A^\top$, with $x^\top Ax\ge 0$ (PSD) or $>0$ (PD) — the way we test convexity of a loss.
  • Vector calculus shapes: gradient $\nabla f\in\mathbb{R}^{d}$, Hessian $\nabla^2 f\in\mathbb{R}^{d\times d}$, Jacobian $J\in\mathbb{R}^{m\times n}$.

Everything later — linear regression's closed form, logistic regression's Hessian, PCA, backprop — is built on these primitives.

2. Plain-English Explanation

Without formulas first

A vector is an arrow with a length (the norm) and a direction. A matrix is a function that takes one arrow and returns another; multiplying matrices is composing those functions.

The dot product $w^\top x$ asks "how much does $x$ point in the same direction as $w$?" That single number is exactly what a linear classifier outputs (Lecture 1, p. 22).

An eigenvector is a special arrow that the matrix only stretches, never rotates; the eigenvalue is by how much. The SVD says any matrix is just "rotate, stretch, rotate" — $X=U\Sigma V^\top$.

A PSD Hessian means the loss surface bends upward in every direction — a bowl. PD means a strict bowl with a unique bottom. That bowl property is why convex losses are so safe to optimize.

Why bother: backprop is matrix multiplication on autopilot, and almost every shape bug is a missing transpose. Master shapes once, debug forever.

3. Core Intuition

Why these tools earn their keep

Dot product = similarity: $w^\top x = \|w\|\|x\|\cos\theta$. Linear models, kernels, and attention all rank inputs by this overlap.

Norms power regularization: $\ell_2$ shrinks weights, $\ell_1$ shrinks and selects (the corners of the diamond ball).

Rank tells you when a system has solutions: if $X\in\mathbb{R}^{n\times d}$ has full row rank $n$, then $\mathrm{Col}(X)=\mathbb{R}^n$, so $Xw=y$ always has a solution (HW1 §3.1). The null space $\{v:Xv=0\}$ classifies all the non-uniqueness — any two solutions differ by a vector in $\mathrm{Ker}(X)$.

SVD reveals the geometry: $\Sigma$ stretches along orthonormal axes, and $U,V$ give the axes. Pseudo-inverses, low-rank approximations, PCA, and minimum-norm regression all live here.

Hessian shape rule: $X^\top BX\succeq 0$ whenever $B\succeq 0$. This single sandwich identity is what proves logistic loss convex (HW1 §4.1) and is reused everywhere.

These primitives reappear later as covariance matrices (PCA, GMM), Gram matrices (kernels, ridge), gradient flows in deep nets, Fisher information, and more.

4. Key Equations

Dot Product & Cosine
$$ x^\top y=\sum_{i=1}^{d} x_i y_i = \|x\|\|y\|\cos\theta $$

Symbols. $x, y\in\mathbb{R}^d$ are column vectors; $x^\top$ is the row form. $\|x\|=\sqrt{x^\top x}$ is the Euclidean length. $\theta$ is the angle between them.

How to read it. The dot product is "overlap" — large positive when the vectors point the same way, zero when perpendicular, negative when opposite. Linear models, kernels, and attention all rank inputs by this overlap.

How to use. To compute, multiply componentwise and sum. To turn a dot product into an angle, divide by $\|x\|\|y\|$. Linear classifier score: $w^\top x$.

$\ell_p$ Norms
$$ \|x\|_2=\sqrt{x^\top x},\ \|x\|_1=\sum_i|x_i|,\ \|x\|_\infty=\max_i|x_i| $$

Symbols. $\|x\|_2$ is the Euclidean / L2 norm; $\|x\|_1$ is the L1 (Manhattan / taxicab) norm; $\|x\|_\infty$ is the largest absolute coordinate. All are non-negative; zero iff $x=0$.

How to read it. A norm is "length." L2 = round ball; L1 = diamond ball (corners on the axes — that's why L1 sets weights exactly to zero); $\ell_\infty$ = box.

How to use. As regularizers ($\lambda\|w\|_2^2$ or $\lambda\|w\|_1$ added to the loss), as distances ($\|x-y\|$), or as size measures of gradients / weights. L2 is differentiable; L1 is not at zero.

Matrix-Multiply Shapes
$$ (m\times n)\cdot(n\times p)\to(m\times p) $$

Symbols. $A\in\mathbb{R}^{m\times n}$ has $m$ rows, $n$ cols. The "inner" dimension ($n$) must match between the two factors and disappears; the "outer" dimensions ($m, p$) survive.

How to read it. Matrix multiplication is function composition: applying $B$ then $A$ to a vector is $(AB)x$. Inner dimensions match because the output of $B$ must be a valid input to $A$.

How to use. Annotate every matrix in your derivation with its shape, then trace through to verify. Useful identities: $(AB)^\top=B^\top A^\top$; $(AB)C=A(BC)$ (associative); matrix multiplication is not commutative.

Rank-Nullity
$$ \dim\mathrm{Col}(A)+\dim\mathrm{Ker}(A)=n,\ \ A\in\mathbb{R}^{m\times n} $$

Symbols. $\mathrm{Col}(A)$ = column space (subspace of $\mathbb{R}^m$ that $A$ can hit). $\mathrm{Ker}(A)$ = null space = $\{v:Av=0\}$ (subspace of $\mathbb{R}^n$ that $A$ kills). $\dim$ counts the basis size of each. $n$ is the input dimension.

How to read it. Every input dimension is either preserved (becomes part of the output, contributing to $\mathrm{Col}$) or destroyed (squashed to zero, falling into $\mathrm{Ker}$). Total = $n$.

How to use. If $A$ has full column rank ($\dim\mathrm{Col}=n$), the null space is just $\{0\}$ and $Av=0\Rightarrow v=0$ — solutions are unique. If $\dim\mathrm{Ker}>0$, any solution to $Aw=y$ has a whole affine family of siblings $w+v$, $v\in\mathrm{Ker}(A)$.

Eigen Equation
$$ Au=\lambda u,\qquad u\ne 0 $$

Symbols. $A\in\mathbb{R}^{n\times n}$ (must be square). $u$ is an eigenvector — a non-zero direction that $A$ leaves pointing the same way. $\lambda$ is the matching eigenvalue — how much $u$ gets stretched. For symmetric $A$, all $\lambda$ are real and $u$'s can be chosen orthonormal.

How to read it. Eigenvectors are the "natural axes" of $A$ — along them, $A$ acts like simple scalar multiplication. In the eigenbasis the matrix is diagonal, and matrix powers / inverses become elementwise.

How to use. Solve $\det(A-\lambda I)=0$ for $\lambda$, then $(A-\lambda I)u=0$ for each eigenvector. PCA: top eigenvector of the covariance matrix = direction of maximum variance.

Reduced SVD
$$ X=U\Sigma V^\top,\ \ U\in\mathbb{R}^{n\times r},\ \Sigma\in\mathbb{R}^{r\times r}_{>0},\ V\in\mathbb{R}^{d\times r} $$

Symbols. $X\in\mathbb{R}^{n\times d}$ is any matrix; $r=\mathrm{rank}(X)$. $U, V$ have orthonormal columns ($U^\top U=I$, $V^\top V=I$). $\Sigma$ is diagonal with strictly positive singular values $\sigma_1\ge\sigma_2\ge\dots>0$.

How to read it. Every matrix is "rotate ($V^\top$) → stretch along orthonormal axes ($\Sigma$) → rotate ($U$)." Singular values measure how much $X$ stretches each axis.

How to use. Pseudo-inverse: $X^+=V\Sigma^{-1}U^\top$ (works even when $X$ isn't square or invertible). Low-rank approximation: keep top-$k$ singular values to compress / denoise. PCA: $V$'s columns are principal directions, singular values squared / $n$ = variances.

Quadratic Form & PSD
$$ x^\top A x=\sum_{i,j}A_{ij}x_ix_j,\quad \text{PSD}: x^\top A x\ge 0\ \forall x $$

Symbols. $A\in\mathbb{R}^{n\times n}$ symmetric ($A=A^\top$). The quadratic form is a scalar. PSD ($A\succeq 0$): $x^\top Ax\ge 0$ for all $x$. PD ($A\succ 0$): $x^\top Ax>0$ for all $x\ne 0$.

How to read it. $x^\top Ax$ is the "energy" of $x$ measured through $A$. PSD means the energy is never negative — geometrically, the surface $f(x)=x^\top Ax$ is a bowl (PD: strict bowl with unique bottom).

How to use. Equivalent tests: all eigenvalues $\ge 0$ (PSD) or $>0$ (PD); $A=B^\top B$ for some $B$ (PSD); leading principal minors $>0$ (PD). Used to certify a Hessian, hence to certify a loss is convex.

Sandwich Identity
$$ A=B^\top B \;\Rightarrow\; A\succeq 0;\quad X^\top D X \succeq 0\ \text{when}\ D\succeq 0 $$

Symbols. $B$ is any matrix; $X$ is any matrix; $D$ is symmetric PSD (often diagonal with non-negative entries). The right form is $X^\top D X$ — $D$ "sandwiched" between $X^\top$ and $X$.

How to read it. Multiplying a PSD matrix on both sides by the same factor never makes the energy negative — it just rescales the basis you measure energy in.

How to use. To prove $H\succeq 0$, factor $H$ as $X^\top D X$ with $D\succeq 0$, then expand $v^\top H v=(Xv)^\top D(Xv)=\sum_i D_{ii}(Xv)_i^2\ge 0$. This is exactly the proof that the logistic-loss Hessian is PSD (HW1 §4.1).

Vector-Calc Shapes
$$ \nabla f\in\mathbb{R}^{d},\ \nabla^2 f\in\mathbb{R}^{d\times d},\ J=\frac{\partial f}{\partial x}\in\mathbb{R}^{m\times n} $$

Symbols. Gradient $\nabla f$: column vector of partial derivatives, same length as the input. Hessian $\nabla^2 f$: matrix of second partials, symmetric for nice $f$. Jacobian $J$: rectangular for vector-valued $f:\mathbb{R}^n\to\mathbb{R}^m$, with $J_{ij}=\partial f_i/\partial x_j$.

How to read it. Conventions vary, but in this course gradients are columns. Track shapes obsessively: a missing transpose collapses your derivation silently. The chain rule for $f:\mathbb{R}^n\to\mathbb{R}^m\to\mathbb{R}^k$ is just $J_{\text{outer}}\,J_{\text{inner}}$ — matrix multiply.

How to use. Treat them as the standard "directional derivative machinery": gradient gives the steepest-ascent direction; Hessian gives curvature; Jacobian linearizes a vector-valued map (chain rule = matrix multiply).

Useful Derivatives
$$ \nabla_w (a^\top w)=a,\quad \nabla_w(w^\top A w)=(A+A^\top)w $$

Symbols. $a\in\mathbb{R}^d$ is a constant vector; $A\in\mathbb{R}^{d\times d}$ is a constant matrix; $w$ is the variable. The gradient is taken with respect to $w$.

How to read it. The first formula is the multivariable analogue of $(ax)'=a$. The second is the analogue of $(ax^2)'=2ax$ — the $A+A^\top$ shows up because $w^\top Aw=w^\top A^\top w$ depends on the symmetric part of $A$.

How to use. If $A$ is symmetric, $\nabla(w^\top A w)=2Aw$ and $\nabla^2=2A$. Combine with the chain rule to differentiate any quadratic / linear loss: for OLS, $L=\tfrac12\|Xw-y\|^2$ has $\nabla L=X^\top(Xw-y)$ and $\nabla^2 L=X^\top X$.

5. Worked Examples

Example 1 · Shape sanity check

Let $A\in\mathbb{R}^{m\times n}$, $x\in\mathbb{R}^{n}$. Then $Ax\in\mathbb{R}^{m}$ (column), $x^\top A\in\mathbb{R}^{1\times m}$ (row). Quadratic form $x^\top A x$ is a scalar but requires $A$ square; $A^\top A\in\mathbb{R}^{n\times n}$ and $AA^\top\in\mathbb{R}^{m\times m}$ are both symmetric and PSD.

Example 2 · Full-row-rank ⇒ $Xw=y$ has a solution (HW1 §3.1)

If $X\in\mathbb{R}^{n\times d}$ has rank $n$, the rows span $\mathbb{R}^n$, so $\mathrm{Col}(X)=\mathbb{R}^n$ and $y\in\mathrm{Col}(X)$. Concretely, with the SVD $X=U\Sigma V^\top$, the choice $w^*=V\Sigma^{-1}U^\top y$ gives $Xw^*=UU^\top y=y$.

Example 3 · Hessian PSD ⇒ convex (Lecture 3, p. 13)

Let $f(w)=\tfrac12 w^\top Aw - b^\top w + c$ with $A$ symmetric. Then $\nabla f=Aw-b$ and $\nabla^2 f=A$. If $A\succeq 0$, the second-order test gives $f$ convex; if $A\succ 0$, $f$ is strictly convex with the unique minimizer $w^*=A^{-1}b$.

Example 4 · Logistic Hessian $H=X^\top BX$ is PSD (HW1 §4.1)

For binary cross-entropy with $\sigma(z)=\tfrac{1}{1+e^{-z}}$, the Hessian factors as $H=X^\top B X$ where $B$ is diagonal with $B_{ii}=\sigma(w^\top x_i)(1-\sigma(w^\top x_i))\in[0,\tfrac14]$.

For any $v$, $v^\top H v=(Xv)^\top B(Xv)=\sum_i B_{ii}(Xv)_i^2\ge 0$, so $H\succeq 0$. The logistic loss is therefore convex everywhere, and every local minimum is global (HW1 §4.2).

Example 5 · Norm concentration in high dimensions (HW1 §1.2)

If $X,q\sim\mathrm{Unif}([0,1]^d)$ are independent, then per coordinate $\mathbb{E}(X_i-q_i)^2=\tfrac16$, so $\mathbb{E}\|X-q\|^2=d/6$. The variance is $O(d)$, so by Chebyshev the relative spread $\sqrt{\mathrm{Var}}/\mathbb{E}\to 0$ as $d\to\infty$ — every distance "looks the same," which is exactly what kills KNN in high dimensions.

6. Problem-Solving Tips

How to attack a linear-algebra question
  1. Annotate shapes first. Write the dimension next to every symbol — mismatched inner dims are the #1 source of errors.
  2. To prove convex / PSD, try to write the matrix as $B^\top B$ or $X^\top D X$ with $D\succeq 0$, then expand $v^\top(\cdot)v$ as a sum of squares.
  3. For "$Xw=y$ has a solution", invoke rank: full row rank ⇒ surjective ⇒ solution exists.
  4. For minimum-norm / SVD problems, split any solution as $w=w_\infty+v$ with $v\in\mathrm{Ker}(X)$; orthogonality gives $\|w\|^2=\|w_\infty\|^2+\|v\|^2$.
  5. Memorize $\nabla(a^\top w)=a$ and $\nabla(w^\top Aw)=(A+A^\top)w$; everything else composes from chain rule.
  6. Sanity check: gradients are columns, losses are scalars, Hessians are symmetric squares. If shapes don't match, you transposed something.

7. Common Mistakes

Frequent traps
  • Treating the gradient as a row vector — convention is $\nabla f\in\mathbb{R}^{d\times 1}$.
  • Confusing $x^\top y$ (scalar) with $x\odot y$ (vector).
  • Writing $(AB)^\top=A^\top B^\top$ — the correct order is $B^\top A^\top$.
  • Confusing $X^\top X$ ($d\times d$) with $XX^\top$ ($n\times n$); both are PSD but live in different spaces.
  • Inverting non-square or rank-deficient matrices — use the pseudo-inverse $X^+$.
  • Treating "PSD ⇒ PD" as automatic; PSD allows zero eigenvalues, so the optimum may be a flat valley.
  • Talking about PSD/PD for non-symmetric matrices — those tests only apply to symmetric (or Hermitian) matrices.

8. Exam Focus

What you must walk in able to do
  • Quickly infer dimensions in any backprop / linear-regression expression.
  • Use $\nabla^2 f\succeq 0$ to argue convexity, and PD to argue uniqueness.
  • Prove $H=X^\top BX\succeq 0$ via the sandwich $v^\top H v=(Xv)^\top B(Xv)$.
  • Write the SVD $X=U\Sigma V^\top$ and pseudo-inverse $X^+=V\Sigma^{-1}U^\top$.
  • State the rank ↔ column-space ↔ solvability link for $Xw=y$.
  • Remember: PCA's max-variance direction = top eigenvector of the covariance matrix.
  • Apply $\nabla(a^\top w)=a$ and $\nabla(w^\top Aw)=(A+A^\top)w$.

9. Quick Checklist

Last-minute recall

  • $A_{m\times n}B_{n\times p}\Rightarrow m\times p$; $(AB)^\top=B^\top A^\top$.
  • Symmetric + all $\lambda\ge 0$ ⇔ PSD; all $\lambda>0$ ⇔ PD.
  • $X^\top BX\succeq 0$ when $B\succeq 0$ — sandwich.
  • Full row rank ⇒ $Xw=y$ has a solution.
  • SVD $X=U\Sigma V^\top$, pseudo-inverse $V\Sigma^{-1}U^\top$.
  • Eigen $Au=\lambda u$; PCA picks largest $\lambda$ of covariance.
  • Gradients are columns; Hessians are symmetric squares.
  • $\nabla(a^\top w)=a$; $\nabla(w^\top Aw)=(A+A^\top)w$.

📐 线性代数

1. 概念理解

正式定义与它解决的问题

线性代数是处理特征向量、模型权重和梯度的语言。在 ML 里你会反复写 $w^\top x$、$X^\top X$、$\nabla f$、$\nabla^2 f$——它们都是这一节定义的对象。

真正必须知道的几条定义：

  • 向量 / 矩阵：$x\in\mathbb{R}^d$ 是有序数列；$A\in\mathbb{R}^{m\times n}$ 是把 $\mathbb{R}^n\to\mathbb{R}^m$ 的算子。
  • 点积 $x^\top y=\sum_i x_iy_i$ —— 相似度 / 投影的标量度量。
  • 范数：$\|x\|_2=\sqrt{x^\top x}$、$\|x\|_1=\sum_i|x_i|$、$\|x\|_\infty=\max_i|x_i|$。
  • 秩、列空间、零空间：$A$ 有几个独立方向、把输入送到哪、把谁送到 0。
  • 特征 / SVD：$Au=\lambda u$ 与 $X=U\Sigma V^\top$，回答“这个矩阵到底在干什么”。
  • 对称、PSD、PD：$A=A^\top$，且 $x^\top Ax\ge 0$（PSD）或 $>0$（PD）—— 用来判断损失是否凸。
  • 向量微积分形状：梯度 $\nabla f\in\mathbb{R}^{d}$、Hessian $\nabla^2 f\in\mathbb{R}^{d\times d}$、Jacobian $J\in\mathbb{R}^{m\times n}$。

后面要用的——线性回归闭式解、Logistic Hessian、PCA、反向传播——都建立在这些原语上。

2. 大白话理解

不看公式先懂大概

向量就是一根有长度（范数）和方向的箭头；矩阵是一个把箭头变成另一个箭头的函数；矩阵乘法 = 函数复合。

点积 $w^\top x$ 在问“$x$ 沿 $w$ 方向走了多少？”——线性分类器干的就是这件事（Lecture 1, p. 22）。

特征向量是矩阵只伸缩、不旋转的特殊方向，特征值是伸缩倍数。SVD 说任意矩阵都是“旋转-伸缩-旋转”，$X=U\Sigma V^\top$。

PSD Hessian = 损失曲面在每个方向都向上弯，是个碗；PD 是有唯一底的严格碗。这就是凸损失为什么好优化。

为什么得练熟：反向传播就是矩阵乘法的自动版本，绝大多数 bug 都是少了一个转置——一次搞懂 shape，终身受益。

3. 核心直觉

这些工具为何有用

点积 = 相似度：$w^\top x = \|w\|\|x\|\cos\theta$。线性模型、核方法、注意力都按它打分。

范数撑起正则化：$\ell_2$ 收缩，$\ell_1$ 收缩 + 选择（菱形球的角点会归零）。

秩告诉你方程组什么时候有解：$X\in\mathbb{R}^{n\times d}$ 满行秩 ⇒ $\mathrm{Col}(X)=\mathbb{R}^n$ ⇒ $Xw=y$ 必有解（HW1 §3.1）。零空间 $\{v:Xv=0\}$ 描述所有非唯一性——任意两解之差落在 $\mathrm{Ker}(X)$ 里。

SVD 揭示几何：$\Sigma$ 沿正交轴伸缩，$U,V$ 给轴。伪逆、低秩近似、PCA、最小范数回归都在这里。

Hessian 形状定理：$X^\top BX\succeq 0$（只要 $B\succeq 0$）。这一个夹心恒等式就证明了 logistic 损失凸（HW1 §4.1），后面会反复用。

这些原语后面会以协方差矩阵（PCA、GMM）、Gram 矩阵（核、岭）、深度网络的梯度流、Fisher 信息等形式不断出现。

4. 关键公式

点积与余弦
$$ x^\top y=\sum_{i=1}^{d} x_i y_i = \|x\|\|y\|\cos\theta $$

符号. $x, y\in\mathbb{R}^d$ 是列向量，$x^\top$ 是其行形式；$\|x\|=\sqrt{x^\top x}$ 是欧式长度；$\theta$ 是二者夹角。

怎么理解. 点积是"重叠度"——同向时大正、垂直时为 0、反向时为负。线性模型、kernel 方法、attention 都靠这一重叠值打分。

怎么用. 计算就是逐分量相乘再求和；想得到夹角，把点积除以 $\|x\|\|y\|$。线性分类器的 score 就是 $w^\top x$。

$\ell_p$ 范数
$$ \|x\|_2=\sqrt{x^\top x},\ \|x\|_1=\sum_i|x_i|,\ \|x\|_\infty=\max_i|x_i| $$

符号. $\|x\|_2$ 欧式 / L2 范数；$\|x\|_1$ L1（曼哈顿 / 出租车）范数；$\|x\|_\infty$ 最大绝对分量。都非负，等于 0 当且仅当 $x=0$。

怎么理解. 范数就是"长度"。L2 = 圆球；L1 = 菱形球（角点落在坐标轴上，所以 L1 才会把权重精确推到 0）；$\ell_\infty$ = 方盒。

怎么用. 用作正则项（损失上加 $\lambda\|w\|_2^2$ 或 $\lambda\|w\|_1$）、距离 $\|x-y\|$、或衡量梯度 / 权重的大小。L2 处处可微；L1 在 0 不可微。

矩阵乘法形状
$$ (m\times n)\cdot(n\times p)\to(m\times p) $$

符号. $A\in\mathbb{R}^{m\times n}$ 表示 $m$ 行 $n$ 列；"内"维 $n$ 必须匹配并消失，"外"维 $m, p$ 保留。

怎么理解. 矩阵乘法 = 函数复合：先用 $B$ 再用 $A$ 等于 $(AB)x$。中间维必须匹配，因为 $B$ 的输出要能当 $A$ 的合法输入。

怎么用. 推导时给每个矩阵标 shape 再追踪。常用恒等式：$(AB)^\top=B^\top A^\top$；$(AB)C=A(BC)$（结合律）。注意：矩阵乘法不满足交换律。

秩 - 零度定理
$$ \dim\mathrm{Col}(A)+\dim\mathrm{Ker}(A)=n,\ \ A\in\mathbb{R}^{m\times n} $$

符号. $\mathrm{Col}(A)$ = 列空间（$A$ 能映射到的 $\mathbb{R}^m$ 子空间）；$\mathrm{Ker}(A)$ = 零空间 = $\{v:Av=0\}$（被 $A$ 杀掉的 $\mathbb{R}^n$ 子空间）；$\dim$ 数它们的基个数；$n$ 是输入维度。

怎么理解. 每个输入维度要么被保留（贡献到 $\mathrm{Col}$），要么被压成 0（落进 $\mathrm{Ker}$），二者之和必为 $n$。

怎么用. 若 $A$ 满列秩（$\dim\mathrm{Col}=n$），则 $\mathrm{Ker}=\{0\}$，$Av=0\Rightarrow v=0$，解唯一。若 $\dim\mathrm{Ker}>0$，$Aw=y$ 的解构成一整个仿射族 $w+v$，$v\in\mathrm{Ker}(A)$。

特征方程
$$ Au=\lambda u,\qquad u\ne 0 $$

符号. $A\in\mathbb{R}^{n\times n}$（必须方阵）；$u$ 是 eigenvector，是 $A$ 不改变方向的非零向量；$\lambda$ 是匹配的 eigenvalue，是 $u$ 被拉伸的倍数。$A$ 对称时所有 $\lambda$ 实数，$u$ 可选成正交单位基。

怎么理解. eigenvector 是 $A$ 的"自然轴"，沿它 $A$ 退化成简单的标量乘。换到 eigenbasis 后矩阵变对角，求幂、求逆都变成逐元素的。

怎么用. 解 $\det(A-\lambda I)=0$ 求 $\lambda$，再解 $(A-\lambda I)u=0$ 求每个 $u$。PCA：协方差矩阵最大特征值对应的方向 = 最大方差方向。

紧凑 SVD
$$ X=U\Sigma V^\top,\ \ U\in\mathbb{R}^{n\times r},\ \Sigma\in\mathbb{R}^{r\times r}_{>0},\ V\in\mathbb{R}^{d\times r} $$

符号. $X\in\mathbb{R}^{n\times d}$ 任意矩阵；$r=\mathrm{rank}(X)$。$U, V$ 列正交（$U^\top U=I$，$V^\top V=I$）。$\Sigma$ 对角，singular values $\sigma_1\ge\sigma_2\ge\dots>0$。

怎么理解. 任意矩阵 = "旋转 ($V^\top$) → 沿正交轴伸缩 ($\Sigma$) → 旋转 ($U$)"。singular value 衡量 $X$ 在每个轴上拉多大。

怎么用. 伪逆 $X^+=V\Sigma^{-1}U^\top$（即便 $X$ 不方 / 不可逆也能算）；低秩近似——只保留前 $k$ 个奇异值压缩 / 去噪；PCA：$V$ 的列是主方向，singular value 平方除以 $n$ 是各方向方差。

二次型与 PSD
$$ x^\top A x=\sum_{i,j}A_{ij}x_ix_j,\quad \text{PSD}: x^\top A x\ge 0\ \forall x $$

符号. $A\in\mathbb{R}^{n\times n}$ 对称（$A=A^\top$）；二次型是标量。PSD（$A\succeq 0$）：对所有 $x$ 都有 $x^\top Ax\ge 0$；PD（$A\succ 0$）：对所有 $x\ne 0$ 都有 $x^\top Ax>0$。

怎么理解. $x^\top Ax$ 是 $x$ 通过 $A$ 测得的"能量"。PSD = 能量永远非负；几何上曲面 $f(x)=x^\top Ax$ 是个碗（PD = 严格碗、唯一底）。

怎么用. 等价判定：所有特征值 $\ge 0$（PSD）/ $>0$（PD）；存在 $A=B^\top B$（PSD）；前主子式 $>0$（PD）。用于认证 Hessian，进而认证损失为凸。

夹心恒等式
$$ A=B^\top B \;\Rightarrow\; A\succeq 0;\quad X^\top D X \succeq 0\ \text{当}\ D\succeq 0 $$

符号. $B$ 任意矩阵；$X$ 任意矩阵；$D$ 对称 PSD（常见为对角且元素 $\ge 0$）。右形 $X^\top D X$——把 $D$ 夹在 $X^\top$ 与 $X$ 之间。

怎么理解. PSD 矩阵两边乘同一因子永远不会让能量变负——只是把测能量的基重新缩放了。

怎么用. 证 $H\succeq 0$，把 $H$ 凑成 $X^\top D X$（$D\succeq 0$），再展 $v^\top H v=(Xv)^\top D(Xv)=\sum_i D_{ii}(Xv)_i^2\ge 0$。logistic Hessian 是 PSD 的证明就是这一招（HW1 §4.1）。

向量微积分形状
$$ \nabla f\in\mathbb{R}^{d},\ \nabla^2 f\in\mathbb{R}^{d\times d},\ J=\frac{\partial f}{\partial x}\in\mathbb{R}^{m\times n} $$

符号. Gradient $\nabla f$：偏导组成的列向量，长度等于输入维度。Hessian $\nabla^2 f$：二阶偏导组成的矩阵，光滑函数下对称。Jacobian $J$：向量值 $f:\mathbb{R}^n\to\mathbb{R}^m$ 的 $m\times n$ 矩阵，$J_{ij}=\partial f_i/\partial x_j$。

怎么理解. 约定不同，本课中 gradient 是列。盯紧 shape：少一个转置整条推导静悄悄塌掉。$f:\mathbb{R}^n\to\mathbb{R}^m\to\mathbb{R}^k$ 的链式法则就是 $J_{\text{outer}}\,J_{\text{inner}}$ 矩阵乘法。

怎么用. 当作"方向导数机器"：gradient 给最陡上升方向；Hessian 给曲率；Jacobian 把向量映射线性化（链式法则 = 矩阵乘法）。

常用导数
$$ \nabla_w (a^\top w)=a,\quad \nabla_w(w^\top A w)=(A+A^\top)w $$

符号. $a\in\mathbb{R}^d$ 常向量；$A\in\mathbb{R}^{d\times d}$ 常矩阵；$w$ 是变量；梯度对 $w$ 取。

怎么理解. 第一条是 $(ax)'=a$ 的多元版本；第二条是 $(ax^2)'=2ax$ 的多元版本——$A+A^\top$ 出现是因为 $w^\top Aw=w^\top A^\top w$ 只取决于 $A$ 的对称部分。

怎么用. $A$ 对称时 $\nabla(w^\top Aw)=2Aw$、$\nabla^2=2A$。配合链式法则可微分任意二次 / 线性损失：OLS $L=\tfrac12\|Xw-y\|^2$ 的 $\nabla L=X^\top(Xw-y)$，$\nabla^2 L=X^\top X$。

5. 例题精解

例 1 · Shape 自检

设 $A\in\mathbb{R}^{m\times n}$，$x\in\mathbb{R}^{n}$。则 $Ax\in\mathbb{R}^{m}$（列），$x^\top A\in\mathbb{R}^{1\times m}$（行）。$x^\top Ax$ 是标量但要求 $A$ 方；$A^\top A\in\mathbb{R}^{n\times n}$ 与 $AA^\top\in\mathbb{R}^{m\times m}$ 都对称且 PSD。

例 2 · 满行秩 ⇒ $Xw=y$ 有解（HW1 §3.1）

$X\in\mathbb{R}^{n\times d}$ 满行秩 ⇒ 行张成 $\mathbb{R}^n$，所以 $\mathrm{Col}(X)=\mathbb{R}^n$ 且 $y\in\mathrm{Col}(X)$。具体构造：取 SVD $X=U\Sigma V^\top$，则 $w^*=V\Sigma^{-1}U^\top y$ 满足 $Xw^*=UU^\top y=y$。

例 3 · Hessian PSD ⇒ 凸（Lecture 3, p. 13）

$f(w)=\tfrac12 w^\top Aw - b^\top w + c$，$A$ 对称。$\nabla f=Aw-b$，$\nabla^2 f=A$。$A\succeq 0$ 时二阶判定 $f$ 凸；$A\succ 0$ 时严格凸，唯一极小 $w^*=A^{-1}b$。

例 4 · Logistic Hessian $H=X^\top BX$ 是 PSD（HW1 §4.1）

对二元交叉熵（$\sigma(z)=\tfrac{1}{1+e^{-z}}$），Hessian 写成 $H=X^\top BX$，$B$ 对角且 $B_{ii}=\sigma(w^\top x_i)(1-\sigma(w^\top x_i))\in[0,\tfrac14]$。

对任意 $v$，$v^\top H v=(Xv)^\top B(Xv)=\sum_i B_{ii}(Xv)_i^2\ge 0$，所以 $H\succeq 0$。logistic 损失处处凸，任意局部最优都是全局（HW1 §4.2）。

例 5 · 高维范数集中（HW1 §1.2）

$X,q\sim\mathrm{Unif}([0,1]^d)$ 独立。逐坐标 $\mathbb{E}(X_i-q_i)^2=\tfrac16$，所以 $\mathbb{E}\|X-q\|^2=d/6$。方差 $O(d)$，由 Chebyshev 得 $\sqrt{\mathrm{Var}}/\mathbb{E}\to 0$（$d\to\infty$）—— 所有距离“看起来差不多”，KNN 在高维失效。

6. 题型与解题步骤

看到题怎么下手
  1. 先标 shape：每个符号旁标维度；中间维不匹配是 #1 错源。
  2. 证凸 / PSD：尝试写成 $B^\top B$ 或 $X^\top D X$（$D\succeq 0$），把 $v^\top(\cdot)v$ 凑成平方和。
  3. “证 $Xw=y$ 有解”：诉诸秩——满行秩 ⇒ 满射 ⇒ 有解。
  4. 最小范数 / SVD 类：把任意解写成 $w=w_\infty+v$（$v\in\mathrm{Ker}(X)$），用正交得 $\|w\|^2=\|w_\infty\|^2+\|v\|^2$。
  5. 背两条求导：$\nabla(a^\top w)=a$，$\nabla(w^\top Aw)=(A+A^\top)w$；其他链式法则组合。
  6. 自检：梯度是列，损失是标量，Hessian 对称方阵；对不上就是少了转置。

7. 常见错误

高频陷阱
  • 把梯度写成行向量——约定 $\nabla f\in\mathbb{R}^{d\times 1}$。
  • $x^\top y$（标量）与 $x\odot y$（向量）混用。
  • 写成 $(AB)^\top=A^\top B^\top$——正确为 $B^\top A^\top$。
  • $X^\top X$（$d\times d$）与 $XX^\top$（$n\times n$）混淆，都 PSD 但所在空间不同。
  • 对非方 / 退化矩阵硬求逆——用伪逆 $X^+$。
  • 把“PSD ⇒ PD”当成自动；PSD 允许 0 特征值，最优可能是平谷而非唯一点。
  • 对非对称矩阵谈 PSD/PD——这些概念只对对称（或 Hermitian）矩阵有定义。

8. 考试重点

必须能做的
  • 反向传播 / 线性回归里能一眼判形状。
  • 用 $\nabla^2 f\succeq 0$ 论凸，用 PD 论唯一。
  • 用夹心 $v^\top Hv=(Xv)^\top B(Xv)$ 证 $H=X^\top BX\succeq 0$。
  • 记住 SVD $X=U\Sigma V^\top$ 与伪逆 $X^+=V\Sigma^{-1}U^\top$。
  • 能说清秩 ↔ 列空间 ↔ $Xw=y$ 是否可解。
  • PCA：最大方差方向 = 协方差最大特征值对应的特征向量。
  • 会用 $\nabla(a^\top w)=a$ 与 $\nabla(w^\top Aw)=(A+A^\top)w$。

9. 速记清单

最后一刻能默

  • $A_{m\times n}B_{n\times p}\Rightarrow m\times p$；$(AB)^\top=B^\top A^\top$。
  • 对称且全 $\lambda\ge 0$ ⇔ PSD；全 $\lambda>0$ ⇔ PD。
  • $X^\top BX\succeq 0$（$B\succeq 0$ 时）—— 夹心。
  • 满行秩 ⇒ $Xw=y$ 有解。
  • SVD $X=U\Sigma V^\top$，伪逆 $V\Sigma^{-1}U^\top$。
  • 特征 $Au=\lambda u$；PCA 取协方差最大 $\lambda$。
  • 梯度是列，Hessian 是对称方阵。
  • $\nabla(a^\top w)=a$；$\nabla(w^\top Aw)=(A+A^\top)w$。
